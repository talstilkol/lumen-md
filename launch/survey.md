# The weekly beta survey (voluntary)

> Plan W2.25 measures active testers **only** with this survey. Lumen has no
> analytics. Post it each week as a GitHub Discussions **poll** in the *Beta*
> category (GitHub polls are anonymous to other readers; GitHub shows the
> totals). Copy the poll below. Nothing in the app asks for it or reports it.

## Poll (Hebrew first, English below)

**כמה ימים השבוע פתחתם את Lumen? / How many days this week did you open Lumen?**

- 0
- 1–2
- 3–4
- 5–7

**Body text:**

> סקר שבועי מרצון, בלי שמות. הוא הדרך היחידה שבה אנחנו יודעים כמה אנשים
> משתמשים בבטא: האפליקציה לא סופרת אתכם. אם משהו הפריע לכם השבוע, ספרו
> בתגובה.
>
> A voluntary, anonymous weekly survey. It's the only way we know how many
> people use the beta: the app doesn't count you. If something got in your
> way this week, say so in a reply.

## Counting

An **active tester** is a "3–4" or "5–7" answer. The week's count is that
number, as GitHub shows it. Record it in a table in this file each week:

| Week | Answers | Active (≥ 3 days) |
