# The Lumen community

Lumen is built in the open, in Hebrew and English. This guide says where to
talk, how to help, and how we treat each other. A Hebrew version is in
[COMMUNITY.he.md](COMMUNITY.he.md).

## Where

| For | Where |
|---|---|
| Joining the beta | GitHub Discussions → **Beta** (a short form) |
| Beta feedback: bugs, ideas, Hebrew and RTL problems | GitHub Discussions → **Beta feedback** |
| A confirmed bug, a concrete feature | GitHub Issues |
| Questions, show and tell | GitHub Discussions → **Q&A** / **Show and tell** |
| A security problem | Privately, as in [SECURITY.md](SECURITY.md); never in public |

Write in Hebrew or English, whichever you prefer. Both get an answer.

## How the beta works

- New features reach beta builds first (feature flags, plan 14.4).
- **Once a week there's a short, voluntary survey** in Discussions: did you
  open Lumen on three days or more this week, and what got in the way? That
  survey is the only way we know who uses Lumen. The app has no analytics
  and doesn't count you.
- Every feedback report is read and given a triage label (plan 14.3), so you
  can see what happened to it.
- Keep a backup (*Export the whole vault*). It's a beta.

## How to help without writing code

- Use Lumen for real writing, and tell us where it got in your way.
- Check Hebrew: wording, direction, niqqud, numbers, dates.
- Review translations (`src/i18n/locales/`).
- Answer someone else's question in Discussions.
- Write a template or a guide for how you work.

Code contributions: see [CONTRIBUTING.md](CONTRIBUTING.md).

## How we treat each other

The [code of conduct](CODE_OF_CONDUCT.md) applies everywhere the project
meets. In short:

- assume good intent;
- criticise the work, not the person;
- no harassment, no personal attacks, no sharing someone's private
  information;
- political arguments stay out of the project's spaces, whatever side.

## Reporting

If someone breaks the code of conduct, or you feel unsafe, report it
privately to the maintainers:

- **Private report:** OWNER — add the private address (an e-mail you read)
  here before the launch.
- On GitHub, *Report content* on any comment also reaches GitHub's own
  moderation.

Reports are confidential. We answer within a week, and act according to the
code's enforcement guidelines.

## Moderation

Maintainers may hide, edit, lock or delete what breaks the code, and say
why. Moderation decisions can be appealed privately, at the same address.
