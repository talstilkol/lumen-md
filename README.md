# ‏Lumen — עורך פתקים שנבנה לעברית

**עברית** · [English](README.en.md)

> **מקומי ופרטי כברירת מחדל. עברית קודם.**

‏Lumen הוא עורך Markdown לפתקים, למחקר ולכתיבה. הפתקים נשמרים במכשיר שלכם
כקובצי Markdown רגילים, העורך עובד בלי אינטרנט, ועברית ושאר השפות שנכתבות
מימין לשמאל עובדות כמו שצריך: הממשק מתהפך, הכיוון נקבע לכל שורה, והחיפוש
מבין תחיליות וניקוד. שום דבר לא יוצא מהמכשיר אלא אם הפעלתם יכולת שצריכה
את זה.

## ✨ מה מיוחד ב-Lumen

| | |
|---|---|
| **עברית ומימין לשמאל** | ממשק ב-8 שפות, ובהן עברית וערבית בפריסה הפוכה; כיוון לכל שורה, כך שמונח באנגלית או מספר בתוך משפט עברי נשארים במקום; קוד ומתמטיקה נשארים משמאל לימין |
| **מקומי ופרטי** | הפתקים באחסון הפרטי של הדפדפן או בתיקייה שבחרתם; עובד בלי רשת; בלי חשבון; סודות מוצפנים |
| **חיפוש בעברית** | `⇧⌘F` מוצא מילים עם תחיליות (ב, ה, ו, ל…) ומתעלם מניקוד ומאותיות סופיות |
| **הקבצים שלכם** | כל פתק הוא קובץ Markdown; ייצוא של כל הכספת כ-zip או כתיקייה; ייבוא כספת Obsidian או ייצוא Notion |
| **בינה מלאכותית, אם רוצים** | מודל שרץ על המכשיר, או ספק ענן עם מפתח משלכם — רק אם תבחרו |
| **עבודה משותפת** | עריכה בזמן אמת מעמית לעמית, בלי שרת |

## 🚀 התחלה

אפליקציית הרשת לא דורשת התקנה. לפרטים ולגרסת שולחן העבודה:
[התקנת Lumen](docs/src/content/docs/he/getting-started/install.md).

מהקוד:

```bash
npm install
npm run dev          # http://localhost:5173
```
