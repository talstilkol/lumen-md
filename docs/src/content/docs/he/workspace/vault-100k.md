העמוד הזה ממשיך את [כספות גדולות ופתקים ארוכים](/he/workspace/large-vaults/), שיש לו גרסה באנגלית בלבד. משתמשים כבדים מגיעים ל-50,000 עד 100,000 פתקים, ושם רוב אפליקציות הפתקים
מאטות. ‏Lumen נמדד מול כספת סינתטית של 100,000 פתקים: 190 מיליון תווים,
שני שלישים מהם בעברית, כולם עם קישורי ויקי.

| מה נמדד (100,000 פתקים) | סף | תוצאה |
|---|---|---|
| חיפוש: מילה, עברית עם אותיות שימוש, ביטוי, או חיפוש בלי תוצאות | ‏< 200 ms | ‏73–148 ms |
| שמירה ← באינדקס | ‏< 50 ms | ‏9 ms |
| זיכרון של אינדקס החיפוש | ‏< 1.5 GB | ‏757 MB (היה 4.3 GB) |
| זיכרון הפתקים ב-thread הראשי של האפליקציה | | ‏67 MB (היה 364 MB) |
| בניית האינדקס מאפס, ב-worker ברקע | | ‏7 s (היה 29 s) |

## מה עושה את זה מהיר

- **עותק אחד של הטקסט.** טקסט החיפוש של כל פתק (באותיות קטנות, ובעברית גם
  בלי תלות בניקוד, באותיות סופיות ובאותיות שימוש) נשמר פעם אחת, במקטעים של
  256 פתקים, ולא פעמיים או שלוש לכל פתק. חיפוש הוא סריקה אחת לכל מקטע.
- **הטקסט נמצא רק באינדקס.** ה-thread הראשי של האפליקציה מחזיק תקציר קטן של
  כל פתק: הקישורים, התגיות, ה-frontmatter והאורך. הגרף ותצוגת התגיות קוראים
  את התקציר, ושינויי שם קורים בתוך האינדקס.
- **שמירה נוגעת במקטע אחד.** שמירת פתק בונה מחדש רק את טקסט החיפוש של המקטע
  שלו.
- **האינדקס נשמר בין הפעלות.** אחרי שינויים, הפתקים שבאינדקס נשמרים במסד
  הנתונים של הדפדפן כשהוא פנוי. בפתיחה הבאה של האפליקציה, כל פתק שזמן
  השינוי שלו לא השתנה מגיע משם, ורק השאר נקראים מהדיסק. אם האינדקס השמור
  חסר או לא מעודכן, ‏Lumen פשוט בונה אותו מחדש במלואו.
- **כל זה רץ מחוץ ל-thread הראשי.** האינדקס יושב ב-worker, ולכן הוא אף פעם
  לא חוסם את פתיחת האפליקציה או את ההקלדה. עץ הקבצים מציג מספר מוגבל של
  שורות בכל תיקייה.
- **embeddings קומפקטיים.** כשהאינדקס הסמנטי מחזיק יותר מ-50,000 קטעים,
  הווקטורים שלהם נשמרים בזיכרון כמספרים שלמים של 8 ביט. זה רבע מהזיכרון,
  עם ציונים בטווח של 1% מאלה שבדיוק מלא. הווקטורים נפרסים פתק אחד בכל פעם,
  כשחיפוש צריך אותם.

## למדוד בעצמכם

```sh
npm run perf:vault100k                  # 100,000 פתקים, נכשל אם סף נשבר
npm run perf:vault100k -- --soak 1440   # 24 שעות של עריכות, מחיקות וחיפושים אקראיים
```
