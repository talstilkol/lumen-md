**מקור** הוא פתק על משהו שאתם קוראים: ספר, מאמר או אתר. זה
[סוג](/he/workspace/database-views/) מובנה עם השדות האלה ב-frontmatter, ושום
דבר מחוץ ל-frontmatter:

| שדה | ערכים |
|---|---|
| `status` | ‏`to-read` (לקרוא), ‏`reading` (בקריאה), ‏`done` (נקרא) |
| `kind` | ‏`book`, ‏`article`, ‏`website` |
| `progress` | אחוז שנקרא, 0–100 |
| `page`, ‏`pages` | איפה אתם והאורך (עמודי PDF, פרקי EPUB) |
| `rating` | הדירוג שלכם, 1–5 |
| `file` | ה-PDF או ה-EPUB שבו אתם קוראים, כקישור: ‏`"[[papers/cohen.pdf]]"` |
| `author`, ‏`year`, ‏`url`, ‏`citekey`, ‏`finished` | מפריט הספרייה, או ידנית |

פתק הוא מקור כשה-frontmatter שלו אומר `type: source` או כשיש לו התגית
`#source`. קובץ `.lumen/types/source.yaml` בכספת מחליף את הסוג המובנה, כמו כל
סוג אחר.

## ההתקדמות מתעדכנת לבד

כשאתם קוראים PDF או EPUB שמקור מציין ב-`file:`, הקורא כותב למקור הזה איפה
אתם:

- **PDF:** העמוד שבו עצרתם, מתוך עמודי ה-PDF. עמוד 50 מתוך 200 הוא
  ‏`progress: 25`.
- **EPUB:** הפרק, מתוך פרקי הספר.
- העמוד הראשון שאתם מעבירים מעביר את המקור מ-`to-read` ל-`reading`. העמוד
  האחרון מעביר אותו ל-`done` וכותב את היום ב-`finished:`. מקור שסימנתם `done`
  נשאר כזה כשאתם פותחים אותו שוב.

רק המפתחות האלה ב-frontmatter משתנים. שאר הפתק, כולל הגוף שלו, נשאר כמו
שהוא.

## רשימת הקריאה

לוח הפקודות (⌘K) ← **כל המקורות** פותח את ה-Base של הסוג. התצוגה **לפי מצב**
שלו היא לוח kanban עם העמודות לקרוא, בקריאה ונקרא. **שמירה כ-.base** שומרת
אותו כקובץ ש-Obsidian פותח גם הוא.

## מקורות חדשים

צרו פתק עם `type: source` (או התגית `#source`), ‏`status: to-read` וקישור
ב-`file:`, ומלאו את מה שאתם יודעים. יצירת מקור ישירות מפריט של Zotero
או מדף שנלכד בדפדפן בדרך: ההמרה כתובה ונבדקה, הפקודה עדיין לא קיימת.
