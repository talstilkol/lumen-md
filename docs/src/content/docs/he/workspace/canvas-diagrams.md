**תרשים…** בסרגל הקנבס פותח את חלון התרשים. התרשים מוצב במרכז התצוגה
כצורות קנבס רגילות: תיבות, חצים ותוויות שאפשר להזיז, לעצב ולחבר לשאר
הקנבס.

## מ־Mermaid

מדביקים הגדרת Mermaid ובוחרים **הוספה** (או `⌘Enter`). חמישה סוגים
הופכים לצורות שאפשר לערוך:

| סוג | שורה ראשונה |
|---|---|
| תרשים זרימה | `flowchart TD`,‏ `flowchart LR`,‏ `graph TD` |
| רצף | `sequenceDiagram` |
| מחלקות | `classDiagram` |
| מצבים | `stateDiagram-v2` |
| ישויות וקשרים | `erDiagram` |

סוגי Mermaid אחרים (mindmap,‏ gantt,‏ pie, …) נוספים כתמונה של התרשים,
והחלון אומר זאת מראש.

לפני ההמרה Mermaid עצמו בודק את ההגדרה, ושגיאת תחביר מוצגת עם ההודעה של
Mermaid. אחרי ההמרה מחפשים כל תווית מההגדרה בצורות החדשות. אם חסרה
תווית, החלון נשאר פתוח ומציין אותה.

תוויות בעברית עובדות בכל הסוגים. בתרשים ER שמות הישויות חייבים להיות
באותיות לטיניות: העברית נכנסת לכינוי (alias) של הישות, למשל
`CUSTOMER["לקוח"] { string name }`.

## ״צייר לי״

מתארים את התרשים במשפט (בעברית או באנגלית) ובוחרים **צייר לי**. מודל
במכשיר הזה כותב את ה־Mermaid, והוא מופיע בחלון כדי שתבדקו אותו לפני
ההוספה.

- זה רץ **רק על מודל מקומי**: Ollama במחשב הזה, או המודל שבדפדפן
  (הגדרות ← AI). הוא אף פעם לא משתמש בצ׳אט בענן, יהיה מצב ה־AI אשר
  יהיה, ולכן שום דבר לא יוצא מהמכשיר.
- התשובה חייבת להיות אחד מחמשת הסוגים שאפשר לערוך ולעבור את הבדיקה של
  Mermaid. אם לא, המודל מקבל את השגיאה ומנסה שוב, עד פעמיים.
- התוויות נשארות בשפה של הבקשה.

היעד: תרשים תקין ב־80% לפחות מ־20 בקשות בדיקה על מודל מקומי של 7B.
מודדים זאת עם `npm run eval:canvas-draw -- --model qwen2.5:7b`.
