היסטוריית הגרסאות מגינה עליכם מפני העריכות של עצמכם, אבל היא נמצאת באותו
דיסק כמו הכספת. **גיבויים** מעתיקים את כל הכספת למקום אחר, פעם ביום כל עוד
Lumen פתוח.

## הגדרה

⌘K ← *גיבויים…*, ואז בחרו אחת מהאפשרויות:

- **גיבוי לתיקייה או לכונן…** כותב ארכיון ‎`.tar` רגיל שכל כלי ארכיונים
  פותח.
- **גיבוי מוצפן לתיקייה או לכונן…** כותב ‎`.tar.age`, מוצפן ב-
  [age](https://age-encryption.org) למפתח גיבוי שנוצר בשבילכם. החלון מציג את
  המפתח (`AGE-SECRET-KEY-1…`) פעם אחת. שמרו אותו הרחק מהמכשיר הזה: בלעדיו אף
  אחד לא יכול לפתוח את הגיבוי, גם לא אתם. רק החצי הציבורי שלו נשמר.

תיקייה שהיא הכספת, או שנמצאת בתוכה, נדחית: גיבויים שם היו מסתנכרנים, וכל
גיבוי היה מכיל את הגיבויים שלפניו. הקבצים הפנימיים של git והאשפה לא מגובים.

## מה נשמר

הגיבוי החדש ביותר מכל אחד מ-**7 הימים**, **4 השבועות** ו-**6 החודשים**
האחרונים: לכל היותר 17 ארכיונים. הישנים יותר נמחקים אחרי כל גיבוי.

## כשמשהו לא בסדר

- גיבוי שנכשל (כונן שנותק, תיקייה שהדפדפן כבר לא מרשה ל-Lumen לכתוב אליה)
  מוצג מיד: הודעה, ושורה אדומה בחלון. Lumen מנסה שוב אחרי 15 דקות.
- **שלושה ימים** בלי גיבוי מוצלח מוצגים פעם ביום.

## שחזור

- **שחזור הכול לתיקייה חדשה…** מעביר את הקבצים של הגיבוי החדש ביותר לתיקייה
  שתבחרו.
- **שחזור לתוך הכספת** משחזר קובץ אחד או תיקייה אחת. שום דבר לא נדרס: קובץ
  שכבר קיים משוחזר לידו, בשם `name (restored 2026-11-10).md`.

כל ארכיון מתחיל ברשימה של הקבצים שבו וה-SHA-256 של כל אחד. שחזור בודק כל קובץ
ודוחה ארכיון פגום.

בלי Lumen:

```sh
tar -xf lumen-backup-2026-11-10T03-12-00Z.tar
age -d -i backup-key.txt lumen-backup-….tar.age | tar -x
```

## איך זה נבדק

`src/__tests__/backup.test.ts` מגבה 1,000 פתקים ו-200 קבצים מצורפים, מוחק את
הכספת ומשחזר אותה, רגיל ומוצפן: **לכל קובץ אותו SHA-256**. הוא בודק גם
שכונן תקול מדווח תוך דקה, ושגיבוי לא כותב כלום לתוך הכספת.
`e2e/backup-drill.spec.ts` מריץ את אותו תרגיל מהחלון בדפדפן.

## מגבלות

- כדי לכתוב לתיקייה, הדפדפן צריך את File System Access API (Chromium).
  הגישה לתיקיות של אפליקציית שולחן העבודה (Tauri) ויעדי WebDAV נמצאים
  מאחורי אותו ממשק `BackupTarget`, ויגיעו עם ה-PR שלהם.
- גיבויים רצים כל עוד Lumen פתוח, ולכן מחשב שתמיד סגור לא מקבל אף גיבוי.
  ההודעה על שלושה ימים אומרת את זה.
