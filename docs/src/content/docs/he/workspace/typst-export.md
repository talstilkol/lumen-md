[Typst](https://typst.app) היא שפת סדר מודרנית, חלופה ל-LaTeX עם תמיכה טובה
בכתיבה מימין לשמאל. **File ← Export to Typst (.typ)** כותב את הפתק הפתוח
כקובץ `.typ`. משורת הפקודה: `lumen convert note.md note.typ`.

## מה מקבלים

- פתק עברי מתחיל ב-`#set text(lang: "he")`, ולכן Typst פורש אותו מימין
  לשמאל. שפת המסמך היא הכתב שרוב האותיות שלו כתובות בו. `dir: ltr` או
  `dir: rtl` ב-frontmatter גוברים על זה.
- כל פסקה שומרת על הכיוון שלה. פסקה באנגלית בתוך פתק עברי עטופה
  ב-`#[#set text(dir: ltr) …]`, ולהפך בפתק באנגלית.
- כותרות, מודגש, נטוי, קוד, קישורים, רשימות מקוננות וממוספרות, תיבות סימון,
  טבלאות (עמודה 1 מימין בעברית), בלוקי קוד עם השפה שלהם, ציטוטים, הערות שוליים
  וה-`title` שב-frontmatter.
- **מתמטיקה:** המתמטיקה של Typst אינה LaTeX. שברים, שורשים, חזקות ואינדקסים,
  אותיות יווניות, יחסים, סכומים ואינטגרלים מתורגמים. כל נוסחה אחרת נשמרת
  כטקסט גולמי, כך ששום דבר לא יוצא שגוי בלי שתדעו.

## קומפילציה ל-PDF

```bash
typst compile note.typ
```

הקובץ מבקש את הגופנים *David CLM*, ‏*Noto Serif Hebrew* ו-*Libertinus Serif*,
בסדר הזה. Typst משתמש בראשון שהוא מוצא.

PDF ישירות מהאפליקציה, עם המהדר של Typst שרץ בדפדפן, עוד לא קיים. הוא צריך את
חבילת typst.ts, שעוד לא נמצאת במאגר.
