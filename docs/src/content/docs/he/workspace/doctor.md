פקודה: `🩺 Vault Doctor: Check Workspace` ‏(`⌘K`).

רופא הכספת קורא כל פתק Markdown בתיקיית סביבת העבודה הפתוחה ופותח דוח
בלשונית חדשה. הדוח מקשר לכל פתק שהוא מזכיר, כך שאפשר ללחוץ ישר ולתקן. הוא
רץ כולו במכשיר שלכם ולא קורא לשום AI.

| בדיקה | מה היא מוצאת |
|---|---|
| קישורי ויקי שבורים | `[[פתק]]` כשאין פתק כזה ואין כותרת כזו באותו פתק. כשיש בדיוק שם פתק אחד קרוב (אותן מילים, או עד שתי שגיאות הקלדה), הדוח מציע אותו. |
| כותרות חסרות | `[[פתק#כותרת]]` או `[[#כותרת]]` כשהכותרת לא קיימת. |
| קישורי Markdown שבורים | קישורים יחסיים לקובצי `.md` שלא קיימים. ‏`../` ו-`%20` מפוענחים. |
| שמות דו-משמעיים | שני פתקים עם אותו שם קובץ. ‏`[[שם]]` יכול לפתוח רק אחד מהם. |
| כמעט-כפולים | פתקים שהטקסט שלהם חופף בכ-80% או יותר (MinHash על רצפים של 5 מילים). |
| תמונות בלי טקסט חלופי | `![](…)` ו-`<img>` בלי `alt`. |
| פתקים ריקים | שום דבר מלבד front matter. |
| יתומים | פתקים שאף פתק אחר לא מקשר אליהם. ‏`index`,‏ `README`,‏ `home` ו-`welcome` לא נחשבים יתומים. |

קישורים בתוך בלוקי קוד וקוד בשורה מתעלמים מהם.

## החלת התיקונים המוצעים

פקודה: `🩺 Vault Doctor: Apply Suggested Link Fixes`.

הפקודה כותבת מחדש כל קישור ויקי שבור שיש לו הצעה אחת, למשל
`[[Projct Plan]]` ← `[[Project Plan]]`. התוויות וחלקי ה-`#כותרת` נשמרים.
קודם מקבלים רשימה של השינויים לאישור. פתקים שפתוחים בלשונית מדולגים, כך
ששינויים שלא נשמרו לא נדרסים לעולם.
