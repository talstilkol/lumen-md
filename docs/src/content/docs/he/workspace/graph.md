## הגרף

**גרף ידע** (בפלטת הפקודות) מציג כל פתק בכספת, וקו לכל `[[קישור]]` בין
שני פתקים.

- **כספות גדולות.** הגרף נבנה מהאינדקס של הכספת, כך שהפתקים לא נקראים שוב.
  הפריסה מחושבת ב-worker ברקע; התמונה מופיעה מיד ומתייצבת תוך שנייה-שתיים.
  הצמתים והקישורים מצוירים ב-WebGL, כך ש-10,000 פתקים ו-50,000 קישורים
  זזים ומתקרבים בחלקות. בזמן שמזיזים את התצוגה מצויר מדגם של הקישורים, וכולם
  חוזרים ברגע שעוצרים.
- **מסננים.** אפשר לצמצם את הגרף לפי **תגית** (כולל תגיות מקוננות: `project`
  משאיר גם את `project/active`), לפי **תיקייה** (ותת-התיקיות שלה), או לפי
  **מאפיין** ב-frontmatter: ‏`status=open`, או רק `status` לכל פתק שיש לו
  כזה.
- **קבוצות צבע.** אפשר לצבוע את הפתקים לפי התיקייה העליונה או לפי התגית
  הראשונה. המקרא מציג את שתים-עשרה הקבוצות הגדולות.
- **תוויות** מופיעות לפתקים הגדולים, ולעוד פתקים ככל שמתקרבים. שמות בעברית
  מעוצבים ונכתבים מימין לשמאל.

## הגרף המקומי

**הצגה / הסתרה של הגרף המקומי** פותחת חלונית ליד הפתק: הפתק הפתוח במרכז,
והפתקים שבמרחק **1, 2 או 3** קישורים ממנו. יש לה אותם מסנני תגית ותיקייה,
והיא צבועה לפי תיקייה. היא עוברת איתכם כשפותחים פתקים אחרים, ונפתחת בהרבה
פחות מחמישית שנייה.

## עם המקלדת

הגרף הוא אזור אחד שאפשר להתמקד בו. מגיעים אליו ב-Tab, ואז:

| מקש | מה עושה |
|---|---|
| ← ↑ → ↓ | מעבר לפתק המקושר בכיוון הזה (ואם אין כזה, לפתק הקרוב ביותר בכיוון הזה) |
| Enter | פתיחת הפתק שבמיקוד |
| + / − | הגדלה / הקטנה |
| 0 | התאמת כל הגרף |
| Shift + חיצים | הזזה |
| Home | חזרה לפתק הגדול ביותר (בגרף המקומי: הפתק הפתוח) |

השם של הפתק שבמיקוד ומספר הקישורים שלו מוקראים לקוראי מסך. בגרף המלא, תיבת
**חיפוש פתק** קופצת לכל פתק לפי שם, כך שאפשר להגיע לכל פתק בלי עכבר.
