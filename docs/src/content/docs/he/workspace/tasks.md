כל פריט ברשימת ביצוע, בכל פתק, הוא משימה. ‏Lumen קורא את הפורמט של
[תוסף Tasks ל-Obsidian](https://publish.obsidian.md/tasks/) ‏(MIT), כך
שפתקים שנכתבו בשבילו עובדים בלי שינוי.

```markdown
- [ ] לשלם ארנונה #בית ⏫ 📅 2026-11-01
- [ ] טיוטה לדוח ⏳ 2026-10-27 🛫 2026-10-25
- [x] להזמין טיסות ✅ 2026-10-20
- [ ] להשקות עציצים 🔁 every week 📅 2026-10-26
```

| סמל | משמעות |
|---|---|
| 📅 | תאריך יעד |
| ⏳ | מתוכנן ל- |
| 🛫 | תאריך התחלה |
| ➕ | נוצר |
| ✅ / ❌ | תאריך ביצוע / ביטול |
| 🔺 ⏫ 🔼 🔽 ⏬ | עדיפות: הגבוהה ביותר … הנמוכה ביותר |
| 🔁 | חזרה (נשמרת כטקסט) |
| 🆔 / ⛔ | מזהה משימה / תלויה ב- |

תווי מצב: `[ ]` פתוחה, `[x]` בוצעה, `[/]` בתהליך, `[-]` בוטלה.

## שאילתות

בלוק קוד מסוג `tasks` מציג את המשימות המתאימות מכל הכספת. סימון תיבה
בבלוק מעדכן את הפתק שממנו המשימה הגיעה.

````markdown
```tasks
not done
due before in 7 days
tags include #בית
sort by due
group by folder
```
````

ההוראות זהות לתוסף, באנגלית: `done`, `not done`, ‏`due … before/after/on`,
‏`priority is above none`, ‏`path includes …`, ‏`tags include …`, ‏`(a) OR (b)`,
‏`sort by`, ‏`group by`, ‏`limit`. תאריכים: `YYYY-MM-DD`, ‏`today`, ‏`tomorrow`,
‏`in 3 days`. הוראה ש-Lumen לא מבין מוצגת כשגיאה, ולא מושמטת בשקט.

## היום ובקרוב

לוח הפקודות ← **משימות: היום ובקרוב**. החלונית מציגה את המשימות שבאיחור
ושל היום, ואחריהן את 7 הימים הבאים.

## תזכורות

בחלונית הזו מפעילים **תזכורות**. כל עוד Lumen פתוח, כל משימה שהיעד או
התכנון שלה הוא היום מקבלת התראה אחת ביום: התראת הדפדפן, או התראת מערכת
ההפעלה באפליקציית שולחן העבודה. שום דבר לא יוצא מהמכשיר.

## מהירות

המשימות מאונדקסות יחד עם שאר הכספת ב-worker ברקע. שאילתה על 1,000 משימות
לוקחת פחות מ-100ms, ונבדקת בכל שינוי.
