שמים טבלה בפתק: בלוק ```` ```csv ````, טבלת Markdown או שורות מופרדות בפסיקים. מריצים `⌘K ← AI: ניתוח הטבלה` ושואלים, למשל „באיזה חודש היו הכי הרבה מקרי מוות ממחלה?” או „סך המכירות ב-2025?”.

## מה קורה

1. **תוכנית, לא ניחוש.** סוכן הניתוח כותב תוכנית Python 3 קצרה לשאלה. מותר לה להשתמש רק בספרייה הסטנדרטית (`csv`, `statistics`, `math`, `datetime`, `json`), והיא מקבלת את הטבלה כ-`inputs["csv"]`. בודק דוחה תוכנית שלא קוראת את הטבלה, שלא מדפיסה תשובה ב-JSON, או שמייבאת משהו מחוץ לרשימה הזאת (`random`, `time`, `os`, רשת…).
2. **ארגז החול.** התוכנית רצה בארגז החול של [`run_python`](/ai/local-agents/): Pyodide במכשיר, בלי רשת, בלי קבצי הכספת ועם מגבלת זמן.
3. **הרצה שנייה.** אותה תוכנית רצה שוב בארגז חול חדש. אם שתי התשובות שונות, או שאחת ההרצות נכשלה, לא מתקבלת תשובה: רק הסיבה.
4. **לתוך הפתק.** התשובה נוספת כציטוט, ואחריה בלוק ```` ```live-python ```` שמכיל את הטבלה ואת התוכנית. אפשר להריץ אותו שוב ולראות בדיוק איך המספר חושב. כשהתוכנית מחזירה נתוני תרשים, נוסף גם בלוק ```` ```chart ````.

המודל שכותב את התוכנית הוא המודל המקומי שלך (Ollama או המודל בדפדפן), לפי מדיניות ה-AI, כמו כל סוכן אחר. הטבלה נשלחת אליו כטקסט (12 השורות הראשונות, בשביל שמות העמודות) ולשום מקום אחר.

## איכות

`node scripts/golden/evals/data-analysis.mjs --dev` מריץ את שאלות הזהב דרך אותו מסלול של ארגז החול. היעד הוא לפחות 85% תשובות מספריות נכונות על 20 שאלות זהב, עם מודל אמיתי. המדידה הזאת היא של הבעלים (תוכנית 15.13).
