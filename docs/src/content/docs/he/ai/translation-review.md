description: הסוכן שבודק כל תרגום של ממשק Lumen מול המקור באנגלית — משתנים חסרים, אורך חריג, מחרוזות שלא תורגמו, ובמכונה הזו גם תרגום חוזר.

ממשק Lumen מתורגם לשבע שפות (ערבית, גרמנית, צרפתית, עברית, יפנית, רוסית,
סינית). `npm run i18n:review` בודק כל תרגום מול המקור באנגלית ומדפיס דוח:

| בדיקה | רמה | משמעות |
|---|---|---|
| משתנה חסר | שגיאה | `{placeholder}` מהאנגלית לא נמצא בתרגום — הממשק יאבד את הערך |
| משתנה עודף | שגיאה | `{placeholder}` שאין באנגלית — יוצג כמו שהוא |
| אורך | אזהרה | קצר או ארוך בהרבה מהאנגלית (ליפנית ולסינית גבולות משלהן) |
| לא תורגם | אזהרה | האנגלית מילה במילה (שמות מוצרים ופורמטים בסדר) |
| סטייה | אזהרה | עם `--back`: אחרי תרגום חוזר לאנגלית **במכונה הזו** (M2M100 דרך transformers.js — בלי ענן) יש מעט במשותף עם האנגלית (chrF מתחת ל-25) |
| מפתח חסר | מידע | אין עדיין תרגום; הממשק מציג אנגלית |

הפקודה יוצאת עם סטטוס 1 כשיש שגיאה כלשהי, והבדיקה
`src/__tests__/i18nReview.test.ts` מחזיקה את שבע השפות על **0 משתנים חסרים**.

```sh
node scripts/extract-i18n-keys.mjs          # קודם מרעננים את i18n/keys.json
npm run i18n:review -- --out review.md      # הדוח
npm run i18n:review -- --back --sample 200  # עם תרגום חוזר (מוריד את M2M100 פעם אחת)
```

ההרצה הראשונה תיקנה 34 משתנים חסרים — מחרוזות בשש שפות שנקטעו במירכאה
מוברחת (`git.alert.cloned`, `collab.prompt.join`, `tree.confirm.deleteFile`,
`tree.confirm.deleteFolder`) ו-`writingGoal.done` בגרמנית ובצרפתית בלי
המספרים שלו.
