כל פקודת AI ב-Lumen היא **סוכן**. הגדרת הסוכן קובעת מה לשאול את המודל,
באילו כלים מותר לו להשתמש, באיזו צורה התשובה צריכה להיות ואיך בודקים
אותה. זמן ריצה אחד (`src/agents/runtime.ts`) מריץ את כל ההגדרות: על
Ollama במחשב שלך, על מודל בדפדפן (WebGPU), או על ספק ענן כשמדיניות ה-AI
מתירה זאת.

## מה קורה כשסוכן נכשל

1. **סוכן השיפור** (המבקר) מאבחן את הכשל ומציע שינוי אחד לניסיון חוזר:
   טמפרטורה 0 יחד עם השגיאה של הבודק, ואחר כך מודל גדול יותר. עד שני
   ניסיונות חוזרים.
2. כשהניסיונות נגמרים, מודל מקומי קטן קורא את הכשל. הוא יכול להוסיף הצעה
   או שתיים בשפה פשוטה, וכשניסיון נוסף יכול לתקן את התשובה (פורמט, שפה או
   אורך לא נכונים), הוא נותן הוראה. זמן הריצה מבצע אז **ניסיון אחד נוסף**
   עם ההוראה הזאת.
3. לוח ההצעות נפתח מעצמו. זה קורה בכל פקודת AI, כולל מחקר, עבודות אצווה,
   חיפוש בכספת, בלוקי גרפים ועורך ה-WYSIWYG. לחיצה על הצעה מבצעת אותה,
   ואחר כך מריצה את הפקודה שוב:

| הצעה | מה הלחיצה עושה |
|---|---|
| הפעלת Ollama | בודקת כל שתי שניות אם Ollama עונה. כשהוא עונה, הפקודה רצה שוב; אחרי שתי דקות הבדיקה מפסיקה, וסגירת הלוח עוצרת אותה. |
| פיצול המסמך | מריצה את הסוכן על חלקים של כ-4000 תווים ומאחדת את התשובות. מוצעת לסוכנים שהתשובה שלהם על חלק שווה בערכה לתשובה על המסמך כולו: תגיות, משימות, תרגום, הגהה, קישורים. |
| סימון חלק | מוצגת לסוכנים שאי אפשר לפצל את התשובה שלהם, כמו תרשים או ראשי פרקים. סמנו את החלק הרצוי והריצו את הפקודה שוב. |
| הורדת המודל | מושכת את המודל ל-Ollama או טוענת אותו בדפדפן. |
| ניסיון חוזר עם … | מריצה את הפקודה שוב עם מנוע אחר או עם מודל גדול יותר. |
| לאפשר ענן כגיבוי | משנה את מדיניות ה-AI ל*מקומי קודם*. |
| הוספת מפתח | פותחת את *AI: Switch Provider*. |

## "לא טוב"

אחרי פקודה שמכניסה תשובה אחת לפתק (משימות, תרגום, תרשים, גרף, תגיות,
קישורים, ראשי פרקים, דקדוק, מחקר, פרופיל סגנון, הודעת commit), מופיע לכמה
שניות כפתור קטן **לא טוב — לנסות שוב**. לחיצה עליו מריצה את הפקודה שוב על
אותו קלט, בטמפרטורה גבוהה יותר ובמודל גדול יותר בדרגה אחת, והמודל מקבל את
התשובה שנדחתה. ביומן הסוכנים, הריצה החדשה מקושרת לריצה שהיא מחליפה
(`retryOf`).

כל ריצה נשמרת במכשיר: `⌘K → "AI: Recent Agent Runs"` מציג את המנוע, המודל,
הכלים, הניסיונות החוזרים והכשלים של 50 הריצות האחרונות.

התיעוד המלא (באנגלית): [Local agents](/ai/local-agents/).
