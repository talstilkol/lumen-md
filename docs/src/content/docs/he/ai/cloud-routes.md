ה-AI של Lumen רץ כברירת מחדל במכשיר הזה. פונים לשירות ענן רק אחרי
שבחרתם בו, ו**מדיניות ה-AI** (`⌘K → "AI: Local or Cloud Policy"`)
קובעת עד כמה הבחירה הזו מגיעה:

| מדיניות | מה יכול לצאת מהמכשיר |
|---|---|
| **מקומי בלבד** (ברירת המחדל בהתקנה חדשה) | כלום. כל מסלול ענן בטבלה למטה נדחה לפני שנשלחת בקשה; שכבת הרשת חוסמת אותו פעם נוספת ויומן הפרטיות מציג את הניסיון. |
| **מקומי קודם** | רק נפילה לספק ה-AI שאת המפתח שלו הזנתם, כשאף מנוע מקומי לא יכול לענות. שירותים שלא הגדרתם — ה-API הציבורי של LanguageTool, זיהוי הדיבור המקוון של הדפדפן, קולות הקראה בשרת — נשארים כבויים. |
| **ענן** | הספק שנבחר ישירות, והשירותים החיצוניים שבטבלה. |

התקנה שהוגדרה עם מפתח ענן לפני שהיו מדיניות מתחילה ב*מקומי קודם* (ועם
ספק ענן נבחר: *ענן*), כך ששדרוג לעולם לא משנה בשקט לאן הפרומפטים הולכים.
בחירה מפורשת של מדיניות גוברת.

## כל מסלולי הענן

לכל מסלול יש מזהה; הבדיקה `src/__tests__/cloudRoutes.test.ts` נכשלת כשקובץ
מקור פונה לשירות ענן בלי להופיע ברשימה הזו, או כשמסלול מאבד את השער שלו.

| יכולת | מזהה מסלול | במכשיר הזה | אפשרות ענן | מתי משתמשים בענן |
|---|---|---|---|---|
| שיחה, כתיבה, סוכנים | `chat-openai` | Ollama, ואחריו web-llm ‏(WebGPU) | OpenAI | הספק נבחר; נפילה ב*מקומי קודם* |
| שיחה, כתיבה, סוכנים | `chat-anthropic` | Ollama, ואחריו web-llm ‏(WebGPU) | Anthropic ‏(Claude) | הספק נבחר; נפילה ב*מקומי קודם* |
| שיחה, כתיבה, סוכנים | `chat-gemini` | Ollama, ואחריו web-llm ‏(WebGPU) | Google Gemini | הספק נבחר; נפילה ב*מקומי קודם* |
| שיחה, כתיבה, סוכנים | `chat-mistral` | Ollama, ואחריו web-llm ‏(WebGPU) | Mistral | הספק נבחר; נפילה ב*מקומי קודם* |
| embeddings לחיפוש חכם | `embeddings-openai` | מודל embedding ב-Ollama, אחרת multilingual-e5-small ‏(transformers.js) | OpenAI embeddings | רק ב*ענן* |
| עבודות אצווה | `batch-api` | תור האצווה המקומי | Batch API של OpenAI / Anthropic | רק ב*ענן* |
| כוונון עדין | `fine-tune` | פרופילי סגנון | כוונון עדין של OpenAI | מחוץ ל*מקומי בלבד*, כשמפעילים אותו |
| תמלול הקלטה קולית | `whisper-1` | Whisper בדפדפן ‏(transformers.js) | `whisper-1` של OpenAI | *ענן*; *מקומי קודם* כשהמודל המקומי נכשל |
| בדיקת דקדוק | `languagetool` | LanguageTool במכונה הזו, אחרת סוכן ההגהה המקומי | ה-API הציבורי של LanguageTool (או שרת LanguageTool מרוחק שהגדרתם) | API ציבורי: רק ב*ענן*; שרת משלכם: מחוץ ל*מקומי בלבד* |
| מחקר ברשת | `web-research` | הספרייה שלכם, או שירות מחקר במכונה הזו | חיפוש הרשת של Claude / שירות מחקר מתארח | מחוץ ל*מקומי בלבד*, אחרי ההסכמה החד-פעמית לרשת |
| הכתבה | `speech-recognition` | הקלטה קולית עם Whisper מקומי | זיהוי הדיבור של הדפדפן (Chrome שולח את השמע ל-Google) | רק ב*ענן* |
| הקראה | `network-voices` | הקולות של המערכת שרצים במכשיר | קולות דפדפן שרצים בשרת ("Google …") | רק ב*ענן* |
| תרשימי PlantUML | `plantuml-kroki` | — (עדיין אין מצייר מקומי) | ‏kroki.io מצייר את התרשים מהטקסט שלו | *ענן*; אחרת רק לתרשים שבחרתם לשלוח ("לצייר את התרשים הזה עם kroki.io") |

הורדות מודלים (Hugging Face, קבצי ה-OCR והמילונים) לא נושאות שום תוכן
שלכם; הן מופיעות ביומן הפרטיות וקורות רק כשיכולת צריכה את המודל.

## לבדוק בעצמכם

- `⌘K → "Privacy ledger"` מציג כל בקשת AI: שרת, גודל, מדיניות והאם
  היא הותרה או נחסמה.
- בדיקת הקצה-לקצה `e2e/local-only-all-commands.spec.ts` מריצה כל פקודת AI
  ב*מקומי בלבד* עם מפתחות ענן שמורים וספק ענן נבחר, ומצפה לאפס בקשות לכל
  שרת ענן.
