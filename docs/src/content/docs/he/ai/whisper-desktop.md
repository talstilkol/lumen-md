**לוח הפקודות ← 🎙 תמלול קובץ שמע (עם חותמות זמן).** בוחרים קובץ שמע או
וידאו. Lumen מתמלל אותו **במכשיר** ומכניס את התמלול במקום הסמן:

```md
### ישיבת-צוות.m4a

[▶ 0:00](<attachments/2026-11-10-ישיבת-צוות.m4a#t=0,6>) בוקר טוב לכולם.
[▶ 0:06](<attachments/2026-11-10-ישיבת-צוות.m4a#t=6,14>) היום נעבור על התקציב.
```

משפט אחד בכל שורה. כל זמן הוא קישור שמנגן את ההקלטה מאותה נקודה. ההקלטה
נשמרת ב-`attachments/` כשסביבת העבודה זמינה; בלעדיה הזמנים מופיעים כטקסט
רגיל.

## איזה מנוע מתמלל

| איפה | מנוע | מתי |
|---|---|---|
| אפליקציית שולחן העבודה, עברית | ivrit.ai Whisper large-v3-turbo (ggml) ב-**whisper.cpp** | אחרי שהוא מותקן (למטה) |
| דפדפן, עברית | ivrit.ai Whisper turbo (ONNX, WebGPU) | מעבד גרפי עם f16 ומספיק זיכרון |
| בכל מקום | Whisper base (WASM) | אחרת, וגם לשפות אחרות |

ההכתבה החיה ממשיכה להשתמש במודל העברי הזורם (Zipformer): הטקסט מופיע בזמן
שמדברים. ל-Whisper פונים בקבצים, שבהם הדיוק חשוב יותר ממהירות המילה
הראשונה. בעברית השפה נקבעת מראש, ולא מנוחשת.

שום דבר לא נשלח לשום מקום. בשולחן העבודה ההקלטה נכתבת לקובץ זמני במחשב,
`whisper-cli` קורא אותו, והקובץ נמחק. אחרי שהמודל נמצא בדיסק, התמלול לא
שולח שום בקשת רשת.

## התקנת המנוע לשולחן העבודה

Lumen לא כולל את המודל (כ-1.6 GB) ולא את התוכנה. מתקינים את שניהם פעם אחת:

1. **whisper.cpp** (MIT) — ב-macOS: `brew install whisper-cpp`, שמתקין את
   `whisper-cli`. Lumen מוצא אותו ב-`PATH`, בתיקיית `whisper` של האפליקציה,
   או בנתיב שבמשתנה הסביבה `LUMEN_WHISPER_CLI`.
2. **קובץ המודל** — ה-Whisper large-v3-turbo העברי של ivrit.ai בפורמט ggml
   (Apache-2.0), לתיקיית `whisper` של האפליקציה:
   - macOS: `~/Library/Application Support/app.lumen.editor/whisper/`
   - Windows: `%APPDATA%\app.lumen.editor\whisper\`
   - Linux: `~/.local/share/app.lumen.editor/whisper/`

Lumen משתמש רק בקובץ המדויק שהוא נבנה עבורו. הוא בודק את הגודל ואת ה-checksum
(SHA-256) לפני כל שימוש, ומתעלם מכל קובץ אחר. אם משהו חסר, הפקודה אומרת זאת
ומשתמשת במנוע שבדפדפן.

:::note
קובץ המודל עוד לא נעוץ בגרסה הזו: עדיין צריך למלא את המאגר המדויק ב-Hugging
Face, את ה-revision ואת ה-checksum (`npm run whisper:desktop -- pin` מסביר איך).
עד אז המנוע לשולחן העבודה לא מוצע, וקבצים מתומללים בדפדפן.
:::

## דיוק ומהירות (למפתחים)

```sh
npm run whisper:desktop -- wer --split test=<תיקייה עם fleurs.json> --model <קובץ ggml>
```

הפקודה מדפיסה WER ו-CER על קטעי המבחן בעברית (FLEURS, Common Voice), באותו
נרמול כמו בהכתבה החיה. היא מדפיסה גם את המהירות: יחס הזמן-אמת (RTF) וכמה
דקות לוקחת שעת שמע. היעדים הם WER ≤ 10% על FLEURS-he test, ופחות מ-10 דקות
לשעת שמע ב-Mac M1.
