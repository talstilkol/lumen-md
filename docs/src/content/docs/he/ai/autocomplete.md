`⌘K → "AI: Local Autocomplete (FIM) — On/Off"` מפעיל השלמות תוך כדי הקלדה.
אחרי הפסקה של 150 ms מהקשה, הטקסט **שלפני הסמן ושאחריו** נשלח למודל מקומי
שממלא את האמצע; התשובה מופיעה באפור במקום הסמן. **Tab** מאשר, **Esc** מבטל,
וההקשה הבאה מבטלת בקשה שעדיין רצה.

## איפה זה רץ

| מנוע | מתי | מודל |
|---|---|---|
| ‏Ollama ‏`/api/generate` עם `suffix` | יש Ollama במכונה הזו או ברשת עם מודל השלמה | `qwen2.5-coder:1.5b`, אחרת `qwen2.5-coder:7b` ‏(Apache-2.0) |
| המודל שבדפדפן (web-llm) | אין Ollama כזה, ומודל בדפדפן כבר טעון בלשונית הזו | המודל הטעון, דרך הסוכן `completer` |
| — | אף אחד מהם | אין השלמה (הקשה לעולם לא מתחילה הורדת מודל) |

אין מסלול ענן: ההשלמה לעולם לא פונה לספק ענן, באף מדיניות AI, ו-Ollama בשרת
מרוחק לא משמש. `qwen2.5-coder:3b` לעולם לא נבחר אוטומטית — הרישיון שלו (Qwen
Research) אינו פתוח. כדי להשתמש במודל מותקן אחר, הגדירו את `lumen.fim.model`
באחסון המקומי של הדפדפן.

מתקינים את המודל המומלץ פעם אחת:

```sh
ollama pull qwen2.5-coder:1.5b
```

## מהירות

תשובות נשמרות במטמון לפי ההקשר (אותו טקסט סביב הסמן פעמיים נענה מיד), והמודל
נשאר טעון בין הקשות. ההשהיה של כל השלמה נשמרת; ה-p50 / p95 שלה נכנסים ליומן
הסוכנים (`⌘K → "AI: Recent Agent Runs"`, הסוכן `fim`) לכל היותר כל 30 שניות.

`npm run bench:fim` מודד אותה על ה-Ollama שלכם: 20 הקשרים באנגלית, בעברית
ובקוד × 3 סבבים אחרי חימום, ומדפיס p50 / p95 (`--assert 300` נכשל כשה-p50
אינו מתחת ל-300 ms, היעד).
