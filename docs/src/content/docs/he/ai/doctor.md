פותחים ב-`⌘K ← AI: Doctor`. כל שורה מראה מה הרופא מצא, וכל שורה שאינה תקינה נותנת גם את התיקון: פקודה להעתקה, כפתור שמבצע את התיקון, או קישור. הבדיקות רק קוראות מצב. אף אחת מהן לא מורידה מודל או שולחת את הפתקים שלך לשום מקום.

## מה נבדק

| שורה | תקין כש- | התיקון כשלא |
|---|---|---|
| מדיניות AI ומנוע מועדף | תמיד (הקשר) | — |
| שרת Ollama נגיש | `/api/version` עונה | התקנה / `ollama serve`; `OLLAMA_ORIGINS` כשמתקבל 403; בנייה מחדש עם הכתובת מותרת כשה-CSP חוסם |
| מודלים: שיחה, מוגדר, קריאת כלים, embeddings | מותקנים | `ollama pull …` (כפתור: *להוריד עכשיו*) |
| WebGPU, WebAssembly | זמינים | Ollama, או דפדפן עם WebGPU |
| אחסון הכספת | יש מקום, קבוע | *לשמור את הנתונים שלי* |
| Service worker | רשום | — |
| **CSP לשירותים המקומיים** | הדף יכול להתחבר לפורטים 8010 ו-8787 | בנייה מחדש עם `VITE_CSP_CONNECT_EXTRA` |
| דקדוק (LanguageTool), מחקר | עונים | `docker compose -f docker/local-ai.yml up -d`; *שימוש בשירותים המקומיים* מכוון את שניהם לקובץ הזה |
| **אירוח המודלים המומרים** (Opus-MT, Nakdimon) | הוגדר אירוח והרישום מפרט את הקבצים | מחכה לבחירת האירוח של הבעלים (תוכנית 15.9), ואז ה-workflow של ההמרה |
| **תרגום מקומי** | המתרגם של Chrome או Opus-MT יכולים לתרגם אנגלית↔עברית | M2M100 יורד בשימוש הראשון באישור, או Chrome |
| **איות אנגלית** | המילון המובנה מסמן שגיאת כתיב ידועה | טעינה מחדש |
| **מילון איות עברי** | Hspell מותקן | *הורדה (5.7 MB)* |
| **ניקוד** | Nakdimon מתארח | כמו אירוח המודלים המומרים |
| **תיאור תמונות** | תמיד זמין (הורדה באישור בשימוש הראשון) | — |
| מנוע שהסוכנים יכולים להשתמש בו | יש אחד זמין | `ollama serve` או הגדרות ה-AI |

*הרצת מקרה זהב לכל סוכן* מריצה קריאה אמיתית למודל עבור כל סוכן שיש לו מקרה זהב. סוכנים בלי מקרה מופיעים כ*דולג*, כך שרואים מה חסר.

## שירותים מקומיים

`docker/local-ai.yml` מפעיל את LanguageTool בפורט 8010 ואת שירות המחקר בפורט 8787. ה-CSP של בניית הייצור כבר מתיר את שניהם (`http://localhost:8010`, `http://localhost:8787`), והרופא בודק שהבנייה שרצה אצלך עדיין מתירה אותם.
