החיפוש הסמנטי והקישורים המוצעים תלויים ב*מודל embeddings*. ב-2026 יצאו שלושה
מודלים קטנים ורב-לשוניים ברישיון פתוח, וסט השאלות הישן לא הבדיל ביניהם: חיפוש
מילים רגיל (BM25) כבר קיבל עליו ציון מושלם של 1.0.

## הסט הקשה

300 שאלות עבריות מ-HeQ, כל אחת בניסוח שאנשים באמת שואלים:

| שכתוב | דוגמה |
| --- | --- |
| פרפרזה | `מתי נולד` ← `באיזו שנה נולד` |
| נטייה | תחילית שנוספה או ירדה (`ו ה ב ל מ ש כ`), רבים ↔ יחיד |
| כתיב | מלא ↔ חסר |
| ראשי תיבות | `צה״ל` ↔ `צבא ההגנה לישראל` |
| מילה לועזית | `מחשב` ↔ `קומפיוטר`, `תוכנה` ↔ `software` |

30% מהשאלות מוחזקות בצד ומשמשות רק להחלטה הסופית. גם השאלות חוצות-השפות של
הבדיקה מעברית לאנגלית נמדדות.

הסט הוא **סינתטי**: השכתובים נעשו לפי כללים בשביל הפרויקט הזה, השאלות
חוצות-השפות נכתבו בשבילו, והשאלות המוחזקות בצד נמצאות בריפו. לכן הוא יושב
ב-`eval/synthetic/retrieval-hard` ולא עם סטי הזהב, וכל תוצאה עליו היא תוצאת
פיתוח. הוא יכול לבחור בין מודלים, אבל לא להוכיח לבדו טענת איכות.

## המועמדים והכללים

המועמדים הם multilingual-e5-small (המודל הנוכחי), ‏EmbeddingGemma 2 (גם בחיתוך
ל-256 ממדים, שמקטין בחצי את האינדקס של כספת גדולה), ‏Qwen3-Embedding-0.6B,
וכ-reranker ‏Qwen3-Reranker-0.6B. לכל אחד נמדדים nDCG@10, ‏Recall@20, זמן
לשאילתה, גודל הורדה וגודל אינדקס.

- הסט תקף רק אם הוא מפריד בין המודל הטוב לגרוע ב-5 נקודות nDCG@10 לפחות.
- ברירת המחדל מתחלפת רק בשיפור של **5 נקודות** לפחות על החלק המוחזק, ורק אם
  שאילתה לוקחת עד **150ms** על 10,000 פתקים במחשב בינוני.
- ה-reranker נדלק רק אם הוא מוסיף **3 נקודות** לפחות; אחרת הוא נשאר כבוי.
- כל מודל צריך רישיון שנבדק, ‏sha256 ומראה לפני ש-Lumen מוריד אותו.

## מהריצה לאפליקציה

ריצה משנה את האפליקציה רק דרך הקליטה (ingest):

```bash
npm run eval:embed-compete      # כותב eval/results/embed-compete-<date>.json
npm run eval:embed-ingest       # שופט אותה, ואז כותב src/ai/embeddingDefault.json
```

הקליטה מקבלת ריצה רק כשכל שורה נמדדה גם על חלק הפיתוח וגם על החלק המוחזק,
וההחלטה נוקבת בברירת מחדל ובסיבה שלה. המנצח הופך למודל החיפוש רק כשארבעת
התנאים מתקיימים:
- כרטיס ההערכה של הריצה מתויג `heldout` או `public`, על סט שאינו סינתטי
  (ריצה על `eval/synthetic/retrieval-hard` לבדה לעולם לא משנה את המודל:
  המספרים שלה, גם של החלק המוחזק, נרשמים כמספרי פיתוח, ו-`src/ai/embeddingDefault.json`
  נשאר כמו שהוא);
- הסט הפריד בין המודלים;
- הרישיון של המודל נבדק;
- לקבצים שלו יש sha256.

אחרת נשאר multilingual-e5-small. מנצח ב-256 ממדים (`embeddinggemma-2@256`)
משמש בגודל הזה: 256 הערכים הראשונים, מנורמלים מחדש. האינדקס רושם את המודל
ואת הגודל, כך ששינוי של אחד מהם בונה אותו מחדש. ‏`--check` שופט ריצה בלי
לכתוב דבר.
