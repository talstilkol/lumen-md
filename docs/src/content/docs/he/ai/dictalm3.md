[DictaLM 3.0](https://arxiv.org/abs/2602.02104) היא משפחת המודלים הפתוחה של
Dicta לעברית ולאנגלית, עם קריאה לכלים (tool calling) והקשר של 65 אלף טוקנים.
יש לה שלושה גדלים, וכל אחד מהם הותאם ממודל בסיס אחר:

| גודל | מודל בסיס | רישיון | ב-Lumen |
|---|---|---|---|
| 1.7B | Qwen3-1.7B | Apache-2.0 (נבדק) | בקטלוג המודלים; מורידים אותו לפי שם ב*הגדרות AI* (Ollama): `hf.co/dicta-il/DictaLM-3.0-1.7B-Thinking-GGUF`. עדיין לא מוצע כברירת מחדל |
| 12B | NVIDIA Nemotron Nano V2 | **עוד לא נבדק** | לא מוצע |
| 24B | Mistral-Small-3.1 | **עוד לא נבדק** | לא מוצע |

מודל מוצע רק אחרי שהרישיון שלו נבדק בשער הרישיונות (`npm run licenses`).
הרישיון של המשקלות של 12B ו-24B והמאגרים המדויקים שלהם עוד לא נבדקו, ולכן
הם לא מופיעים באף רשימה; ב-`models/registry.json` הם רשומים כ-*unknown*.

## מתי הוא הופך לברירת המחדל

DictaLM 3.0 מחליף את המודל העברי ש-Lumen מציע היום רק אם הוא משיג
**לפחות 5 נקודות יותר** ב-eval של הסוכנים וב-eval של ההנחיות בעברית,
כשמודדים במחשב שלך:

- את 1.7B משווים ל-`qwen3:4b` (מה ש-Lumen מציע במחשב עם 4 GB).
- את 12B ו-24B משווים ל-`qwen3:14b`.

מודל שהרישיון שלו מותאם אישית (לא רישיון פתוח) מוצע עם הודעת הרישיון שלו,
אבל אף פעם לא הופך לברירת מחדל.

## הרצת ההשוואה (למפתחים)

הגדלים והבדיקות הפתוחות שלהם נמצאים ב-`models/dictalm3.json`.

```sh
npm run dictalm3                         # כל גודל, הרישיון שלו והבדיקות הפתוחות
npm run dictalm3 -- eval --size 1.7B     # eval לשני המודלים עם Ollama ← eval/results/
npm run dictalm3 -- decide --json eval/results/dictalm3-decision.json
```

`eval` מסרב להריץ גודל כל עוד יש לו בדיקה פתוחה: המאגר, ה-commit שנבדק,
השם ב-Ollama והרישיון. `decide` מדפיס לכל גודל *blocked*, *no results*,
*keep*, *offer* או *switch*, ואת שורת הקטלוג שצריך להוסיף ל-`src/ai/modelCatalog.ts`
כשיש כזו.
