`AI: Batch over a Folder…` מתייג, מסכם או מתרגם כל פתק בתיקייה. במדיניות
*מקומי בלבד* ו*מקומי קודם* המשימה רצה במכשיר הזה (Ollama או המודל שבדפדפן),
פתק אחד בכל פעם ברקע; במדיניות *ענן* עם OpenAI או Anthropic היא נשלחת ל-Batch
API שלהם בחצי מחיר (ראו [עלות AI](/he/ai/cost/)).

## חלונית משימות האצווה

`⌘K → "AI: Batch Jobs — Progress, Pause, Resume"` (נפתחת גם מעצמה אחרי שליחת
משימה מקומית) מציגה כל משימה שעוד לא הוחלה:

| מה רואים | מה זה אומר |
|---|---|
| פס התקדמות ו-"*n* מתוך *סה״כ* הושלמו · *k* נכשלו" | חי, אחרי כל פתק |
| "נותרו בערך …" | הזמן הממוצע של הפתקים האחרונים × הפתקים שנשארו |
| **השהיה** | הפתק שבעבודה נעצר (ירוץ שוב ב"המשך") ושום פתק אחר לא מתחיל. ההשהיה נשמרת: אחרי רענון או הפעלה מחדש המשימה עדיין מושהית, ו-"AI: Check Batch Jobs" לא מפעיל אותה מחדש. |
| **המשך** | ממשיך מהפתק הראשון שאין לו תשובה — פתק שכבר נענה לא נשלח שוב |
| **ביטול המשימה** | עוצר את המשימה (משימת ענן מבוטלת אצל הספק); אף תוצאה שלה לא מוחלת |
| "ממתין למודל מקומי" | לא היה Ollama ולא מודל בדפדפן; "המשך" ינסה שוב |
| **החלת התוצאות** | כשהמשימה הסתיימה: אותה בדיקה כמו "AI: Check Batch Jobs" — פתקים הפתוחים בלשונית מדולגים ומאשרים לפני שנכתב משהו |

## כל תשובה נבדקת

לכל משימה יש מאמת לפי סוג הפעולה, ותשובה שנכשלת עוברת למבקר של זמן הריצה של
הסוכנים, שמנסה שוב פעם אחת עם הסיבה כרמז:

| פעולה | התשובה צריכה להיות |
|---|---|
| תיוג | מערך JSON (או רשימה מופרדת בפסיקים) של 1–10 תגיות קצרות |
| סיכום | משפט או שניים פשוטים — בלי כותרות, רשימות או ציטוטים, וקצר מהפתק |
| תרגום | לא טקסט המקור עצמו, ובאורך סביר (לא שבריר מהפתק ולא פי שלושה ממנו) |

פתק שהתשובה שלו עדיין נכשלת נספר כ*נכשל* עם הסיבה — מופיע תחת "תשובות שנדחו"
בחלונית — ולעולם לא נכתב.
