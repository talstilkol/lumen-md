מפעילים **פקודה קולית** מלוח הפקודות, ואז אומרים פקודה אחת. Lumen
מקשיבה למשפט אחד (עד 8 שניות), מזהה אותו במודל ההכתבה שבמכשיר, ומריצה
את הפקודה המתאימה. שום דבר לא נשלח לשום מקום: מודל הדיבור הוא זה
שההכתבה כבר הורידה, והפקודה מזוהה מול רשימה קבועה של ביטויים.

בפעם הראשונה, מפעילים הכתבה פעם אחת כדי להוריד את המודל (74 MB).

## מה אפשר לומר

| אומרים (עברית / אנגלית) | מה קורה |
|---|---|
| ״צור פתק חדש בשם…״ / "new note called…" | פתק חדש, עם השם ככותרת |
| ״חפש…״ / "search for…" | החיפוש נפתח עם המילים שלך בתיבה |
| ״הוסף משימה…״ / "add a task…" | שורת משימה עם תיבת סימון בתיבת הלכידה |
| ״פתח את הפתק היומי״ / "open the daily note" | הפתק של היום |
| ״הקרא״ / "read aloud", ״הפסק להקריא״ / "stop reading" | מקריאה את הפתק, או מפסיקה |
| ״לכידה מהירה״ / "quick capture" | חלון הלכידה המהירה |
| ״פתח משימות״ / "show my tasks" | חלונית המשימות |
| ״מחק את הפתק״ / "delete this note" | שואלת קודם, ואז מעבירה את הפתק לאשפה |
| ״שמור״ / "save" | שומרת |
| ״סכם״ / "summarize", ״תרגם״ / "translate" | הסיכום או התרגום של ה-AI |
| ״הכתבה״ / "start dictation" | הכתבה |
| ״מצב כהה״ / "dark mode" | מחליפה ערכת נושא |
| ״הגדרות״ / "settings", ״לוח שנה״ / "calendar", ״תצוגת גרף״ / "graph view" | פותחת אותם |
| ״תוכן עניינים״ / "outline", ״קישורים חוזרים״ / "backlinks" | החלוניות שבצד |
| ״בדוק דקדוק״ / "check grammar" | בדיקת הדקדוק |

אפשר לומר ״בבקשה״ או ״אממ״, להתחיל ב״היי לומן״, ו-״ו״ שצמודה למילה
הראשונה לא מפריעה. משפט רגיל (״שמור את זה בצד לבינתיים״) לא מריץ כלום,
כי פקודה צריכה להיות המשפט כולו.

## איך מודדים

רשימת הביטויים נכתבה מול 200 פקודות דבורות, 10 לכל פקודה, בעברית
ובאנגלית. היא מזהה נכון את כל ה-200, ולא מריצה כלום על 20 משפטים
רגילים. מכיוון שהרשימה נכתבה בשביל אותן 200, זו לא בדיקה אמיתית.
הבדיקה האמיתית היא 200 פקודות **מוקלטות** בידי דוברים שונים, שעוברות
דרך מודל הדיבור:

```sh
npm run eval:voice-commands -- --script > commands.json   # 200 המשפטים להקראה
npm run eval:voice-commands -- --dir <תיקייה עם commands.json וההקלטות>
```

היעד הוא 90% זיהוי נכון לפחות. אותה ריצה היא שלב ב-`npm run models:day -- --voice-dir <תיקייה>`.
