החיפוש מדרג ב-BM25 (ובחיפוש החכם גם ב-embeddings). **מדרג מחדש** מסדר אחר כך
את המועמדים הטובים ביותר מחדש, כשהוא קורא את השאילתה ואת כל מועמד יחד.
ב-Lumen יש שניים, ו**אף אחד מהם לא פועל כברירת מחדל**: ברירת המחדל היא סדר
BM25, כי הוא זה שנמדד כטוב ביותר (למטה).

| מדרג | איפה | ברירת מחדל |
|---|---|---|
| בלי (סדר BM25) | בכל מכשיר | **ברירת המחדל** |
| מובנה (מילולי) | בכל מכשיר; כיסוי מילים מותאם לעברית, משולב עם דירוג האחזור; בלי הורדה | כבוי; הגדרה להפעלה (`lumen.ai.rerank` = `lexical`) |
| מודל: ‏`bge-reranker-v2-m3` ‏(Apache-2.0) | רק בדפדפנים עם WebGPU ובאפליקציית שולחן העבודה; הורדה חד-פעמית של כ-571 MB ‏(q8), אחרי שאתם מסכימים | כבוי; הפקודה „AI: דירוג חיפוש עם המודל המקומי” |

`jina-reranker-v2` לא משמש (הרישיון שלו אוסר שימוש מסחרי), ומדרגי mMiniLM
לא מכסים עברית.

## המדידה

על סט הזהב לאחזור (תוכנית 7.1, `eval/golden/retrieval`), חלק הפיתוח של HeQ
— 12 שאלות בעברית על 238 פסקאות, 20 מועמדי BM25 לכל אחת, nDCG@10:

| | nDCG@10 |
|---|---|
| ‏BM25 לבד | 1.0000 |
| ‏BM25 + המדרג המובנה | 1.0000 |

‏BM25 כבר מציב כל תשובה ראשונה בחלק הזה, ולכן שום מדרג לא יכול להראות שם
שיפור. החלק הזה לא יכול לשמש בסיס להחלטה.

על **הסט הקשה** (`eval/synthetic/retrieval-hard`, סט סינתטי, ולכן אלה מספרי פיתוח: שאלות מבחן אמיתיות של HeQ ששונו
בכתיב, בניסוח ובסדר המילים, על אותן 238 פסקאות) ‏BM25 מתחת לתקרה, והמדרג
המובנה **מוריד** את התוצאה:

| | פיתוח (210 שאלות) | מוחזק (90) |
|---|---|---|
| ‏BM25 לבד | 0.9500 | 0.9521 |
| ‏BM25 + המדרג המובנה | 0.9184 (‎−3.2) | 0.9072 (‎−4.5) |

לכן **BM25 לבד הוא ברירת המחדל**, והמדרג המילולי הוא הגדרה שמפעילים לבד.
`src/__tests__/rerankHard.test.ts` מודד את שניהם מחדש בכל הרצה ונכשל אם ברירת
המחדל היא לא המנצח.

מודל הדירוג מחדש (bge-reranker-v2-m3) **עוד לא נמדד** על הסט הזה; צריך בשביל
זה את המודל. הוא יכול להפוך לברירת המחדל רק אחרי מדידה על Mac בסט הזה שעוברת
את BM25 ב-**3 נקודות nDCG לפחות גם בחלק הפיתוח וגם בחלק המוחזק**, ונרשמת בקבלת
הערכה (`eval/results/rerank-<date>.json`, שרושמת את המכונה):

```sh
LUMEN_EVAL_RERANK_DIRS=eval/synthetic/retrieval-hard npm run eval:rerank
```

המודל מוצע רק היכן שהוא רץ מהר, אחרי הסכמה. החלק הבין-לשוני (Belebele — שאלה באנגלית על
פסקאות בעברית, שם BM25 לא מתאים ומדרג עשוי לעזור) וחלק המבחן המוחזק נמדדים עם
המודל כך:

```sh
npm run eval:rerank
# עם חלק המבחן ו-Belebele בנויים:
LUMEN_EVAL_RERANK_DIRS=eval/golden/retrieval/dev,<test split dir> npm run eval:rerank
```

הפקודה כותבת את `eval/results/rerank-<date>.md` עם BM25, ‏BM25 + המודל והשיפור
לכל חלק, ואת ההחלטה שהכלל של התוכנית נותן (פחות מ-5 נקודות: כבוי כברירת מחדל).
