החיפוש מדרג ב-BM25 (ובחיפוש החכם גם ב-embeddings). **מדרג מחדש** מסדר אחר כך
את המועמדים הטובים ביותר מחדש, כשהוא קורא את השאילתה ואת כל מועמד יחד.
ב-Lumen יש שניים:

| מדרג | איפה | ברירת מחדל |
|---|---|---|
| מובנה (מילולי) | בכל מכשיר; כיסוי מילים מותאם לעברית, משולב עם דירוג האחזור; בלי הורדה | פועל |
| מודל: ‏`bge-reranker-v2-m3` ‏(Apache-2.0) | רק בדפדפנים עם WebGPU ובאפליקציית שולחן העבודה; הורדה חד-פעמית של כ-571 MB ‏(q8), אחרי שאתם מסכימים | **כבוי** |

`jina-reranker-v2` לא משמש (הרישיון שלו אוסר שימוש מסחרי), ומדרגי mMiniLM
לא מכסים עברית.

## המדידה

על סט הזהב לאחזור (תוכנית 7.1, `eval/golden/retrieval`), חלק הפיתוח של HeQ
— 12 שאלות בעברית על 238 פסקאות, 20 מועמדי BM25 לכל אחת, nDCG@10:

| | nDCG@10 |
|---|---|
| ‏BM25 לבד | 1.0000 |
| ‏BM25 + המדרג המובנה | 1.0000 |

‏BM25 כבר מציב כל תשובה ראשונה בחלק הזה, ולכן שום מדרג לא יכול להוסיף את 5
הנקודות שהתוכנית דורשת: **מודל הדירוג מחדש נשאר כבוי כברירת מחדל**, ומוצע רק
היכן שהוא רץ מהר, אחרי הסכמה. החלק הבין-לשוני (Belebele — שאלה באנגלית על
פסקאות בעברית, שם BM25 לא מתאים ומדרג עשוי לעזור) וחלק המבחן המוחזק נמדדים עם
המודל כך:

```sh
npm run eval:rerank
# עם חלק המבחן ו-Belebele בנויים:
LUMEN_EVAL_RERANK_DIRS=eval/golden/retrieval/dev,<test split dir> npm run eval:rerank
```

הפקודה כותבת את `eval/results/rerank-<date>.md` עם BM25, ‏BM25 + המודל והשיפור
לכל חלק, ואת ההחלטה שהכלל של התוכנית נותן (פחות מ-5 נקודות: כבוי כברירת מחדל).
