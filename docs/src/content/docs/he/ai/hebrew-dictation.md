ההכתבה רצה במכשיר שלך. השמע לא יוצא ממנו, אלא אם שולחים אותו למחשב
שלך ברשת המקומית (בהמשך).

## איזה מודל, מתי

| מצב | מודל | גודל | רישיון |
|---|---|---|---|
| הכתבה חיה, בזמן הדיבור | Zipformer2 של ivrit.ai, הזרמה (WASM) | 72 MB | CC BY 4.0 |
| כל משפט שהסתיים, ב-GPU עם WebGPU ו-f16 | Whisper large-v3-turbo של ivrit.ai | כ-563 MB | Apache-2.0 |
| כל משפט שהסתיים, בלי WebGPU או בטלפון | עדיין אין: טקסט ההזרמה נשאר, או שהמחשב שלך קורא אותו מחדש (בהמשך) | | |
| קובץ שמע או הקלטה בעברית | turbo ב-GPU חזק, אחרת whisper-base / small | | |

**Ozen v1 כבוי בינתיים.** המשקלות שלו ברישיון Apache-2.0, אבל כרטיס
המודל מציין נתוני אימון (imvladikon/hebrew_speech_kan) שלא מצהירים על
רישיון. Lumen נותנת רק מודל דיבור שהרישיון שלו נבדק, ולכן Ozen כבוי עד
שזה יתברר.

**הכתבה חיה מזרימה קודם, ואז מתקנת.** בזמן שמדברים, מודל ההזרמה מציג
טקסט מיד. כשעוצרים, השמע של המשפט עובר דרך Whisper, והתוצאה נכנסת
במקום הטקסט. זה קורה רק אם היא מגיעה תוך 2 שניות ונקראת כאותו משפט.
אחרת נשאר טקסט ההזרמה, כך שמעבר שני איטי או מבולבל לא מאבד את המילים
שלך.

**שום דבר לא יורד בזמן הכתבה.** המעבר השני משתמש במודל רק אם הוא כבר
במכשיר. כדי לקבל אותו, מתמללים קובץ עברי אחד: turbo ב-GPU מתאים.

## שליחה למחשב שלי

בטלפון, הכתבה בעברית מריצה רק את מודל ההזרמה, והוא טועה בכ-23.6%
מהמילים ב-FLEURS-he: מעל היעד של 15%. אם הטלפון מקושר למחשב שלך
ב[סנכרון ברשת המקומית](/he/sync/lan/), חלון ההכתבה מציע **שליחה למחשב
שלי**:

- Lumen מציעה את זה רק כשההכתבה במכשיר הזה מעל 15% (מספר שנמדד בו, או
  המספר שנמדד למודלים שהוא מריץ) ויש במחשב מודל גדול יותר מוכן: Whisper
  באפליקציית המחשב ([Whisper בשולחן העבודה](/he/ai/whisper-desktop/)), או
  ה-turbo של ivrit.ai שכבר נמצא בדפדפן שלו.
- לוחצים, וכל משפט שמסיימים נשלח למחשב, מתומלל שם, והטקסט חוזר לפתק.
  טקסט ההזרמה עדיין מופיע בזמן הדיבור.
- **הכל נשאר ברשת שלך.** השמע עובר רק בקישור הרשת המקומית בין שני
  המכשירים שלך (בלי שרת, בלי STUN או TURN, רק כתובות מקומיות, אותו קישור
  שהסנכרון משתמש בו), והוא גם מוצפן במפתחות הכספת שלך, כך שרק המכשירים
  שלך יכולים לקרוא אותו.
- אם המחשב לא עונה בזמן (10 שניות לכל דקת שמע, ולפחות 2.5 שניות למשפט),
  עסוק או מתנתק, המשפט הזה נשאר עם הטקסט של הטלפון. שום מילה לא הולכת
  לאיבוד.
- הכספת במחשב צריכה להיות פתוחה, והטלפון צריך לפתוח את אותה כספת.

## איך מודדים דיוק

את ה-WER (שיעור שגיאות המילים) מודדים על **FLEURS-he validation**,
הסט שבו מודל ההזרמה מגיע ל-23.6%. היעד הוא **15% לכל היותר**.

```sh
npm run eval:asr-web -- --fleurs <התיקייה מ-scripts/asr/fleurs_spike.py> --models turbo
```

המדידה מריצה את אותם קובצי ONNX ואותן הגדרות שהדפדפן משתמש בהם. זה גם
שלב אחד ב-`npm run models:day`.

הדוח מציג שתי צורות נרמול, זו לצד זו:

- **v1**: בלי ניקוד, בלי פיסוק, מקף מפריד מילים, אותיות קטנות.
- **v2**: v1, ובנוסף מספר נחשב זהה בין אם נכתב במילים ובין אם בספרות
  (״אלפיים ועשרים״ = ״2020״), ״%״ שווה למילה ״אחוז״, ואות שימוש אחת
  שצמודה למספר היא מילה נפרדת (״ב2020״ = ״ב 2020״). מילים לועזיות **לא**
  מתועתקות (״Google״ ≠ ״גוגל״), והשגיאה הזאת נשארת בציון.

v2 הוא המספר הראשי. v1 נשאר לצידו, כדי שאפשר יהיה להשוות לריצות
קודמות.
