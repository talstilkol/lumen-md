אפליקציית שולחן העבודה (Windows, macOS, Linux) מתעדכנת מהגרסאות שמתפרסמות
ב-GitHub של הפרויקט.

- **בדיקה:** לוח הפקודות ← **בדיקת עדכונים…**. ‏Lumen לא בודק מעצמו.
- **מה נשלח:** בקשה אחת לשרת הגרסאות, עם מספר הגרסה והפלטפורמה. בלי פתקים,
  בלי חשבון ובלי מזהה. הבקשה מופיעה ביומן הפרטיות.
- **מקומי בלבד:** כשמדיניות הפרטיות היא *מקומי בלבד*, לא נבדק כלום, והפקודה
  אומרת זאת.
- **אימות:** כל עדכון חתום. האפליקציה בודקת את החתימה מול המפתח שמובנה בה,
  ודוחה קובץ שאינו תואם, או גרסה ישנה שמוצגת כחדשה.
- **התקנה:** אחרי האישור שלכם, ‏Lumen מוריד, מאמת, מתקין ומופעל מחדש.

לגרסה שנבנתה בלי מפתח העדכונים (בנייה מקומית או גרסת פיתוח) אין מנגנון
עדכון. *בדיקת עדכונים…* אומרת שהוא לא מוגדר, ומתקינים גרסאות חדשות ידנית.

## מתקינים חתומים

המתקינים של הגרסאות ייחתמו כשתעודות החתימה של הפרויקט יהיו מוכנות
(Windows Authenticode, ‏Apple Developer ID). עד אז Windows SmartScreen
ו-macOS Gatekeeper מציגים אזהרה בהפעלה הראשונה.

## מה מותר לאפליקציה

לחלון אין הרשאה כללית למערכת הקבצים. הוא ניגש רק לתיקיית הכספת שבחרתם, דרך
הפקודות של Lumen עצמו. אין גישה לשורת הפקודה, אין HTTP חופשי מהצד הנייטיב,
ואין source maps בקבצים שמופצים.
