## מסמך אחד

1. ב-Google Docs: **קובץ ← הורדה ← Markdown ‏(.md)**. מסמכים ישנים אפשר
   להוריד גם כ-**Word ‏(.docx)**.
2. ב-Lumen: פותחים את הקובץ (`⌘O`) או גוררים אותו לחלון. קובץ `.md` נפתח כמו
   שהוא; קובץ `.docx` מומר ל-Markdown עם הכותרות, הרשימות, הטבלאות והתמונות.
3. שומרים בכספת.

## תיקייה שלמה

‏Google Takeout ‏(takeout.google.com ← **Drive**) מייצא תיקיית מסמכים
כקובצי `.docx`. פותחים את ה-zip, ופותחים את הקבצים ב-Lumen אחד אחד, או
ממירים אותם קודם ל-Markdown ומייבאים את התיקייה עם
`⌘K → Import notes from another app (Obsidian, Notion, Evernote, Bear, Keep, Logseq, OneNote…)…`.

## מה משתנה

| ב-Google Docs | ב-Lumen |
|---|---|
| כותרות, רשימות, טבלאות, קישורים | כותרות, רשימות, טבלאות וקישורים של Markdown |
| הערות והצעות | לא נמצאות בהורדה; ל-Lumen יש [מצב הצעות והערות](/he/collab/webrtc/) משלה |
| פסקאות מימין לשמאל | מזוהות לכל פסקה — ראו [עברית ומימין לשמאל](/he/editor/hebrew/) |
| שיתוף | ‏Lumen עובדת קודם כול על המכשיר; ראו [עבודה משותפת בזמן אמת](/he/collab/webrtc/) |
