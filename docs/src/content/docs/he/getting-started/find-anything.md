ב-Lumen יש הרבה פקודות והגדרות. במדריך הזה מוצאים אותן בהקלדה, כמו
שמוצאים קובץ במחשב. כל תיבה שתפגשו כאן מתעלמת מניקוד, מסימני הטעמה,
מאותיות גדולות ומגרשיים: `שלום` מוצא `שָׁלוֹם`, `cafe` מוצא `café`, `צהל`
מוצא `צה״ל`.

1. **פותחים את לוח הפקודות.** לוחצים `⌘K`. מקלידים `תוכן` — או `outline`
   באנגלית. הפקודות המתאימות מופיעות, הטובה ראשונה. לוחצים `Esc`.
2. **מקלידים בפריסה הלא נכונה.** לוחצים `⌘K` שוב ומקלידים `jhpuai` כשהפריסה
   באנגלית: אלה המקשים של `חיפוש`. ‏Lumen מוצא את פקודת החיפוש ואומר שקרא את
   המקשים שלכם גם כעברית. לוחצים `Esc`.
3. **פותחים את ההגדרות מהמקלדת.** לוחצים `⌘,`. תיבת החיפוש כבר במיקוד.
4. **מחפשים את מה שרוצים, לא את השם שלו.** מקלידים `מצב כהה` (או `dark
   mode`). הגדרת ערכת הנושא מופיעה ראשונה, אף שקוראים לה "ערכת נושא".
   לוחצים `Enter`: המיקוד עובר לפקד שלה; בוחרים ערכה בחיצים.
5. **חוזרים לחיפוש.** לוחצים `⌘F`. מקלידים `vim`, ואז `↓` ו-`Enter` כדי להגיע
   למתג של Vim. לוחצים `Esc` פעמיים כדי לסגור את ההגדרות.
6. **מסננים את הקישורים הנכנסים של פתק.** פותחים פתק שפתקים אחרים מקשרים
   אליו, ופותחים את חלונית הקישורים הנכנסים (`⌘K` ← *קישורים נכנסים*).
   מקלידים מילה בתיבת החיפוש שלה: נשארים רק הקישורים שהמילה בשם הפתק או
   במשפט שלהם.
7. **מקשרים לפתק ששמו עם סימנים.** בעורך מקלידים `[[` ואז `lodz`: מוצע
   פתק בשם `Łódź`. לוחצים `Enter` כדי להכניס את הקישור.

עכשיו אפשר למצוא כל פקודה, הגדרה, כותרת או פתק לפי השם שלהם או לפי מה שהם
עושים. ב[הגדרות](/he/editor/settings/) יש את כל מקשי ההגדרות.
