Lumen היא אותה אפליקציה בכל פלטפורמה. ההבדל היחיד הוא איפה הפתקים נשמרים
ואיך האפליקציה מתעדכנת.

| פלטפורמה | איך | הפתקים נשמרים ב- |
|---|---|---|
| דפדפן | פותחים את האפליקציה המתארחת, או `npm run dev` מעותק של הקוד | מערכת הקבצים הפרטית של הדפדפן (OPFS) |
| אפליקציית רשת מותקנת (PWA) | כפתור **התקנה** של הדפדפן באפליקציה המתארחת | אותו OPFS; עובדת בלי רשת |
| macOS / Windows / Linux | בונים עם `npm run tauri:build` ‏(Tauri 2) | תיקייה אמיתית בדיסק |
| iOS | `npm run ios:open` ‏(Capacitor, פותח את Xcode) | האחסון של האפליקציה |
| Android | `npm run android:open` ‏(Capacitor, פותח את Android Studio) | האחסון של האפליקציה |

## בדפדפן

אין מה להתקין. הפתקים נשארים באחסון הפרטי של הדפדפן הזה ולא יוצאים מהמכשיר,
אלא אם מפעילים סנכרון. **מחיקת נתוני האתר מוחקת אותם**, ולכן לפני שמוחקים
נתוני דפדפן כדאי לייצא את הכספת (*Export the whole vault…*, ראו
[ייצוא וייבוא](/he/workspace/export-import/)), או לשמור את הכספת בתיקייה
אמיתית.

הגרסאות המינימליות (נקבעות על ידי Tailwind CSS 4): ‏Safari ו-iOS 16.4 ומעלה,
Chrome / Edge 111 ומעלה, Firefox 128 ומעלה.

## אפליקציית רשת מותקנת (בלי רשת)

משתמשים בכפתור ההתקנה של הדפדפן (Chrome, ‏Edge) או ב-*שיתוף ← הוספה למסך
הבית* (Safari). האפליקציה המותקנת נפתחת בלי רשת: העורך, הדגשת התחביר,
הגופנים והקבצים שלכם שמורים במטמון.

## שולחן עבודה

עדיין אין גרסאות חתומות להורדה, ולכן בונים מעותק של הקוד:

```bash
npm ci
npm run tauri:build
```

אפליקציית שולחן העבודה שומרת את הכספת כתיקייה של קובצי `.md` רגילים שכלים
אחרים (git, ‏Obsidian, עורך טקסט) יכולים לפתוח, ושומרת סודות במחזיק המפתחות
של מערכת ההפעלה ב-macOS וב-Windows (ראו
[איך Lumen שומרת את הסודות שלכם](/he/security/vault/)). ב-Linux היא צריכה
WebKitGTK 2.40 ומעלה.

## iOS ו-Android

פרויקטי המובייל נוצרים עם Capacitor:

```bash
npm ci
npm run ios:open        # או: npm run android:open
```

ואז בונים ומריצים מ-Xcode או מ-Android Studio.

## הרצה מקוד המקור

```bash
git clone https://github.com/talstilkol/lumen-md
cd lumen-md
npm ci
npm run dev
```
