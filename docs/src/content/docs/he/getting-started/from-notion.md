## ייצוא מ-Notion

1. ב-Notion: **Settings ← Export** (לדף בודד: **⋯ ← Export**).
2. בוחרים **Markdown & CSV**, כוללים דפי משנה, ומורידים את ה-zip.

## מביאים ל-Lumen

`⌘K → Import notes from another app (Obsidian, Notion, Evernote, Bear, Keep, Logseq, OneNote…)…`, ובוחרים את
ה-zip כמו שהגיע. ‏Lumen מזהה ייצוא של Notion לפי המזהים בני 32 התווים
ש-Notion מוסיפה לכל שם קובץ, ואז:

- מסירה את המזהים משמות הקבצים והתיקיות (`Plans 1a2b….md` ← `Plans.md`);
- משכתבת את הקישורים בין הדפים לשמות החדשים, כולל `#כותרות`;
- ממספרת שני דפים שיוצאים עם אותו שם (`Page 2.md`) ושומרת שהקישורים יפנו
  לנכון;
- מייבאת הכול לתיקייה חדשה, `Imported/<שם>`, ואף פעם לא על פתק קיים.

## מה משתנה

| ב-Notion | ב-Lumen |
|---|---|
| דפים ודפי משנה | קובצי Markdown ותיקיות |
| מסדי נתונים | קובץ `.csv` לכל מסד, ליד תיקייה של השורות שלו; פותחים את ה-CSV כטבלה, או בונים [תצוגת מסד נתונים](/he/workspace/database-views/) מעל השורות |
| בלוקים מתקפלים, הדגשות | רשימות וציטוטים של Markdown |
| הערות, היסטוריית דף, הרשאות | לא נמצאים בייצוא |

## עברית

‏Notion שומרת כותרות בעברית בשמות הקבצים; Lumen משאירה אותן כמו שהן. כיוון
מימין לשמאל מזוהה לכל פסקה — ראו [עברית ומימין לשמאל](/he/editor/hebrew/).
