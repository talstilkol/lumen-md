‏Evernote שומרת פתקים בפורמט משלה (ENML), ולכן הם מומרים בדרך פנימה.

## ייצוא מ-Evernote

1. בוחרים מחברת (או את הפתקים הרצויים).
2. **File ← Export notes…** (או **⋯ ← Export**).

## מביאים ל-Lumen

:::note[מגיע עם אשף הייבוא]
אשף הייבוא (תוכנית W1.26) קורא ייצואי `.enex` ישירות: תיקייה לכל מחברת,
תמונות וקבצים במקומם, משימות כמשימות, ותגיות ותאריכי יצירה ועריכה כמאפיינים.
עד שהוא מגיע לגרסה שלכם, השתמשו בדרך ה-HTML שלמטה.
:::

**דרך ה-HTML**: מייצאים את הפתקים כ-**HTML** (קובץ לכל פתק). ב-Lumen פותחים
כל קובץ (`⌘O`) או גוררים אותו לחלון — ה-HTML מומר ל-Markdown, כולל התמונות —
ושומרים בכספת.

## מה משתנה

| ב-Evernote | ב-Lumen |
|---|---|
| מחברות וערימות | תיקיות |
| תגיות | ‏`tags:` ב-frontmatter של כל פתק |
| רשימות סימון | משימות Markdown ‏`- [ ]` |
| טקסט מוצפן | לא עובר (Evernote לא מייצאת אותו גלוי) |
| תזכורות, שיתוף | לא נמצאים בייצוא |
