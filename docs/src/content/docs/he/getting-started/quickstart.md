## 1. פותחים את Lumen

נכנסים ל-[lumen.app](https://lumen.app) (ה-PWA המתארח), מתקינים את אפליקציית
שולחן העבודה (ראו [התקנת Lumen](/he/getting-started/install/)), או מריצים
מקומית:

```bash
git clone https://github.com/talstilkol/lumen-md
cd lumen-md
npm ci
npm run dev
```

## 2. כותבים פתק ראשון

`⌘N` פותח מסמך חדש. נסו את ההדבקה החכמה — `⌘⇧V` פותח חלון ״Insert
anything…״. הדביקו:

- קישור YouTube ← נעטף כ-`\`\`\`embed`
- שורת CSV ← נעטפת כ-`\`\`\`csv` ומציגה טבלה שאפשר למיין + הצעות לגרפים
- ‏`CREATE TABLE` של SQL ← אותו דבר, מפוענח כנתונים
- ‏Mermaid ‏`flowchart LR …` ← מוצג כ-SVG
- משוואת LaTeX ← מתמטיקה בעימוד KaTeX

## 3. שומרים

`⌘S` שומר בסביבת העבודה המקומית ב-OPFS. פותחים את לוח סביבת העבודה
(`⌘K → Toggle workspace`) כדי לעיין בקבצים, לשנות שם ולהעביר. הכול Markdown
רגיל — הפתקים שלכם נשארים ניידים.

## 4. מקשים למשתמשים מתקדמים

| מקש | פעולה |
| --- | --- |
| `⌘K` | לוח הפקודות (הכול נמצא כאן) |
| `⇧⌘F` | מצב מיקוד |
| `⌘⇧V` | הוספה חכמה (זיהוי אוטומטי) |
| `⌘1`–`⌘4` | מקור / מפוצל / תצוגה / WYSIWYG |
| `⌘H` | חיפוש והחלפה |
| `⌘O` / `⌘N` | פתיחה / חדש |

החיפוש בכספת הוא `⌘K → Search workspace…`; הרשימה המלאה ב-
[קיצורי מקלדת](/he/getting-started/shortcuts/).

עכשיו מתחילים לכתוב — וכדאי להכיר את [מצבי העורך](/he/editor/modes/)
לממשקים הכבדים יותר.
