כספת Obsidian היא תיקייה של קובצי Markdown, וכך גם כספת Lumen: אין מה להמיר.

## מביאים את הכספת

1. ב-Obsidian אין צורך לייצא. מכווצים את תיקיית הכספת ל-zip, או משאירים אותה
   כתיקייה.
2. ב-Lumen: `⌘K → Import notes (zip / folder: Obsidian, Notion, Lumen)…`
   (בעברית: „ייבוא פתקים”) ובוחרים את ה-zip או את התיקייה.
3. ‏Lumen מזהה את הכספת לפי תיקיית `.obsidian/` שלה ומייבא כל פתק וכל קובץ
   מצורף לתיקייה חדשה, `Imported/<שם הכספת>`. שום דבר שכבר נמצא ב-Lumen לא
   נדרס. ההגדרות של Obsidian עצמה (`.obsidian/`, ‏`.trash/`) נשארות מאחור.

פרטים ורשימה מלאה של מה שלא מיובא: [ייצוא וייבוא](/he/workspace/export-import/).

## מה עובר

| ב-Obsidian | ב-Lumen |
|---|---|
| ‏`[[wikilinks]]`, ‏`[[note#heading]]`, ‏`![[embeds]]` | אותו תחביר |
| מאפייני frontmatter, ‏`tags:` | אותו YAML; חלונית התגיות ותצוגות מסד הנתונים קוראות אותו |
| קבצים מצורפים (תמונות, PDF) | אותם קבצים, אותם קישורים יחסיים |
| הדגשות `> [!note]` | מוצגות כציטוט; ההדגשות של Lumen הן בלוקי `:::note` |
| ‏Canvas ‏(`.canvas`) | נשמרים כקבצים |
| תוספים וערכות נושא | לא עוברים: ל-Lumen יש [תוספים](/he/plugins/sdk/) משלה |

## הרגלים יומיומיים

- **פלטת הפקודות**: `⌘K`, כמו `⌘P` ב-Obsidian. השאר ב[קיצורי
  מקלדת](/he/getting-started/shortcuts/).
- **עברית**: העורך והתצוגה מכירים כיוון לכל פסקה; ראו [עברית ומימין
  לשמאל](/he/editor/hebrew/).
- **סנכרון**: Obsidian Sync לא מגיע ל-Lumen. השתמשו ב-Git, או שמרו את הכספת
  בתיקייה ששתי האפליקציות פותחות בשולחן העבודה.

## חזרה

הפתקים נשארים Markdown רגיל. `⌘K → Export the whole vault…` נותן zip או
תיקייה ש-Obsidian פותחת ככספת.
