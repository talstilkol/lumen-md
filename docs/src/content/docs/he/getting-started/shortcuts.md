title: קיצורי מקלדת
description: כל קיצור ש-Lumen מגדירה, איפה הוא עובד, ואיך למצוא את השאר בלוח הפקודות.
---

ב-Windows וב-Linux‏ `⌘` הוא **Ctrl**,‏ `⌥` הוא **Alt** ו-`⇧` הוא **Shift**;
האפליקציה מציגה את המקשים הנכונים למערכת שלכם. `⌘/` פותח את הרשימה הזו בתוך
האפליקציה.

כל מה ש-Lumen יודעת לעשות הוא פקודה ב**לוח הפקודות** (`⌘K`), שמציג את
הקיצור של כל פקודה שיש לה קיצור.

## בכל מקום באפליקציה

| מקשים | פעולה |
|---|---|
| `⌘K` | לוח הפקודות |
| `⌘/` | קיצורי מקלדת |
| `⌘N` | מסמך חדש |
| `⌘O` | פתיחת קובץ |
| `⌘S` | שמירה |
| `⇧⌘S` | שמירה בשם |
| `⌘1` / `⌘2` / `⌘3` / `⌘4` | מקור / מפוצל / תצוגה / WYSIWYG |
| `⌘H` | חיפוש והחלפה |
| `⇧⌘V` | הוספה חכמה (מדביקים כל דבר, הוא מזוהה ונעטף) |
| `⇧⌘F` | מצב מיקוד (לחיצה נוספת יוצאת) |
| `Esc` | סגירת החלון הפתוח |

לחיפוש בכספת אין היום קיצור גלובלי משלו: פותחים אותו עם
`⌘K → Search workspace…`. הדפסה היא `⌘K → Print / Save as PDF…`;‏ `⌘P`
פותח את חלון ההדפסה של הדפדפן עצמו.

## בעורך

| מקשים | פעולה |
|---|---|
| `⌘Z` / `⇧⌘Z` | ביטול / ביצוע מחדש |
| `⌘F` | חיפוש בפתק הזה (עורך המקור) |
| `⇧⌥F` | עיצוב המסמך |
| `Ctrl+Space` | בקשת המשך מה-AI (טקסט רפאים) |

## בפס הלשוניות ובעורך העשיר

| מקשים | איפה | פעולה |
|---|---|---|
| `⌘W` | לשונית שבמיקוד | סגירה |
| `↑` / `↓` | ידית בלוק שבמיקוד | הזזת הבלוק למעלה / למטה |
| `Enter` / `Space` | ידית בלוק שבמיקוד | הצבת הסמן בתחילת הבלוק |
