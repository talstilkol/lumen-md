## להתחיל מתבנית

לוח הפקודות מציג תבניות כפקודות. בוחרים אחת והיא נפתחת כ**לשונית חדשה שלא
נשמרה**: היא לעולם לא נכתבת לתוך הפתק הפתוח, ושם שכבר תפוס מקבל מספר
(*Meeting notes 2.md*).

## גלריית התבניות

`⌘K → Browse template gallery` פותח את הגלריה: מסננים לפי קטגוריה, מחפשים
לפי שם, ו**מתקינים** תבנית. ההתקנה כותבת אותה ל-`templates/<id>.md` בכספת
ומוסיפה אותה ללוח הפקודות תחת **Templates: <name>**. זה פתק רגיל, כך שאפשר
לערוך אותו כמו כל פתק אחר. כשהממשק בעברית, תבניות שיש להן גרסה עברית מותקנות
בעברית.

רשימת הגלריה מגיעה עם האפליקציה (`public/templates/registry.json`), כך
שעיון בה לא שולח בקשה לשום אתר אחר.

## להוסיף תבנית לגלריה

ראו `public/templates/CONTRIBUTING.md` בריפו: קובץ Markdown אחד ועוד רשומה
ב-`registry.json` (וקובץ עברי תחת `public/templates/he/` כשיש כזה).

**⌘K ← פתח גלריית תבניות** פותח את הגלריה. **התקן** מעתיק תבנית
לסביבת העבודה בתור `templates/<id>.md`; מאותו רגע היא מופיעה
ב-**⌘K ← תבניות**, ובחירה בה פותחת ממנה פתק חדש שעוד לא נשמר. הגלריה
מדברת בשפת הממשק: בעברית מקבלים את השם, התיאור והתוכן העבריים של כל
תבנית שיש לה כאלה.

## תבניות לשימושים ישראליים

עשרים תבניות, כל אחת בעברית ובאנגלית:

| תחום | תבניות |
|---|---|
| יומן | יומן יומי (עם התאריך העברי), סיכום שבועי (ראשון–חמישי) |
| סטודנטים | קורס באוניברסיטה (סמסטר, נקודות זכות), מבחן (מועד א׳ / ב׳), סיכום הרצאה, עבודה סמינריונית |
| מחקר | מאמר לקריאה, יומן מחקר / ניסוי |
| עבודה | ישיבת צוות, שיחת אחד על אחד, פרויקט (קנבן), משימה |
| בית | מתכון (בשרי / חלבי / פרווה, לשבת), תכנון חג, חיפוש דירה (שכירות ב-₪, ארנונה, ועד בית) |
| קריאה וכתיבה | ספר שאני קורא/ת, פרק בספר, דמות |
| אישי | יומן מילואים, מועמדות לעבודה (קנבן) |

כל התבניות שומרות את הפרטים בתור **מאפיינים** ב-frontmatter, עם מפתחות
באנגלית (`type`, `status`, `due`…) וערכים בשפה שלכם — כך שאותו פתק עובד
גם ב-Lumen וגם ב-Obsidian.

### תצוגת Bases לכל תבנית

לכל תבנית יש [קובץ ‎`.base`](/he/workspace/obsidian-bases/) נלווה. התקנת
התבנית כותבת גם אותו אל `Bases/‎` (למשל `Bases/קורסים.base`, או
`Bases/Courses.base` באנגלית): תצוגת טבלה, כרטיסים או קנבן של כל
הפתקים עם ה-`type` של התבנית, ושמות העמודות בשפה שלכם. אם הקובץ כבר
קיים, לא נוגעים בו — השינויים שעשיתם בתצוגה נשארים גם אחרי התקנה חוזרת.

## משתני תבנית

כשתבנית הופכת לפתק, ממלאים את אלה — אותם שמות כמו בתוסף התבניות של
Obsidian:

| משתנה | הופך ל- |
|---|---|
| `{{title}}` | שם הפתק |
| `{{date}}` | היום, ‎`YYYY-MM-DD` |
| `{{time}}` | עכשיו, ‎`HH:mm` |
| `{{hebrewDate}}` | היום בלוח העברי, למשל „30 בחשוון 5787” |

כל דבר אחר בסוגריים מסולסלים כפולים נשאר כמו שהוא.

## ייבוא תבנית מקובץ

**⌘K ← ייבוא תבנית מקובץ…**, או **ייבוא מקובץ…** בראש הגלריה, מעתיק
קובץ Markdown שבחרתם אל `templates/‎`. שם תפוס מקבל מספר (`מתכון.md`,
ואחריו `מתכון 2.md`), ותווים שאסור שיהיו בשם קובץ מוחלפים ברווחים.
התבנית מופיעה ב-**⌘K ← תבניות** מיד.

## כספות לדוגמה

שלוש כספות מוכנות מראות את התבניות, הקישורים ותצוגות ה-Bases עובדים
יחד. כל אחת נפתחת מפלטת הפקודות, בשפת הממשק, לתיקייה משלה:

- **פתיחת כספת לדוגמה: סטודנטים** — שני קורסים, סיכומי הרצאות ומבחן עם
  תוכנית לימוד; תצוגות של קורסים, הרצאות ומבחנים.
- **פתיחת כספת לדוגמה: מחקר** — תזה, שלושה מאמרים ושני ניסויים; תצוגות
  של הספרות, יומן המחקר והעבודות.
- **פתיחת כספת לדוגמה: כתיבה** — שלושה פרקים ושלוש דמויות שמקושרים זה
  לזה; תצוגות של כתב היד ושל הדמויות.

כמו מרחב העבודה לדוגמה, כספת לדוגמה אף פעם לא דורסת כלום: הרצה נוספת
רק מוסיפה את הקבצים שחסרים.
