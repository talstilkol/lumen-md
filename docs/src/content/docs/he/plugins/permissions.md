תוסף בארגז חול לא יכול לעשות שום דבר עד שמאשרים לו — ראו
[ה-API של התוספים](/he/plugins/api/). שני דברים הופכים את ההחלטה למושכלת.

## מסך ההתקנה

**גלריית התוספים ← תוספים בארגז חול ← התקנה…** פותח מסך שמפרט, לפני
שמשהו רץ, כל הרשאה שה-manifest של התוסף מבקש:

| הרשאה | מה היא מאפשרת לתוסף |
|---|---|
| `document:read` | לקרוא את הפתק הפתוח |
| `document:write` | לשנות את הפתק הפתוח (*רגיש*) |
| `vault:read` | לקרוא כל פתק בכספת (*רגיש*) |
| `vault:write` | ליצור ולשנות פתקים בכספת (*רגיש*) |
| `commands` | להוסיף פקודות ללוח הפקודות |
| `panel` | להציג חלונית צד |
| `renderer` | לצייר בתצוגה בלוקי קוד בשפה משלו |
| `settings` | לשמור הגדרות משלו |
| `storage` | לשמור נתונים משלו במכשיר הזה |
| `clipboard:write` | להעתיק טקסט ללוח (*רגיש*) |
| `notifications` | להציג התראות |
| `network:<origin>` | להתחבר לכתובת האחת הזאת — ולשום מקום אחר (*רגיש*) |

כל שורה מציגה גם את הסיבה של התוסף עצמו („למה: …”) ואת סריקת הבטיחות של
הגרסה. **להתקין ולאשר** נותן בדיוק את מה שמופיע ברשימה; כל דבר אחר שהתוסף
מנסה נחסם בארגז החול, וכל בקשת רשת מופיעה ביומן הפרטיות. הקוד נסרק שוב רגע
לפני שהוא רץ, כך שהכרטיס לא יכול לתאר עותק אחר.

## סריקת הבטיחות

כל גרסה ברישום (`public/plugins/examples/index.json`) נסרקת על ידי
`scripts/scan-plugins.mjs` לתוך `scan.json`; הגלריה מציגה לכל גרסה כרטיס —
ציון (A, ‏B, ‏C), ניקוד מתוך 100, ומה הסריקה העירה. **גרסה שנכשלת לא מוצגת
ואי אפשר להתקין אותה.**

הסריקה קוראת את הקוד — היא אף פעם לא מריצה אותו — ומכשילה גרסה ש:

- משתמשת ב-API שה-manifest לא מצהיר על ההרשאה שלו (למשל כותבת לפתק עם
  `document:read` בלבד);
- ניגשת לרשת בלי להצהיר על כך, או מתחברת למקור אחר מזה שהוצהר;
- מריצה קוד שנבנה מטקסט (`eval`, ‏`Function`, טיימרים עם מחרוזת), טוענת עוד
  קוד (`import`), או ניגשת ל-`globalThis` / ‏`lumen` עם מפתח מחושב;
- אינה JavaScript תקין, גדולה מ-512 KB, או שהחתימה שלה לא מאומתת.

היא מעירה (ומורידה ניקוד) על הרשאות שהתבקשו ולא בשימוש, שימוש עקיף ב-API,
כתובות רשת שנבנות תוך כדי ריצה, וחתימה חסרה או לא מוכרת.

כדי לבדוק גרסה חדשה לפני פרסום: מוסיפים אותה ל-`index.json`, ואז
`node scripts/scan-plugins.mjs` (או `--check` לבדיקה בלבד).

## דיווח על בעיה

בכל כרטיס ובכל מסך התקנה יש **דיווח על בעיה**, שפותח issue שבו מזהה התוסף
והגרסה כבר ממולאים.
