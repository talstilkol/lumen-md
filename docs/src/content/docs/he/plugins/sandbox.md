לומן מריץ כל תוסף **בלי שום גישה כברירת מחדל**. תוסף מקבל רק את היכולות
שאישרתם בהתקנה, ואפשר לבטל אותן בכל רגע.

## איפה רץ הקוד של התוסף

| חלק | רץ ב- | מה זמין לו |
|---|---|---|
| לוגיקה (`main`) | [QuickJS](https://github.com/justjake/quickjs-emscripten) (MIT), מנוע JavaScript נפרד שקומפל ל-WebAssembly, בתוך Web Worker משלו | רק האובייקט `lumen`. אין `fetch`, `XMLHttpRequest`, `WebSocket`, `importScripts`, DOM או אחסון, ואין `import` של מודולים אחרים. |
| ממשק (פאנלים, הגדרות, פלט של בלוקים) | לומן עצמו | התוסף שולח **עץ של רכיבים מוכרים**: טקסט, כותרת, פסקה, קופסה, רשימה, כפתור, שדה, תיבת סימון, בחירה, קוד, קישור לפתק, קו מפריד. אין `img`, `iframe`, `form`, `style`, `script` או HTML, ואין קישור לכתובת אינטרנט. |

הממשק הוא נתונים, ולא iframe בארגז חול, בכוונה. CSP ותכונת `sandbox` חוסמים
כל ערוץ חוץ מאחד: מסגרת תמיד יכולה לנווט *את עצמה*
(`location = "https://…?" + text`). לעץ של רכיבים מוכרים אין ערוץ כזה.

## מגבלות

לכל תוסף יש ערימה של 32MB ומחסנית של 512KB. בכל כניסה של לומן לקוד שלו
(אירוע, תשובה לקריאה) הוא מקבל 250ms של מעבד, והקונסול שלו מוגבל ל-120 שורות
בדקה. תוסף שעובר מגבלה, או זורק שגיאה שאף אחד לא תופס, נעצר.

## יכולות

| יכולת | נותנת |
|---|---|
| `document:read` / `document:write` | הטקסט והבחירה של הפתק הפתוח / שינוי שלהם |
| `vault:read` / `vault:write` | רשימה וקריאה של פתקים / כתיבת פתקים |
| `commands` | פקודות בלוח הפקודות |
| `panel` | פאנל צד |
| `renderer` | רינדור של שפת בלוק קוד |
| `settings` | אזור הגדרות |
| `storage` | אחסון מפתח–ערך משלו |
| `clipboard:write` | העתקת טקסט |
| `notifications` | הודעות קופצות |
| `network:https://exact.origin` | בקשות **למקור הזה בלבד** — https (http רק ל-localhost), בלי עוגיות, בלי הפניות, תשובה של 5MB לכל היותר |

כל יכולת שהמניפסט מבקש באה עם נימוק, שמוצג לכם לפני האישור. קריאה בלי
היכולת שלה נכשלת בתוך התוסף עם `PluginDenied` ולא מגיעה ללומן. לומן בודק את
האישור פעם שנייה גם בצד המארח, כי ה-worker הוא גבול ולא המדיניות.

## רשת ופרטיות

כל בקשה של תוסף מופיעה ב**יומן הפרטיות** תחת "תוסף". במדיניות **מקומי בלבד**
בקשות של תוספים נחסמות ונרשמות כחסומות, גם כשלתוסף יש הרשאת רשת.

## מניפסט (`lumen-plugin.json`)

```json
{
  "schema": 1,
  "id": "org.example.word-stats",
  "name": "Word stats",
  "version": "1.0.0",
  "description": "Counts words in the open note",
  "author": "Example",
  "license": "MIT",
  "main": "main.js",
  "capabilities": [
    { "id": "document:read", "reason": "To count the words of the open note" },
    { "id": "commands", "reason": "Adds the “Word stats” command" }
  ]
}
```
