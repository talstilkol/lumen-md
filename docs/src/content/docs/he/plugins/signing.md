---
title: מפתחות חתימה לתוספים
description: להחליט על התוספים של אילו מפרסמים Lumen סומכת.
---

אפשר לחתום על תוספים מהמאגר במפתח **Ed25519**. לפני ההתקנה Lumen מאמתת את
החתימה מול המפתחות שאתם סומכים עליהם, כך ש-CDN שנפרץ לא יכול לשלוח קוד
ששונה.

## ניהול מפתחות מהימנים

לוח הפקודות ← **Trusted plugin signing keys…**

- מפתחות **מובנים** מגיעים מההתקנה (`VITE_PLUGIN_TRUSTED_KEYS`) ואי אפשר
  להסיר אותם מהממשק.
- **המפתחות שלכם** נשמרים בדפדפן הזה. מדביקים את המפתח הציבורי של המפרסם
  ולוחצים **Trust key**.

כל מפתח מזוהה לפי **טביעת האצבע** שלו — SHA-256 של המפתח הציבורי, בהקסה.
השוו אותה לטביעת האצבע שהמפרסם מציג באתר שלו לפני שאתם סומכים עליו.

## פורמטים נתמכים

- ‏SPKI ב-Base64 ‏(44 בייטים ל-Ed25519, מתחיל ב-`MCow`).
- ‏PEM:‏ `-----BEGIN PUBLIC KEY----- … -----END PUBLIC KEY-----`.

יוצרים זוג מפתחות עם OpenSSL:

```bash
openssl genpkey -algorithm ed25519 -out plugin-signing.pem
openssl pkey -in plugin-signing.pem -pubout
```

## שגיאות

- **Not an Ed25519 public key** — הטקסט שהודבק אינו מפתח Ed25519 ב-SPKI
  של 44 בייטים (מפתחות RSA ו-ECDSA לא מתקבלים).
- **Untrusted signer** — התוסף חתום כראוי, אבל במפתח שלא סימנתם כמהימן.
  אמתו את טביעת האצבע, ואז הוסיפו את המפתח.
