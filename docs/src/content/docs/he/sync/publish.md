:::caution[עדיין לא באפליקציה]
הקוד של הפרסום קיים (`src/sync/publish.ts`), אבל **אף מסך או פקודה עוד לא
קוראים לו**. העמוד הזה מתאר מה שיש, כדי שמי שמארח את האפליקציה יוכל להקים
את צד השרת לפני הכפתור.
:::

## מה זה עושה

`publishNote()` שולח פתק לשרת פרסום, ששומר את הדף המעובד ועונה עם הכתובת
הציבורית וה-slug שלו. ‏`unpublishNote()` מחזיר אותו להיות פרטי. אפשר לפרסם
פתק כ**ציבורי** או כ**לא רשום**, ועם סיסמה: אז התוכן מוצפן במכשיר לפני
שהוא נשלח, כך שבשרת יש רק טקסט מוצפן. ה-slug נשמר ב-front matter של הפתק (`published: <slug>`),
כך שפרסום נוסף מעדכן את אותו דף. פרסום דורש מסלול עם תכונות ענן (Pro / Team).

## השרת

כל נקודת קצה HTTP שמקבלת את אותו JSON מתאימה. ההפניה היא Cloudflare Worker
ב-`edge-workers/publish`; שלבי ההתקנה ב-`DEPLOY.md` (הסעיף *Publish edge
worker*). האפליקציה מוצאת את השרת דרך `VITE_PUBLISH_ENDPOINT` בזמן הבנייה.
בלעדיו, בנייה לפיתוח (או כזו שרצה ב-`localhost`) מפרסמת לתוך מדמה מקומי,
וכל בנייה אחרת מסרבת עם *“VITE_PUBLISH_ENDPOINT is not set”*.

הדפדפן לא מחזיק אף מפתח שירות: הבקשות נושאות את הסשן של המשתמש.
