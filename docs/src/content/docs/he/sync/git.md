Lumen יכול לשמור תיקייה בכספת שלכם מסונכרנת עם מאגר git. הכול רץ באפליקציה (דרך [isomorphic-git](https://isomorphic-git.org)); אין שרת של Lumen באמצע.

פקודות (⌘K):

| פקודה | מה היא עושה |
| --- | --- |
| **Git: clone repository…** | מעתיקה מאגר לתיקייה בכספת. |
| **Git: pull current repo** | מביאה את המרוחק וממזגת אותו לתיקייה הזו (ראו בהמשך). |
| **Git: commit & push current repo…** | קודם שומרת כל פתק פתוח עם עריכות שלא נשמרו (כולל לשוניות), ואז יוצרת commit לתיקייה ודוחפת אותה. פתק שהקובץ שלו השתנה בינתיים מחוץ ל-Lumen לא נכנס ל-commit ומופיע ברשימה, כדי שאפשר יהיה לפתור את ההתנגשות קודם. |
| **Git: status (current repo)** | קבצים שנוספו / שונו / נמחקו. |
| **Git: toggle watch-mode auto-pull** | מושכת כל 5 דקות כל עוד הלשונית גלויה. |
| **Git: set CORS proxy…** | ה-proxy שבקשות git עוברות דרכו בדפדפן. |
| **Git: set access token…** | נחוץ רק למאגרים פרטיים ולדחיפה. |

## מה משיכה עושה (ומה אף פעם לא)

משיכה היא **fetch + מיזוג תלת-כיווני** לתוך הכספת:

- קובץ שרק המרוחק שינה מתעדכן.
- קובץ ששיניתם והמרוחק לא נשאר כמו שהוא.
- קובץ ששניכם שיניתם ממוזג שורה אחרי שורה. עריכות בשורות שונות מתמזגות מעצמן.
- עריכות ב**אותן שורות** הן **התנגשות**. הקובץ מכיל אז את שתי הגרסאות בין הסמנים הרגילים:

  ```text
  <<<<<<< local
  your line
  =======
  their line
  >>>>>>> remote
  ```

  מסך הפתרון נפתח לכל התנגשות: להשאיר את שלכם, לקחת את שלהם, או לבחור לפי קטע. אם בוחרים **Resolve later**, הסמנים נשארים בקובץ, ו**ה-commit מסרב** עד שהם נעלמים, כך שסמנים אף פעם לא נדחפים בטעות. לפני שקובץ עם התנגשות או קובץ ממוזג נכתב מחדש, הטקסט הקודם שלו נכנס להיסטוריית הגרסאות ("before git pull").

מה משיכה **אף פעם** לא עושה:

- **היא אף פעם לא מוחקת קובץ.** קובץ שנמחק במקור נשאר בכספת שלכם, והמשיכה אומרת אילו. מחקו אותו בעצמכם אם אתם רוצים שייעלם.
- **היא אף פעם לא נוגעת בקבצים ש-git לא עוקב אחריהם.** הפתקים שלכם בתיקיית המאגר לא נבדקים.
- **היא אף פעם לא דורסת פתק פתוח עם עריכות שלא נשמרו.** מיזוג נקי נכנס לעורך ונשמר בדרך הרגילה. בהתנגשות הפתק נשאר בדיוק כמו שהוא, והגרסה המרוחקת נשמרת לידו בשם `name (git 1a2b3c4).md`.
- **היא אף פעם לא ממזגת קבצים בינאריים.** אם שני הצדדים שינו תמונה, שלכם נשארת ושלהם נשמרת כעותק.

שכפול לתיקייה שכבר קיימת משאיר כל קובץ שכבר נמצא בה. קבצים שכבר קיימים עם תוכן שונה נספרים, ולא נדרסים.

### שכפולים רדודים

שכפול מביא רק את ה-commit האחרון (עומק 1). מיזוג צריך את ה-commit ששני הצדדים חולקים (*בסיס המיזוג*), ולכן כשמשיכה לא מוצאת אותו, Lumen מעמיק את השכפול אוטומטית: 50, ואז 500, ואז 5,000 commits, ולבסוף את כל ההיסטוריה.

## מאגרים ציבוריים לא צריכים אסימון

שכפול ומשיכה עובדים במאגרים ציבוריים בלי אסימון. צריך אסימון (ב-GitHub: ‏fine-grained personal access token עם *Contents: read & write*) רק למאגרים פרטיים ולדחיפה. האסימון נשאר במכשיר הזה, במאגר הסודות המוצפן.

## ‏CORS proxy

דפדפנים מאפשרים לדף לדבר רק עם שרתים שמתירים זאת (CORS), ו-GitHub, ‏GitLab ורוב שרתי ה-git לא מתירים זאת לתעבורת git. לכן בדפדפן git עובר דרך **CORS proxy**. אפליקציית שולחן העבודה ושרתי git ששולחים כותרות CORS לא צריכים אחד.

**ל-Lumen אין proxy מובנה.** בחרו אחת מהאפשרויות:

1. **הריצו אחד במכונה הזו** (מומלץ):

   ```sh
   docker compose -f docker/git-proxy.yml up -d
   ```

   ואז ⌘K ← **Git: set CORS proxy…** ← `http://localhost:9999`. מדיניות ה-Content-Security-Policy של Lumen כבר מתירה את `localhost:9999`.

2. **proxy שההתקנה שלכם מארחת.** בנו עם `VITE_GIT_CORS_PROXY=https://git-proxy.example.com`. הבנייה מוסיפה את המקור הזה ל-`connect-src` של ה-CSP, והוא הופך לברירת המחדל לכל המשתמשים. ההגדרה של המשתמש עצמו (אפשרות 1) עדיין קודמת.

ה-proxy הוא [@isomorphic-git/cors-proxy](https://github.com/isomorphic-git/cors-proxy) ‏(MIT). הוא מעביר רק בקשות git smart-HTTP ולא שומר דבר. האסימון שלכם עובר דרכו בכותרת `Authorization`, לכן השתמשו רק ב-proxy שאתם סומכים עליו.

אם שכפול או משיכה נכשלים לפני שהם מגיעים לשרת ה-git, ‏Lumen אומר זאת ומפנה להגדרה הזו.

## ‏Git LFS לא נתמך

מאגרים שמשתמשים ב-[Git LFS](https://git-lfs.com) שומרים קבצים גדולים כקובצי *מצביע* קטנים, והתוכן האמיתי נמצא בשרת LFS נפרד ש-Lumen לא מדבר איתו. מה קורה:

- שכפול כותב את קובצי המצביע כמו שהם ומפרט אותם, כדי שתדעו שהקבצים האלה אינם התוכן האמיתי.
- משיכה **אף פעם לא מחליפה קובץ אמיתי במצביע**. אם בכספת יש את הקובץ האמיתי ובמקור יש מצביע, הקובץ נשמר ומדווח.
- ‏commit **אף פעם לא מחליף מצביע בקובץ האמיתי**: המאגר שומר את המצביע שלו וה-commit אומר אילו קבצים הוא השאיר כך, כדי שקובץ גדול לא יידחף כאובייקט Git רגיל ומעקב ה-LFS של המאגר יישאר שלם.

כדי לעבוד עם תוכן LFS, הוציאו את המאגר עם שורת הפקודה של git ופתחו את התיקייה הזו ככספת שלכם.
