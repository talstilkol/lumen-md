לצד WebDAV, ‏S3, ‏Dropbox ו-Google Drive, [הסנכרון המוצפן](/he/sync/e2ee/) יכול
לשמור את הכספת **ברשת המקומית שלכם בלבד**. מכשיר אחד שומר את הכספת, והאחרים
מתחברים אליו ישירות. אין שרת, אין חשבון ואין ענן, וזה עובד גם בלי חיבור
לאינטרנט בכלל.

## הגדרה

1. במכשיר ששומר את הכספת (מחשב שבדרך כלל דולק): ⌘K ← *סנכרון מוצפן…* ←
   **רשת מקומית** ← *שומר את הכספת* ← *התחברות*, ובחרו סיסמה.
2. באותו מכשיר: **צימוד מכשיר**. Lumen מציג קוד צימוד כקוד QR וכטקסט.
3. במכשיר השני: ⌘K ← *סנכרון מוצפן…* ← **רשת מקומית** ← *מצטרף למכשיר ששומר
   את הכספת*. הדביקו או סרקו את הקוד, ולחצו *תשובה*.
4. החזירו את קוד התשובה למכשיר הראשון, הדביקו אותו שם ולחצו *התחברות*.
5. במכשיר המצטרף, פתחו את הכספת עם אותה סיסמה.

מכאן כל מכשיר מסתנכרן **בעצמו**, זמן קצר אחרי שאתם עורכים וזמן קצר אחרי
שהמכשיר השני מדווח על שינוי. עריכה מגיעה למכשיר השני בפחות משתי שניות.

> השאירו את Lumen פתוח במכשיר ששומר את הכספת בזמן שהאחרים מסתנכרנים. אם
> החיבור נופל (המכשיר נכנס לשינה, הרשת השתנתה), צמדו שוב. שום דבר לא אובד:
> הסבב הבא משלים את הפער.

## מה עובר ברשת

אותו דבר ששירות ענן היה שומר: כותרת הכספת, ומניפסטים וקבצים חתומים בשמות
HMAC. המכשירים מעבירים אותם ישירות, בערוץ נתונים של WebRTC ‏(DTLS). הפתקים
מוצפנים לפני שהם יוצאים מהמכשיר (AES-256-GCM, מפתחות מהסיסמה), בדיוק כמו
עם הספקים האחרים.

| | |
|---|---|
| שרת איתות | אין. שני קודי הצימוד נושאים את פרטי החיבור של כל מכשיר |
| STUN / TURN | אין (`iceServers: []`) |
| כתובות בשימוש | רק כתובות ברשת המקומית: ‎10/8, 172.16/12, 192.168/16, 169.254/16, 127/8, IPv6 מקומי לקישור ומקומי ייחודי, `*.local` |
| מי רשאי לכתוב | רק מכשיר שמוכיח שהוא יודע את הסיסמה |

שתי בדיקות שומרות את החיבור בתוך הרשת שלכם:

- כל מועמד חיבור, בשני הקודים, חייב להיות מועמד host עם כתובת ברשת המקומית;
  כל מועמד אחר נזרק. אחרי ההתחברות הכתובת של הצד השני נבדקת שוב, וחיבור
  למשהו מחוץ לרשת המקומית נסגר.
- המכשיר ששומר את הכספת מגיש רק את כותרת הכספת עד שהמכשיר השני מוכיח שהוא
  יודע את הסיסמה (אתגר HMAC בשני הכיוונים במפתח הצימוד של הכספת). מכשיר עם
  סיסמה אחרת, או מכשיר שיש לו רק קוד צימוד, לא יכול לרשום, לכתוב או למחוק
  כלום.

קודי הצימוד לא נושאים חומר מפתח. עדיין צריך את הסיסמה.

## יומן הפרטיות

כל חיבור מופיע ביומן הפרטיות (⌘K ← *יומן פרטיות*) תחת *במכשיר / ברשת
המקומית*. הכתובת שבו היא הכתובת של המכשיר השני ברשת המקומית (או "הכתובת
מוסתרת על ידי הדפדפן" כשהדפדפן לא חושף אותה), יחד עם מספר הבתים שעברו בחיבור.
אף רשומה של הסנכרון המקומי לא יכולה להציג כתובת מחוץ לרשת שלכם.

## סריקת קוד ה-QR

אפליקציית הרשת לא יכולה לפתוח את המצלמה: מדיניות ההרשאות שלה מכבה אותה.
כדי להעביר קוד, סרקו את קוד ה-QR באפליקציית המצלמה של מכשיר אחר, או העתיקו
והדביקו את הטקסט (למשל דרך פתק לעצמכם או AirDrop). סריקה מובנית וגילוי
אוטומטי של מכשירים (mDNS) שייכים לאפליקציות לשולחן העבודה ולנייד, ואינם
חלק מהגרסה הזו.

## איך זה נבדק

- `src/__tests__/lanSync.test.ts`: שני מכשירים, מנוע הסנכרון האמיתי, חיבור
  עם השהיה של רשת מקומית. **1,000 סבבים** של עריכות ומחיקות אקראיות בשני
  הצדדים, לפעמים באותו רגע, מסתיימים **בלי לאבד כלום** (וכל כתיבה מקבילה
  נשמרת, בפתק או בעותק הקונפליקט שלו). החיבור לא נושא טקסט של פתקים, ואין
  **אף** `fetch`. שינוי מגיע למכשיר השני **בפחות מ-2 שניות**, בשני הכיוונים.
  סיסמאות שגויות ומארחים שגויים נדחים.
- `e2e/lan-sync.spec.ts`: שני דפדפנים מצטמדים עם הקודים, פותחים את הכספת
  ומסתנכרנים בשני הכיוונים בעצמם. הם לא שולחים אף בקשה מלבד לשרת של
  האפליקציה עצמה, והיומן מציג רק כתובות ברשת המקומית.
