## עבודה משותפת

- [שיתוף חי מוצפן](/he/collab/e2ee-sharing/) — שיתוף פתק בזמן אמת דרך שרת ששומר ומעביר רק טקסט מוצפן, כולל שמות וסמנים.
- [הצפנה מקצה לקצה בשיתוף](/he/collab/encryption/) — מוסיפים סיסמה לחדר, ואף שרת ממסר, שרת איתות או שרת סנכרון לא יכול לקרוא את המסמך.
- [קנבס חי](/he/collab/live-canvas/) — ציור משותף על אותו קנבס בזמן סשן שיתוף. השינויים והסמנים מופיעים מיד, דרך אותו חדר מוצפן של הפתק.
- [השרת הציבורי](/he/collab/public-server/) — שרת שיתוף חי חינמי לכולם, ששומר רק חדרים מוצפנים, מוחק חדרים שלא נגעו בהם 90 יום ולא שומר כתובות IP ביומנים.
- [קישור שיתוף מוצפן](/he/collab/share-link/) — לשתף עותק לקריאה בלבד של פתק אחד בקישור שמכיל את הפתק עצמו, מוצפן. בלי שרת ובלי חשבון.
- [שיתוף, תפקידים ושרשורי תגובות](/he/collab/sharing/) — שיתוף פתק לצפייה, לתגובה או לעריכה בקישור עם תפוגה; ביטול הקישור; שרשורי תגובות עם אזכורים.
- [הצעות וגרסאות בשם](/he/collab/suggestions-versions/) — הציעו עריכות שלא משנות דבר עד שמישהו מקבל אותן, קבלו או דחו את ההצעות של אדם אחד בכל פעם, ראו מי כתב מה (גם ה-AI), ותנו שמות לגרסאות כדי להשוות ביניהן מילה במילה.
- [שיתוף בזמן אמת ב-WebRTC](/he/collab/webrtc/) — עריכה עם כמה סמנים מעל רשת עמית-לעמית — בלי חשבון בשרת, בלי יומן מרכזי של המסמך.

## תרומה לפרויקט

- [תקציבים שרק יורדים](/he/contributing/budgets/) — תקציבי החבילה וספי ה־FCP וה־LCP של שער הביצועים יורדים אחרי כל רכבת למה שהרכבת מדדה ועוד 2%, ולעולם לא עולים. לחריגות יש תאריך תפוגה, והן נכשלות כשהוא עובר.
- [בדיקות בכל ענף (Vercel)](/he/contributing/checks/) — השערים של Lumen רצים בבניית Vercel של כל ענף, בלי GitHub Actions — מה רץ, מה המשמעות של סטטוס אדום, ולאן עברו בדיקות ה-CI הישנות.
- [בדיקות קוד: מחרוזות, כיסוי, מאגרי כספת](/he/contributing/code-checks/) — שלוש בדיקות שתורמים פוגשים בקוד עצמו — אין מחרוזת גלויה למשתמש מחוץ ל-t(), כיסוי בדיקות על כל src/, וחבילת חוזה אחת שכל מאגר כספת עובר.
- [מערכת העיצוב](/he/contributing/design-system/) — האסימונים של Lumen לצבע, ריווח, רדיוס, טיפוגרפיה, הגבהה ותנועה, הכללים שהקוד עומד בהם, והרכיבים המשותפים.
- [הקול העברי הפתוח (ערכת הקלטה)](/he/contributing/hebrew-voice/) — איך מקליטים, בודקים ומאמנים את הקול העברי העצבי הראשון שמשוחרר ב-CC0, כדי שהקראה בעברית תהיה פתוחה לכל אפליקציה.
- [סקירה עצמאית](/he/contributing/independent-review/) — כל שינוי בנתיב רגיש צריך, לפני המיזוג, קבלת סקירה על ה-commit שבראש, מסוקר שלא כתב אותו, עם מבחני התקפה. גם ברכבות האינטגרציה.
- [קומפילציה של הקוד ה-native בלי רשת](/he/contributing/native-check/) — איך הקוד של Lumen ב-Rust, ב-Java וב-Swift מקומפל בלי crates.io, בלי Android SDK ובלי Xcode — מה הבדיקה מוכיחה, מה לא, ומה עדיין דורש Mac.
- [ריצות לילה וקבלות](/he/contributing/nightly/) — npm run nightly מריץ את ציד ה-flakes, בדיקות הביצועים, מיון הביקורות ובריאות התלויות השבועית על המחשב שלך, וכותב לכל אחד דוח חתום, בלי GitHub Actions.
- [בדיקת ה־PR](/he/contributing/pr-check/) — הפקודה npm run pr:check היא שער ה־PR המקומי שמחליף את Danger.js ואת size-limit. היא מדווחת על גודל החבילה מול הבסיס, על סעיפי תיאור ה־PR, על [skip ci] בקומיטים, על קריאות רשת לא רשומות, על רישיונות ועל כלל הדומיין.
- [לפני main, ‏WebKit ו-Safari](/he/contributing/promotion/) — ‏npm run promote:check מסרב לקדם את main לקומיט שאין לו קבלת WebKit חתומה וקבלת Safari חתומה. ‏WebKit רץ במפעל האימות, ו-Safari אמיתי רץ בתוכנית הקוד הפתוח של BrowserStack.
- [fuzz השחרה כל לילה](/he/contributing/redaction-fuzz/) — בכל לילה המארח השני מזין 20,000 פתקים מחוללים לתצוגה המקדימה ולייצוא, וכל קטע שהתצוגה מצללת והייצוא משאיר הופך למבחן קבוע.
- [מתחזק שני](/he/contributing/second-maintainer/) — הכניסה של המתחזק השני של Lumen — הרשאות, הבדיקות המקומיות, איך סוקרים שינוי רגיש ומוסיפים את התווית human-reviewed, דיווחי אבטחה, ומה רק הבעלים מחזיק היום.
- [בדיקות מדולגות](/he/contributing/skipped-tests/) — כל בדיקה מדולגת אומרת למה, באיזו משימה ועד מתי; npm run hygiene נכשל על בדיקה שלא אומרת, ו-npm run skips מציג את כולן.
- [כל PR על ראש הרכבת](/he/contributing/train-base/) — ‏pull request מבוסס על הרכבת הנוכחית או על main, ולעולם לא על ענף של PR אחר. ‏pr:check מכשיל בסיס מוערם וערימה בעומק גדול מ־1, מזהיר על רכבת ישנה ועל סחיפה, ומכשיל בסיס מיזוג ישן או criss-cross. ‏scripts/restack.mjs מדפיס איך להעביר PR מוערם אל הרכבת.
- [הרכבת השבועית](/he/contributing/train/) — איך רכבות האינטגרציה של Lumen נבנות, נבדקות ומקודמות, כל שבוע. ‏npm run train:build ממזג את ה־PR־ים ופותר מה שאפשר, ‏npm run train:status מראה את היומן ואת השערים, ו־main זז לפחות פעם בשבוע.
- [טיוטות תרגום](/he/contributing/translation-drafts/) — npm run i18n:draft מתרגם מחרוזות ממשק חדשות לשבע השפות עם מודל מקומי; הטיוטות נשארות "ממתינות לבדיקה" עד שאדם מאשר אותן.
- [שפות בבטא, ואיך לעזור](/he/contributing/translations/) — אנגלית ועברית הן השפות המלאות של Lumen; שש האחרות תורגמו במכונה ומסומנות בטא (תרגום מכונה, ממתין לבדיקת דובר/ת שפת אם). איך מדווחים על בעיה בתרגום מתוך האפליקציה.
- [רגרסיה חזותית](/he/contributing/visual-regression/) — npm run test:visual משווה עשרה מסכים בעברית ובאנגלית, בהיר וכהה, מול תמונות הבסיס שלהם — מקומית, בלי CI.
