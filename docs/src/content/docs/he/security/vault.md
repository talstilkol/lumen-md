Lumen מרחיקה את הסודות שהיא צריכה מהאחסון הגלוי של הדפדפן: מפתחות של ספקי
AI, טוקנים של Git ושל שירותי ענן, הסיסמה של חדר השיתוף ומפתח החיפוש של
המחקר. אפשר גם להצפין את הכספת כולה בסיסמה ובמפתח שחזור (ראו
[הצפנת הכספת במנוחה](/he/security/vault-encryption/)); הסודות שמתוארים כאן
נשמרים בנפרד ממנה.

## איפה הסודות נשמרים

| איפה Lumen רצה | איך הסודות נשמרים |
|---|---|
| דפדפן / אפליקציית רשת מותקנת | כל סוד מוצפן ב-AES-GCM-256 במפתח WebCrypto **שאי אפשר לייצא**: שום סקריפט לא יכול לשלוף את הבייטים של המפתח עצמו. הסודות כבר לא יושבים ב-localStorage כטקסט גלוי, כך שהצצה ב-DevTools, העתקה של localStorage או ייצוא מסונכרן של ההגדרות מראים רק טקסט מוצפן. |
| אפליקציית שולחן העבודה ב-macOS / Windows | מחזיק המפתחות של מערכת ההפעלה (Keychain / Credential Manager). Lumen שומרת רק את השמות של הסודות, כדי לדעת מה לטעון. |
| מנועים ישנים בלי IndexedDB או WebCrypto | localStorage רגיל, כמו קודם. Lumen מדווחת על המצב הזה ולא מסתירה אותו. |

**המגבלות, בלי כחל ושרק:**

- המפתח נשמר באותו מסד IndexedDB שבו נשמרים הסודות המוצפנים, ו-Lumen
  מפענחת אותם בהפעלה בלי לבקש סיסמה. לכן מי שמעתיק את פרופיל הדפדפן כולו
  ופותח אותו ב-Lumen יכול להשתמש במפתח השמור ולקרוא את הסודות. "אי אפשר
  לייצא" מונע *ייצוא* של המפתח, לא *שימוש* בו. הגנה מפני פרופיל מועתק
  דורשת סיסמה שאתם מקלידים (מתוכנן יחד עם הצפנת הכספת כולה, משימה 11.4) או
  את מחזיק המפתחות של מערכת ההפעלה באפליקציית שולחן העבודה.
- גם קוד שרץ בתוך המקור (origin) של Lumen עצמה יכול לבקש מ-WebCrypto
  לפענח. מה שמרחיק קוד זר הוא מדיניות אבטחת התוכן (CSP) ומנקה ה-HTML.

סודות בטקסט גלוי שגרסאות ישנות השאירו מוצפנים ומועברים בהפעלה.

## הצפנת מסמך

הפקודה **🔒 הצפנת מסמך** (⌘K) מצפינה את הפתק הפתוח ב-AES-256-GCM בסיסמה
שאתם מקלידים. הפתק מוחלף בבלוק מוצפן, והפקודה **🔓 פענוח מסמך** מחזירה
אותו. Lumen לא שומרת את הסיסמה: אם תאבדו אותה, אי אפשר לשחזר את הפתק. ראו
גם [הצפנה מקצה לקצה](/he/collab/encryption/).

## מה לא מוצפן

הפתקים עצמם הם קובצי Markdown רגילים (במערכת הקבצים הפרטית של הדפדפן, או
בתיקייה במחשב באפליקציית שולחן העבודה). הצפנה של הכספת כולה במנוחה היא
אפשרות, דרך **🔐 הצפנת הכספת…** (ראו
[הצפנת הכספת במנוחה](/he/security/vault-encryption/)).
