## הצעות, לבד או ביחד

הפעילו את **מצב ההצעות** (מעקב שינויים) מלוח הפקודות. מעכשיו, מה שאתם
מקלידים ומוחקים נכתב כהצעה, והטקסט עצמו לא משתנה עד שמישהו מקבל אותה:

```md
הדוח {++כמעט ++}{>>@דנה<<}מוכן{--, סוף סוף--}{>>@אבי<<}.
```

זה עובד בעורך המקור וב-WYSIWYG, לבד ובפתק משותף. בפתק משותף, כולם רואים
כל הצעה ברגע שהיא נכתבת.

## מי הציע מה

- ההצעות של כל מחבר מסומנות בקו תחתון בצבע משלו, וריחוף מעליהן מציג את
  השם.
- הצעות שה-AI כתב נושאות את המחבר **AI**, ומסומנות "AI".
- לוח הפקודות מציג כל מי שיש לו הצעה בפתק: **קבלת הכול מ-דנה (3)**
  ו**דחיית הכול מ-דנה (3)**, וכך לכל מחבר אחר, כולל ה-AI. הפקודות האלה
  מטפלות רק בהצעות של אותו אדם; ההצעות של כל השאר נשארות כמו שהן.

## גרסאות בשם

בפתק משותף, פתחו את **גרסאות בשם…** מלוח הפקודות.

- תנו שם לטקסט הנוכחי, למשל "לפני הגשה". הגרסה נשמרת בתוך הפתק המשותף,
  כך שכל מי שבפתק רואה את אותה רשימה. רק עורכים יכולים לשמור גרסה.
- בחרו שתי גרסאות כלשהן, או גרסה והטקסט הנוכחי, כדי להשוות ביניהן.
  ההשוואה היא מילה במילה: תוספות בירוק, מחיקות באדום, ולצידן כמה מילים
  נוספו וכמה הוסרו.
- ההשוואה בנויה לעברית. מילה שומרת על אותיות השימוש שלה (ו, ה, ב, ל, מ,
  ש, כ), על הניקוד שלה ועל גרש או גרשיים שבתוכה (צה״ל), ולכן "הבית" שהפך
  ל"ובית" מוצג כמילה אחת שהשתנתה, ולא כאות אחת.

## בדיקות

- עשרים מקרי השוואה בעברית, שמכסים אותיות שימוש, ניקוד, גרשיים, מספרים,
  פיסוק וטקסט מעורב בעברית ובאנגלית, נבדקים בכל הרצה.
- קבלה ודחייה לפי מחבר נבדקות כדי לוודא שהן משנות רק את ההצעות של אותו
  מחבר.
- בדיקה עם שני דפדפנים רצה דרך שרת השיתוף. משתתף מציע, והטקסט של הבעלים
  לא משתנה. הבעלים מקבל, והשינוי נכנס. אחר כך גרסה שהבעלים נתן לה שם
  מופיעה אצל המשתתף, עם ההשוואה מילה במילה.
