## מה issue מקבל

| מה | מתי | תווית |
|---|---|---|
| סוג | לפי מילים בכותרת ובגוף (עברית ואנגלית) | `bug`, ‏`enhancement`, ‏`question` או `documentation` |
| תחום | עד שניים — אלה שהמילים שלהם מופיעות הכי הרבה | `area:editor`, ‏`area:hebrew`, ‏`area:ai`, ‏`area:storage`, … |

**תגובה אחת**, בעברית ובאנגלית. הוא מזהה את התגובה שלו לפי סימון נסתר, ולכן
ריצה חוזרת לא מגיבה פעמיים. תוויות שעוד לא קיימות נוצרות.

## מה הוא לא עושה

- הוא לא סוגר, לא משייך ולא עורך issue, ולא מסיר תוויות.
- הטקסט של ה-issue רק מושווה לרשימות מילים: הוא לא מורץ ולא נשלח לשום מקום.
  הסקריפט מדבר רק עם ה-REST API של GitHub דרך `gh`, עם הטוקן של ה-workflow
  (`issues: write`).

## להריץ בעצמכם

