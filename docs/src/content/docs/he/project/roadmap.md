כל פריסה של Lumen מגישה מפת דרכים פתוחה ב-`/roadmap.html` (וגם ב-`/roadmap`
ב-Cloudflare Pages, ב-Netlify ובתמונת ה-Docker). הקישור **מפת דרכים** בשורת
המצב פותח אותה.

## מאיפה היא באה

הדף הוא הפלט השלישי של `npm run plan`, לצד הלוח ב-`MASTER_PLAN.md`
וב-`plan/board.html`. שלושתם נוצרים מקובץ אחד, `plan/plan.json`,
ו-`npm run plan:check` מכשיל את ה-CI כשאחד מהם לא תואם לו. כך מפת הדרכים
משתנה באותו commit שבו משתנה התוכנית — תמיד.

## מה היא מראה — ומה לא

| מוצג | לא מוצג |
|---|---|
| כל שלב, עם המספר והשם שלו | השלבים של משימה ושורת הקבלה שלה |
| המספר והכותרת של כל משימה | הערכות זמן, תאריכים ולוח הזמנים |
| המצב: **הושלם** (✅), **בעבודה** (⏳) או **מתוכנן** | ענפים, מספרי PR והפעולות של הבעלים (שלב 15) |
| הספירות וסרגל התקדמות | שום דבר מ-issues או מפתקים |

התוכנית המלאה, עם כל קריטריון קבלה מדוד, נמצאת בריפו.

## איך היא מוצגת

‏`public/roadmap.html` נושא את הנתונים כבלוק JSON, ו-`public/roadmap.js`
בונה את הכרטיסים עם `textContent`. הסקריפט חיצוני כי מדיניות ה-CSP של
האפליקציה לא מתירה סקריפט inline, והוא לא צריך מדיניות Trusted Types כי הוא
אף פעם לא כותב HTML. הדף בעברית ומימין לשמאל, עם מאפייני CSS לוגיים.

## עדכון

```bash
npm run plan        # כותב מחדש את הלוח ב-MASTER_PLAN.md, את plan/board.html ואת public/roadmap.html
npm run plan:check  # מה שה-CI מריץ: יוצא עם 1 כשאחד מהם לא מעודכן
```
