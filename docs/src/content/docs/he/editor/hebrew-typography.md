Word מתקן פיסוק עברי אוטומטית כבר עשרות שנים. ב-Lumen עורך המקור עושה את אותו
הדבר **תוך כדי הקלדה**, ו**טיפוגרפיה עברית…** בלוח הפקודות מחיל את הכללים על
פתק שלם אחרי תצוגה מקדימה.

| כלל | מקלידים | מקבלים |
|---|---|---|
| גרשיים | `צה"ל` | צה״ל |
| גרש | `ג'ירפה` | ג׳ירפה |
| מירכאות עבריות | `"שלום"` | „שלום” |
| מקף | `בית-ספר` | בית־ספר |
| קו מפריד בין מילים | `אחד - שניים` | אחד – שניים |
| מספרים | `50 %`, `%50`, `10–20` | 50%, 50%, 10-20 (טווח שנקרא בסדר הנכון מימין לשמאל) |
| שורות מעורבות | `HTML היא שפה.` | סימן כיוון בלתי נראה (RLM) בתחילת השורה, כך שהיא נקראת מימין לשמאל והנקודה מגיעה לסופה |

כל כלל פועל רק בהקשר עברי. `say "hello"`, ‏`it's` ו-`ב-2026` נשארים כמו שהם,
וכך גם אות שימוש לפני מירכאות: `ו"ההגנה"` הופך ל-ו„ההגנה”, לא לגרשיים.

## מה לא משתנה אף פעם

שום דבר לא משתנה בתוך **קוד** (בלוקים מגודרים וקוד בשורה), **קישורים**
וכתובות, קישורי wiki, תגי HTML, מתמטיקה או **ה-frontmatter**.

## ביטול

כל תיקון הוא צעד ביטול נפרד. **Ctrl+Z / ⌘Z** מיד אחרי תיקון מחזיר את התו
שהקלדתם, והמקשים הבאים לא מתקנים אותו שוב. מירכאות מיד אחרי אות עברית מתוקנות
כשמקלידים את המקש הבא, כי רק אז ברור אם אלה גרשיים (צה"ל) או מירכאות סוגרות ”.

## כיבוי כללים

ב**טיפוגרפיה עברית…** (לוח הפקודות):

- **תיקון תוך כדי הקלדה** מפעיל או מכבה את התיקונים האוטומטיים.
- לכל כלל יש תיבת סימון משלו.
- החלון מפרט כל שינוי שהכללים יעשו בפתק הנוכחי. **החלה על הפתק** מבצעת את
  כולם כצעד ביטול אחד.

ההגדרות נשמרות בדפדפן הזה.
