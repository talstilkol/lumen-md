## ציטוט בשתי הקשות

לוחצים `⌥⌘C` (או `⌘K ← "הוספת ציטוט ‎[@key]…"`) כדי לפתוח את חלון
הציטוט. הוא מחפש בכל הספרייה בבת אחת.

- כשלא הקלדתם כלום, המקורות שציטטתם לאחרונה מופיעים ראשונים: **Enter**
  מצטט שוב את האחרון, ו־**↓ Enter** את זה שלפניו.
- מקלידים כדי לחפש לפי מחבר, כותרת, שנה או מפתח. עברית עובדת.
- **Tab** עובר לשדה המיקום (`עמ׳ 12`,‏ `p. 10`,‏ `chap. 3`).
- **Enter** כותב `[@key]`. ‏**⇧Enter** כותב `@key`, לציטוט בתוך המשפט.

## הספרייה

הספרייה היא כל מה שבכספת, ונקראת במכשיר הזה:

- **BibTeX**: כל קובץ `*.bib`.
- **CSL-JSON**: ‏`*.csl.json`,‏ `references.json` או `bibliography.json`
  (‏Zotero,‏ Zettlr ו־pandoc מייצאים כולם את הפורמט הזה).
- **Zotero**: באפליקציית שולחן העבודה מריצים `⌘K ← "ציטוטים: העתקת
  ספריית Zotero לכספת"`, או לוחצים **העתקה מ־Zotero** בחלון. זה מעתיק את
  הספרייה של Zotero 7 מהמחשב הזה אל `.lumen/zotero-library.csl.json`
  (קודם מפעילים ב־Zotero: הגדרות ← מתקדם ← "Allow other applications on
  this computer to communicate with Zotero").

המפתחות מגיעים מהמקור: מפתח ה־BibTeX, ה־`citation-key` של CSL, או שורת
`Citation Key:` מ־Better BibTeX. אחרת המפתח הוא שם המשפחה של המחבר והשנה
(‏`austen1813`,‏ `כהן2020`).

## Zotero בלי האפליקציה השולחנית

בדפדפן ובטלפון, **⌘K ← ציטוטים: סנכרון ספריית Zotero מ-zotero.org (קריאה
בלבד)** קורא את הספרייה שלך מה-Web API של Zotero. Zotero Desktop לא צריך
להיות פתוח.

1. ב-zotero.org, פותחים **Settings ← Security ← Applications** ויוצרים מפתח
   עם גישת **קריאה בלבד** לספרייה.
2. מריצים את הפקודה ומדביקים את המפתח. הוא נשמר בכספת הסודות של המכשיר
   ונשלח רק ל-`api.zotero.org`, בכותרת `Zotero-API-Key`. כל בקשה מופיעה
   ביומן הפרטיות כמסלול ענן. מדיניות AI ופרטיות **מקומית בלבד** חוסמת
   אותו.
3. המקורות מצטרפים לדיאלוג הציטוט, כמו העותק מהאפליקציה השולחנית. פריטים
   עם הערות או קובצי PDF מקבלים גם פתק ב-`Zotero/`, שבראשו ה-`[@key]` שלהם.
   בפתק: ההערות מ-Zotero כ-Markdown, קישור שפותח כל PDF ב-Zotero, וקישור
   אליו ב-zotero.org.

הסנכרון הבא מבקש רק את מה שהשתנה מאז הקודם. אם שום דבר לא השתנה, Zotero
עונה בתשובה ריקה אחת (`304`). אחרת Lumen מביא את הפריטים שהשתנו, עד 50
בבקשה, ומסיר את אלה שנמחקו. Lumen אף פעם לא כותב ל-Zotero. אם Zotero מבקש
להאט (`Backoff`, `429`), Lumen ממתין.

## תחביר pandoc

| כותבים | APA 7 מציג |
|---|---|
| `[@austen1813]` | ‏(Austen, 1813) |
| `[@austen1813, p. 10]` | ‏(Austen, 1813, p. 10) |
| `[see @austen1813, pp. 10–12; @darwin1859]` | ‏(see Austen, 1813, pp. 10–12; Darwin, 1859) |
| `[-@austen1813]` | ‏(1813) |
| `@austen1813 [p. 10] writes` | ‏Austen (1813, p. 10) writes |

המיקום יכול להיות עמודים, פרקים, סעיפים, איורים, כרכים, פסקאות, הערות או
שורות, בעברית או באנגלית. ‏Chicago כותב את העמוד בלי "p."
(‏`(Austen 1813, 10)`), וכך גם MLA (‏`(Austen 10)`).

מפתח שהספרייה לא מכירה נשאר כמו שכתבתם אותו.

## סגנונות

קובעים את הסגנון ב־frontmatter של הפתק:

```yaml
---
citation-style: il      # apa (ברירת מחדל), chicago, mla, il
---
```

- **APA 7**,‏ **Chicago author-date** ו־**MLA 9** משתמשים בתבניות של
  6.13, בשפת הפתק (בפתק עברי: ו, ואחרים, עמ׳).
- **il** הוא APA 7 כפי שהספריות האקדמיות בישראל מלמדות אותו:
  - המקורות בעברית באים ראשונים, ברשימה משלהם, ואחריהם השאר.
  - כל מקור נכתב בשפה שלו.
  - ראשי תיבות של שמות עבריים נכתבים עם גרש: `דרשן, ד׳`.
  - אותו מחבר ואותה שנה מובחנים באותיות א / ב (ובשפות אחרות a / b).

רשימת המקורות נכנסת במקום שבו בפתק יש את הבלוק `::: {#refs}` של
pandoc, או בסוף הפתק. היא מופיעה בתצוגה, בהדפסה ל־PDF וב**ייצוא
ל־Word**.

כל העיצוב נעשה בקוד של האפליקציה עצמה, בלי citeproc ובלי שום הורדה.
