**הגדרות ← ערכת נושא** (בפלטת הפקודות: *הגדרות ערכת נושא*) משנה את המראה
של Lumen בזמן אמת, בלי רענון: החלפת ערכת נושא לוקחת פריים אחד.

## ערכות הנושא המובנות

| ערכה | בשביל |
|---|---|
| ברירת מחדל | הצבעים של Lumen, בהיר וכהה |
| ספיה | נייר חם, פחות סנוור |
| נורד | כחול-אפור קריר |
| ניגודיות גבוהה | שחור על לבן ולבן על שחור, טקסט ב-7:1 |
| **כתב (קריאה בעברית)** | נייר ודיו, סריף עברי בעורך ובתצוגה המקדימה, יותר רווח בין השורות |

כל ערכות הנושא עוברות WCAG AA גם בבהיר וגם בכהה: טקסט רגיל וטקסט משני
ביחס של 4.5:1 לפחות מול הרקע, צבע ההדגשה ב-3:1, וטקסט על צבע ההדגשה
ב-4.5:1. החלק **ניגודיות** בהגדרות מציג את המספרים למה שבחרתם, כולל צבע
הדגשה משלכם.

**כתב** מעבירה את העורך ואת התצוגה המקדימה לסריף עברי שמגיע עם מערכת ההפעלה
(Frank Ruehl CLM,‏ David,‏ Noto Serif Hebrew, ואז Times New Roman),
בגודל 16px, עם גובה שורה 1.85 ורוחב שורה של 70 תווים. אפשר לשנות כל אחד
מהם אחרי שבוחרים את הערכה.

## קובצי ערכת נושא והטוקנים

**ייצוא** שומר את ערכת הנושא כ-JSON; **ייבוא** קורא אחת בחזרה, עם בדיקה
קפדנית (עד 8KB, מפתחות לא מוכרים נדחים). ערכת נושא קובעת רק את הטוקנים
המתועדים: משתני ה-CSS שבטבלה, שנצרכים כ-`hsl(var(--token))`.

| טוקן | מה הוא |
|---|---|
| `--bg`,‏ `--bg-subtle`,‏ `--bg-muted`,‏ `--bg-inset` | רקעים, מהעמוד ועד שקעים |
| `--fg`,‏ `--fg-subtle`,‏ `--fg-muted` | טקסט, מגוף הטקסט ועד רמזים |
| `--border`,‏ `--border-strong` | קווים |
| `--accent`,‏ `--accent-fg` | קישורים, מיקוד, כפתורים; טקסט על צבע ההדגשה |
| `--editor-font`,‏ `--editor-font-size`,‏ `--editor-line-height` | הגופן של העורך |
| `--content-width`,‏ `--preview-width` | רוחב השורה בעורך ובתצוגה המקדימה |
| `--font-serif`,‏ `--preview-line-height` | הגופן של התצוגה המקדימה (כתב קובעת אותם) |

שאר הטוקנים של מערכת העיצוב — מרווחים, עיגולי פינות, צללים, תנועה — מפורטים
ב*תרומה ← מערכת העיצוב*; גם קטעים יכולים להשתמש בהם.

## קטעי CSS

שימו קובצי ‎`.css` בתיקייה ‎`.lumen/snippets/`‎ שבכספת (Lumen קורא גם את
‎`.obsidian/snippets/`‎, כך שכספת שהגיעה מ-Obsidian שומרת את הקטעים שלה). כל
אחד מופיע תחת **קטעי CSS** בהגדרות ערכת הנושא, עם מתג. שינויים בקבצים חלים
ברגע ששומרים אותם.

קטעים יכולים לשנות כל דבר במראה, אבל **הם לא יכולים לטעון שום דבר מהרשת**.
לפני שקטע מגיע לעמוד, Lumen קורא אותו כמו שהדפדפן קורא, ומסיר:

- כל ‎`@import`;
- כל הצהרה עם ‎`url()`,‏ `image-set()`,‏ `image()`,‏ `cross-fade()`,‏
  `element()` או ‎`attr(… url)`‎ שמצביעה על משהו שאינו תמונה או גופן ב-`data:`
  או ‎`#fragment`. זה תקף בכל צורת כתיבה: ‎`URL(`, ‏`u\72l(`, עם מירכאות או
  בלי, בתוך משתנה CSS או בברירת המחדל של ‎`var()`;
- ווים ישנים לסקריפטים (‎`expression()`,‏ `behavior`,‏ `-moz-binding`) ו-‎`@document`.

ההגדרות מראות מה הוסר, עם השורה והסיבה. מדיניות אבטחת התוכן (CSP) של העמוד
היא קו שני, אבל לבדה היא הייתה מאפשרת לגיליון סגנונות לטעון תמונות מכל אתר
HTTPS, ולכן ה-sanitizer הוא מה שמרחיק קטעים מהרשת. כקו שלישי, Lumen מאזין לכל
בקשה שגיליון סגנונות שולח לאתר אחר, ו**יומן הפרטיות** היה מציג אותה. הבדיקות
מוודאות שקטע מלא בכתובות מרוחקות לא שולח אף בקשה.
