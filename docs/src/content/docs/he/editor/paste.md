רוב הטקסט נכנס לפתק בהדבקה. Lumen הופך את מה שיש בלוח ל-Markdown נקי,
בשני העורכים.

## מה נשמר

- כותרות, כולל סגנונות הכותרת והכותרת הראשית של Word.
- רשימות תבליטים ורשימות ממוספרות, כולל רשימות מקוננות. Word ו-Google Docs
  כותבים רשימות כל אחד בדרך שלו (Word כפסקאות מוזחות, Docs כרשימה שטוחה
  אחת לכל רמה), ו-Lumen בונה אותן מחדש כרשימות מקוננות אמיתיות.
- טבלאות, עם ההדגשות, הקישורים וירידות השורה שבכל תא.
- קישורים ותמונות.
- הדגשה, נטוי, קו חוצה וקוד. ב-Google Docs אלה מסומנים בסגנונות ולא
  בתגיות, ו-Lumen קורא את הסגנונות.
- ציטוטים, כולל התשובה המצוטטת בהודעת Gmail.

## מה מושמט

- כל סגנון מוטבע: גופנים, גדלים, צבעים, שוליים ויישור. הדבקה אף פעם לא
  מכניסה לפתק `style=`.
- תכונות כיוון (`dir`). כל פסקה מוצאת את הכיוון שלה בעצמה, כך שפסקה בעברית
  יושבת מימין ופסקה באנגלית משמאל.
- תווי כיוון בלתי נראים (LRE,‏ RLE,‏ PDF,‏ LRO,‏ RLO, תווי הבידוד, וסימנים
  כפולים). ‏LRM או RLM נשארים רק במקום שבו הם קובעים את סדר הטקסט שמיד
  אחריהם, כמו ב-`שלום‎ (2)`.
- רעש של אתרים: סקריפטים, טפסים, קישורי העריכה וסימני ההערות של ויקיפדיה,
  וחתימות של דוא"ל.

## שתי דרכים להדביק

| | עורך המקור | WYSIWYG |
|---|---|---|
| **Ctrl+V / ⌘V** | HTML עם מבנה הופך ל-Markdown. קוד שהועתק מעורך קוד נשאר טקסט פשוט. | ה-HTML המנוקה הופך לכותרות, לרשימות ולטבלאות. |
| **הדבקה כטקסט פשוט** (לוח הפקודות) | הטקסט שבלוח, כמו שהוא | הטקסט שבלוח, כמו שהוא |
| **הדבקה עם עיצוב** (לוח הפקודות) | ממיר את ה-HTML תמיד | ממיר את ה-HTML תמיד |

הפקודות שבלוח הפקודות קוראות את הלוח, ולכן הדפדפן עשוי לבקש הרשאה בפעם
הראשונה.

## בדיקות

שלושים דוגמאות של תוכן לוח מומרות בכל הרצת בדיקות, וכל אחת נבדקת מול
ה-Markdown הצפוי שלה. הן מכסות את Word,‏ Google Docs, ויקיפדיה (באנגלית
ובעברית), אתר חדשות בעברית ו-Gmail, בעברית, באנגלית ובטקסט מעורב. ההרצה
בודקת גם שאין אף סגנון מוטבע ואף סימן כיוון מיותר.
