## רשימות חכמות

ברשימה, המקשים עושים את מה שהתכוונתם:

| מקש | בפריט רשימה |
| --- | --- |
| `Enter` | פריט חדש: המספר הבא (`3.` אחרי `2.`, `ב.` אחרי `א.`), תיבה ריקה אחרי משימה, ושאר השורה עוברת איתו. הפריטים שאחריו ממוספרים מחדש. בפריט ריק: רמה אחת החוצה, או סוף הרשימה. |
| `Shift+Enter` | שורה חדשה בתוך אותו פריט |
| `Tab` / `Shift+Tab` | רמה אחת פנימה / החוצה, עם תתי־הפריטים שלו. פריט לא נכנס יותר מרמה אחת מתחת לפריט שמעליו. |
| `Alt+↑` / `Alt+↓` | העברת הפריט, עם תתי־הפריטים, מעל או מתחת לשכן שלו |
| `Backspace` | בתחילת הטקסט של הפריט: הסרת התבליט או המספר |
| `⌘Enter` | הוספת תיבת משימה, סימון, הסרה |
| `⌘B` | מודגש. בחירת חלק מביטוי מודגש מוציאה את החלק הזה מההדגשה; בחירה שחוצה את קצה הביטוי מדגישה את כולו. |

הדבקת רשימה לתוך פריט לא מוסיפה תבליט שני, ותתי־הפריטים המודבקים שומרים על
הרמות שלהם מתחת לפריט. רשימות ממוספרות באותיות (`א.`, `ב.` … `י.`, `יא.` …
`טו.`, `טז.`) ממוספרות מעצמן כמו ספרות.

## כמה סמנים

| מקש | מה עושה |
| --- | --- |
| `Alt` + גרירה | בחירת עמודה (מלבן), למשל עמודה אחת של טבלה — הסמן הופך לצלב כל עוד `Alt` לחוץ |
| `⌘` + לחיצה | סמן נוסף |
| `⌘D` | בחירת המילה שמתחת לסמן, ואחר כך כל מופע הבא שלה (מילה עברית עם ניקוד היא מילה אחת; `ושלום` איננה `שלום`) |
| `Esc` | חזרה לסמן אחד |

מה שמקלידים אז נכנס בכל הסמנים.

## מצב Vim

מפעילים ב**הגדרות ← כללי ← הפעלת מצב Vim** (או מחפשים בהגדרות *vim*).
מקשי Vim נטענים רק אז.

- בשורה עברית, `h` ו-`l` זזים שמאלה וימינה על המסך, כמו *rightleft* של Vim;
  `w`, ‏`b` ו-`e` זזים לפי מילים בסדר הקריאה. אות עם הניקוד שלה היא תו אחד.
- `:w` שומר, `:q` סוגר את הלשונית, `:wq` ו-`:x` עושים את שניהם.
- `Esc` בזמן שבקשת AI רצה מבטל את הבקשה ומשאיר אתכם במצב הקלדה; ה-`Esc`
  הבא יוצא ממצב הקלדה.
- כשמצב Vim פעיל, גם מסך ההגדרות זז ב-`j` וב-`k`, ו-`/` עובר לתיבת החיפוש שלו.
