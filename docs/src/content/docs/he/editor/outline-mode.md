Logseq,‏ Tana ו-Workflowy הפכו כתיבה במתאר לדרך עבודה בפני עצמה. Lumen נותן
את אותן פעולות על פתק Markdown רגיל: הקובץ נשאר Markdown פשוט, ושום דבר לא
נוסף אליו.

## מה זה בלוק

- **כותרת** יחד עם הפרק שלה: כל מה שעד הכותרת הבאה באותה רמה או ברמה גבוהה
  ממנה.
- **פריט ברשימה** יחד עם הילדים שלו: השורות המוזחות תחתיו.
- כל בלוק אחר ברמה העליונה: פסקה, בלוק קוד, טבלה, ציטוט.

קוד אף פעם אינו מבנה: שורת `#` או שורת `- ` בתוך בלוק קוד נשארות כמו שהן.

## הפעולות

הן עובדות אותו דבר בעורך המקור וב-WYSIWYG, ובעברית (מימין לשמאל) כמו
באנגלית. כל אחת נמצאת גם בלוח הפקודות, תחת **מתאר: …**.

| פעולה | מקשים (Windows / Linux) | macOS |
|---|---|---|
| הזזת בלוק למעלה / למטה | Alt+Shift+↑ / ↓ | ⌥⇧↑ / ↓ |
| הזחה / ביטול הזחה | Ctrl+Alt+→ / ← | ⌘⌥→ / ← |
| שכפול בלוק | Alt+Shift+D | ⌥⇧D |
| מחיקת בלוק | Alt+Shift+Backspace | ⌥⇧⌫ |
| קיפול / פתיחה | Ctrl+Alt+↑ / ↓ | ⌘⌥↑ / ↓ |
| זום לתוך הבלוק / יציאה | Ctrl+Alt+Enter ‏(Escape יוצא) | ⌘⌥↵ |
| קיפול הכול / פתיחת הכול | לוח הפקודות | לוח הפקודות |

- **הזזה** מחליפה את הבלוק עם השכן שלו באותה רמה, והשורות הריקות נשארות
  במקומן. כותרת זזה עם כל הפרק שלה; פריט זז עם הילדים שלו. הילד הראשון של
  פרק או של רשימה לא יוצא מההורה שלו.
- **הזחה** של פריט הופכת אותו לילד האחרון של הפריט שלפניו; ביטול הזחה מעלה
  אותו רמה אחת. הזחה של כותרת מורידה את כל הפרק שלה רמה (`#` ← `##`, וכל
  כותרות המשנה איתה).
- **בשורה מימין לשמאל החצים הולכים עם הטקסט**: החץ שמצביע לסוף השורה מזיח.
  בעברית זה Ctrl+Alt+←.
- **זום** מציג רק את הבלוק ואת הילדים שלו, עם סרגל שמחזיר לכל הפתק.

גרירה של בלוקים יש בעורך ה-WYSIWYG (הידית ⠿ ליד בלוק).

## פתיחת פתק כמתאר

**פתיחת הפתק כמתאר** בלוח הפקודות מוסיפה מתגי קיפול ליד כותרות ופריטים
ומקפלת הכול לרמה העליונה — פתק מ-Logseq, שבנוי מפריטי `- ` מקוננים, נפתח
כמתאר שאפשר לפתוח צעד אחר צעד. הפעלה נוספת מכבה את המצב. הבחירה נשמרת לכל
פתק.

## שום דבר לא נכנס לקובץ

קיפול וזום משנים רק את מה שרואים. הפתק זהה בייט-לבייט אחרי קיפול, זום
ופתיחה. אילו בלוקים מקופלים נשמר לכל פתק בדפדפן (localStorage), לא בקובץ,
כך שהקובץ נקרא אותו דבר בכל עורך אחר וב-Git. פרק שקופל בעורך אחד מקופל גם
בשני.
