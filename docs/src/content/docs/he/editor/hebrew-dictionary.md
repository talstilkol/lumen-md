לחיצה ימנית על מילה בעברית בעורך מציגה את **המילים הנרדפות** שלה, את **ההגדרה** שלה או את
**הניקוד** שלה. הכול נבדק במכשיר הזה, מתוך חבילת מילון שמורידים פעם אחת.

## הורדת המילון

לוח הפקודות (**⌘K / Ctrl+K**) ← **מילון עברי ומילים נרדפות (הורדה / הסרה)**. Lumen מציג את
גודל החבילה, את מספר הערכים ואת הרישיון, ומוריד אותה רק אחרי שתסכימו. החבילה מגיעה מהאתר של
Lumen עצמו ונבדקת מול הגודל וסכום הביקורת שפורסמו. היא נשמרת באחסון של הדפדפן, ולכן עובדת
גם בלי רשת. כדי להסיר אותה, הריצו שוב את אותה פקודה.

## שימוש

- **לחיצה ימנית** על מילה בעברית: **מילים נרדפות**, **הגדרה**, **ניקוד המילה**.
  **Shift+לחיצה ימנית** פותחת את התפריט של הדפדפן (העתקה, הדבקה, איות).
- או: הציבו את הסמן על המילה והריצו **חפש במילון את המילה שליד הסמן**.
- אותיות שימוש מזוהות: **ובבית** מוצאת את **בית**. מילה נרדפת שלוחצים עליה מחליפה את המילה
  ושומרת על אותיות השימוש (**ובבית** ← **ובדירה**). הצורה המנוקדת מחליפה את המילה באותו
  אופן, ואותיות השימוש נשארות בלי ניקוד.
- טקסט מנוקד נבדק בלי הניקוד.
- מילים נרדפות עובדות בשני הכיוונים: אם ערך אחד מציין מילה אחרת כנרדפת, גם המילה האחרת
  מציגה אותו.

שום דבר בפתק לא משתנה עד שבוחרים מילה, ואז רק המילה הזו, ורק אם היא עדיין שם.

## מאיפה המילים

החבילה נבנית מ**ויקימילון העברי** (he.wiktionary.org), שהטקסט שלו ברישיון **CC BY-SA 4.0**.
לכל ערך נשמרים הערך המנוקד, חלק הדיבר, עד ארבע הגדרות (מקוצרות, בלי דוגמאות) וסעיף המילים
הנרדפות. הקרדיט מופיע ב**קרדיטים** (לוח הפקודות) ובחלון המילון, והחבילה מגיעה עם הרישיון
שלה (`public/lexicon/LICENSE.md`).

**למה ויקימילון ולא Hspell:** רשימות המילים של Hspell הן ברישיון AGPL-3.0, שלא ניתן לכלול
בתוך Lumen (MIT). בודק האיות של Lumen עדיין מציע את Hspell כהורדה נפרדת מהמקור שלו. רישיון
CC BY-SA של ויקימילון חל על החבילה, שהיא קובץ נפרד, ולא על הקוד של Lumen.

## בניית החבילה (למתחזקים)

```bash
curl -LO https://dumps.wikimedia.org/hewiktionary/latest/hewiktionary-latest-pages-articles.xml.bz2
npm run lexicon:build -- hewiktionary-latest-pages-articles.xml.bz2 20261101
```

הפקודה כותבת את `public/lexicon/he-wiktionary.json` ואת `public/lexicon/manifest.json` (גודל,
sha256, מספר ערכים). מעלים את שניהם, והאפליקציה מציעה את ההורדה מרגע שקובץ ה-manifest קיים.
התוכנית דורשת לפחות 20,000 ערכים וחיפוש של 20ms לכל היותר. החיפוש הוא שליפה מטבלת גיבוב ועוד
לכל היותר שלוש אותיות שימוש מקולפות; בדיקה מריצה 2,000 חיפושים בחבילה של 25,000 ערכים, וכל
אחד מהם מתחת ל-20ms.
