‏Lumen נמצא במרחק הקשה אחת בטלפון, בעברית ובאנגלית.

## במסך הבית

ל**ווידג'ט של Lumen** (אייפון ואנדרואיד) יש שלושה כפתורים:

- **חיפוש** פותח את החיפוש.
- **פתק מהיר** פותח את תיבת הלכידה, עם הסמן בתוכה.
- **היום** פותח את הפתק היומי של היום.

הווידג'ט לא מציג טקסט מהפתקים. בעברית הכפתורים מסודרים מימין לשמאל.

## ‏Siri, ‏Spotlight וקיצורים (אייפון)

הפקודות האלה עובדות בלי הגדרה. אפשר לומר אותן ל-Siri, להקליד אותן
ב-Spotlight או למצוא אותן באפליקציית הקיצורים:

| מה אומרים או מחפשים | מה קורה |
|---|---|
| „הוסף לתיבת הלכידה של Lumen” | ‏Siri שואלת מה להוסיף ומוסיפה את זה לסוף `inbox.md`, בלי לפתוח את Lumen |
| „פתק מהיר ב-Lumen” | פותח את תיבת הלכידה |
| „פתק קולי ב-Lumen” | פותח את התיבה ומתחיל להקליט |
| „חפש ב-Lumen” | פותח את החיפוש (ומאפליקציית הקיצורים, עם מילות החיפוש) |
| „הפתק של היום ב-Lumen” | פותח את הפתק של היום |

באנגלית: "Add to Lumen inbox", ‏"Quick note in Lumen", ‏"Search Lumen" וכן
הלאה.

*הוספה לתיבה* עובדת גם כש-Lumen סגור. הטקסט מחכה בטלפון, ובפעם הבאה
ש-Lumen נפתח הוא נכנס ל-`inbox.md`, עם השעה שבה אמרתם אותו. כל שורה נוספת
פעם אחת, ושום דבר לא הולך לאיבוד אם Lumen נסגר שוב לפני כן.

## ממסך הנעילה וממרכז הבקרה (אייפון)

לוכדים שורה עוד לפני ש-Lumen נטען:

- **ווידג׳ט במסך הנעילה:** עורכים את מסך הנעילה ← מוסיפים את **לכידה**
  של Lumen (עגול, רחב או בשורה אחת).
- **מרכז הבקרה (iOS 18 ומעלה):** עורכים את מרכז הבקרה, או את שני הכפתורים
  של מסך הנעילה, ← מוסיפים את **לכידה לתיבה**.
- **קיצורים:** „לכידה ב-Lumen”.

כל אחד מהם פותח מיד תיבת טקסט קטנה, לפני ששאר Lumen נטען. מקלידים, מקישים
**שמירה**, והשורה נכנסת לסוף `inbox.md`, עם השעה שבה הקלדתם אותה. אם התיבה
לא מצליחה לשמור, היא אומרת זאת ומשאירה את הטקסט.

## שיתוף ל-Lumen (אייפון)

בכל אפליקציה מקישים **שיתוף** ← **Lumen**. טקסט, קישור (עם כותרת הדף),
תמונות ו-PDF נשמרים בלי לפתוח את Lumen. בפעם הבאה ש-Lumen נפתח:

- טקסט וקישורים נכנסים ל-`inbox.md`;
- תמונות ו-PDF נשמרים ב-`attachments/`, ושורה בתיבה מקשרת אליהם, עם שם
  הקובץ.

## שיתוף והגדרות מהירות (אנדרואיד)

- **שיתוף ← Lumen** מכל אפליקציה: טקסט, קישור, תמונות ו-PDF (אחד או כמה)
  נשמרים בלי לפתוח את Lumen. הודעה ששותפה מ-WhatsApp או מ-Telegram שומרת
  את האפליקציה, הכותב והשעה.
- **אריח בהגדרות המהירות:** מושכים את הווילון, עורכים את האריחים ומוסיפים
  את **לכידה**. הקשה פותחת תיבה קטנה. מקלידים שורה ומקישים **שמירה**; היא
  נכנסת ל-`inbox.md` בפעם הבאה ש-Lumen נפתח.

## קיצורי אפליקציה (אנדרואיד)

לחיצה ארוכה על הסמל של Lumen: **פתק מהיר**, **פתק קולי**, **חיפוש**
ו**היום**. אפשר לגרור כל אחד מהם למסך הבית כדי שיישאר שם.

## קישורים לאפליקציות אחרות

כל כפתור בווידג'ט וכל קיצור הוא קישור, ואפליקציות ואוטומציות אחרות יכולות
להשתמש בו:

| קישור | מה הוא עושה |
|---|---|
| `lumen://capture` | פותח את תיבת הלכידה |
| `lumen://capture?mode=voice` | פותח את התיבה ומתחיל להקליט |
| `lumen://capture?text=…` | מוסיף את הטקסט לתיבת הלכידה |
| `lumen://new` | פותח פתק חדש |
| `lumen://search?q=…` | פותח חיפוש עם מילות החיפוש |
| `lumen://daily` | פותח את הפתק של היום |

## למתחזקים: איך בונים

לחלקים המקוריים יש כלל אחד: הם רק מעבירים לאפליקציה קישור או שורה שחיכתה
בתור. מה כל קישור עושה נקבע ב-`src/mobile/nativeActions.ts`, שנבדק
(`src/__tests__/widgets.test.ts`). עוזר הקישורים באנדרואיד הוא
`LumenActions.java`, ‏Java רגיל שנבדק עם `javac`.

### ‏iOS ‏(Xcode)

פרויקט ה-Xcode כבר מכיל הכול (`ios/App/App.xcodeproj`, ונבדק ב-`src/__tests__/iosProject.test.ts`):

- היעד **App** מקמפל את `AppDelegate.swift`, ‏`LumenNative.swift`,
  ‏`LumenIntents.swift`, ‏`NativeCapture.swift` (תיבת הלכידה),
  ‏`iCloudSync.swift` ו-`Shared/CaptureQueue.swift`, עם `en.lproj` /
  ‏`he.lproj` (`Localizable.strings`, ‏`AppShortcuts.strings`); עברית היא שפה
  של הפרויקט;
- הרחבת הווידג׳ט **LumenWidgets** ‏(`com.lumen.editor.LumenWidgets`)
  מקמפלת את `LumenWidgets/LumenWidgets.swift` (הווידג׳ט של מסך הבית
  והחבילה) ואת `LumenControls.swift` (הווידג׳ט של מסך הנעילה והפקד של מרכז
  הבקרה), עם המחרוזות, ה-`Info.plist` וה-entitlements שלה, והאפליקציה
  מטמיעה אותה. אין צורך להוסיף יעד Widget Extension ביד;
- הרחבת השיתוף **LumenShare** ‏(`com.lumen.editor.LumenShare`) מקמפלת את
  ‏`LumenShare/ShareViewController.swift` ואת `Shared/CaptureQueue.swift`,
  והאפליקציה מטמיעה אותה;
- לשלושת היעדים יש את ה-App Group ‏`group.com.lumen.editor`
  ב-entitlements. תור הלכידות נמצא שם: קובץ אחד לכל לכידה, שנכתב באופן
  אטומי, והאפליקציה קוראת אותו (`src/mobile/captureQueue.ts`, נבדק
  ב-`src/__tests__/captureQueue.test.ts`).

כדי לבנות:

1. ‏`npm run build && npx cap sync ios`, ואז פותחים את `ios/App/App.xcworkspace`
   (או את `App.xcodeproj` עם Swift Package Manager).
2. **חתימה:** אותו צוות ליעדים App, ‏LumenWidgets ו-LumenShare (החשבונות
   בתוכנית 15.7), ורושמים את ה-App Group ‏`group.com.lumen.editor` לשלושת
   מזהי החבילה בחשבון המפתחים.
3. ‏`Main.storyboard` כבר משתמש ב-`MainViewController`, שרושם את התוסף של
   האפליקציה. בודקים שהמחלקה מציגה *Module: App*.
4. בונים ומריצים במכשיר. לחיצה ארוכה על מסך הבית → **+** → **Lumen** כדי
   להוסיף את הווידג׳ט.

### ‏Android ‏(Android Studio)

הכול כבר בפרויקט: הווידג'ט (`LumenWidgetProvider`,
‏`res/layout/widget_lumen.xml`, ‏`res/xml/widget_lumen_info.xml`), קיצורי
האפליקציה (`res/xml/shortcuts.xml`), מסנן ה-intent של `lumen://`, התוסף,
ש-`MainActivity` רושם, גיליון השיתוף (`ShareActivity`), והאריח בהגדרות
המהירות (`CaptureTileService`) עם תיבת הלכידה שלו (`CaptureActivity`). התור
שהם כותבים אליו הוא `CaptureQueue.java`, בתיקיית הקבצים של האפליקציה.

בלי ה-SDK, ‏`tools/native-check/check-android.sh .` מקמפל את ה-Java מול
stubs ובודק כל הפניה למשאב, ו-`tools/native-check/test-android.sh .` מריץ
את בדיקות ה-JUnit של התור. עם ה-SDK, ‏`cd android && ./gradlew test lint`
מריץ את אותן בדיקות ואת ה-lint של Android.

1. `npm run build && npx cap sync android`, ואז פותחים את `android/`
   ב-Android Studio.
2. ‏Build ← Make Project, ומריצים על מכשיר או אמולטור (API 26 ומעלה).
3. לחיצה ארוכה על מסך הבית ← **Widgets** ← **Lumen** מוסיפה את הווידג'ט.
   לחיצה ארוכה על סמל האפליקציה מציגה את הקיצורים.

### בדיקות ידניות במכשירים אמיתיים

התוכנית מבקשת לבצע את הבדיקות האלה ולתעד אותן, באייפון ובטלפון אנדרואיד,
כשהטלפון בעברית ואז באנגלית:

1. **מהקשה עד הקלדה בפחות משנייה:** מקליטים את המסך ב-60 פריימים לשנייה,
   מקישים *פתק מהיר* בווידג'ט, וסופרים פריימים מההקשה עד שהסמן מהבהב.
   האפליקציה גם רושמת ביומן `widget tap → typing` מהרגע שבו היא מקבלת את
   הקישור, כך שזמן ההפעלה של המערכת לא נכלל בו.
2. **‏Siri:** אומרים „הוסף לתיבת הלכידה של Lumen” ואז משפט, כש-Lumen
   סגור. פותחים את Lumen: המשפט נמצא בסוף `inbox.md`, עם השעה שבה אמרתם
   אותו.
3. **אפליקציית הקיצורים:** יוצרים קיצור עם *הוספה לתיבת הלכידה של Lumen*
   ומריצים אותו. התוצאה זהה.
4. **‏RTL:** כשהטלפון בעברית, כפתורי הווידג'ט מסודרים מימין לשמאל
   והתוויות בעברית. אותו הדבר בקיצורי האפליקציה.
5. **כל קישור:** ‏`lumen://search?q=test` מהדפדפן פותח חיפוש עם „test”.
6. **מסך הנעילה ומרכז הבקרה:** כשהטלפון נעול ו-Lumen סגור, מקישים על
   הווידג׳ט במסך הנעילה, ואז על הפקד. התיבה נפתחת, ושורה שנשמרה נמצאת
   ב-`inbox.md` אחרי ש-Lumen נפתח.
7. **שיתוף:** משתפים דף מ-Safari, תמונה מ-Photos ו-PDF מ-Files, כש-Lumen
   סגור. פותחים את Lumen: כל אחד מהם נמצא שם, עם הקישור או שם הקובץ.
8. **שיתוף ואריח באנדרואיד:** משתפים דף מ-Chrome, שתי תמונות בבת אחת
   והודעת WhatsApp, ואז מוסיפים שורה מהאריח בהגדרות המהירות. פותחים את
   ‏Lumen: כולם ב-`inbox.md` (התמונות ב-`attachments/`), ושורת ה-WhatsApp
   מציינת את האפליקציה ואת הכותב.
