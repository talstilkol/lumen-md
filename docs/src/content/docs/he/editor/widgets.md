‏Lumen נמצא במרחק הקשה אחת בטלפון, בעברית ובאנגלית.

## במסך הבית

ל**ווידג'ט של Lumen** (אייפון ואנדרואיד) יש שלושה כפתורים:

- **חיפוש** פותח את החיפוש.
- **פתק מהיר** פותח את תיבת הלכידה, עם הסמן בתוכה.
- **היום** פותח את הפתק היומי של היום.

הווידג'ט לא מציג טקסט מהפתקים. בעברית הכפתורים מסודרים מימין לשמאל.

## ‏Siri, ‏Spotlight וקיצורים (אייפון)

הפקודות האלה עובדות בלי הגדרה. אפשר לומר אותן ל-Siri, להקליד אותן
ב-Spotlight או למצוא אותן באפליקציית הקיצורים:

| מה אומרים או מחפשים | מה קורה |
|---|---|
| „הוסף לתיבת הלכידה של Lumen” | ‏Siri שואלת מה להוסיף ומוסיפה את זה לסוף `inbox.md`, בלי לפתוח את Lumen |
| „פתק מהיר ב-Lumen” | פותח את תיבת הלכידה |
| „פתק קולי ב-Lumen” | פותח את התיבה ומתחיל להקליט |
| „חפש ב-Lumen” | פותח את החיפוש (ומאפליקציית הקיצורים, עם מילות החיפוש) |
| „הפתק של היום ב-Lumen” | פותח את הפתק של היום |

באנגלית: "Add to Lumen inbox", ‏"Quick note in Lumen", ‏"Search Lumen" וכן
הלאה.

*הוספה לתיבה* עובדת גם כש-Lumen סגור. הטקסט מחכה בטלפון, ובפעם הבאה
ש-Lumen נפתח הוא נכנס ל-`inbox.md`, עם השעה שבה אמרתם אותו. כל שורה נוספת
פעם אחת, ושום דבר לא הולך לאיבוד אם Lumen נסגר שוב לפני כן.

## קיצורי אפליקציה (אנדרואיד)

לחיצה ארוכה על הסמל של Lumen: **פתק מהיר**, **פתק קולי**, **חיפוש**
ו**היום**. אפשר לגרור כל אחד מהם למסך הבית כדי שיישאר שם.

## קישורים לאפליקציות אחרות

כל כפתור בווידג'ט וכל קיצור הוא קישור, ואפליקציות ואוטומציות אחרות יכולות
להשתמש בו:

| קישור | מה הוא עושה |
|---|---|
| `lumen://capture` | פותח את תיבת הלכידה |
| `lumen://capture?mode=voice` | פותח את התיבה ומתחיל להקליט |
| `lumen://capture?text=…` | מוסיף את הטקסט לתיבת הלכידה |
| `lumen://new` | פותח פתק חדש |
| `lumen://search?q=…` | פותח חיפוש עם מילות החיפוש |
| `lumen://daily` | פותח את הפתק של היום |

## למתחזקים: איך בונים

לחלקים המקוריים יש כלל אחד: הם רק מעבירים לאפליקציה קישור או שורה שחיכתה
בתור. מה כל קישור עושה נקבע ב-`src/mobile/nativeActions.ts`, שנבדק
(`src/__tests__/widgets.test.ts`). עוזר הקישורים באנדרואיד הוא
`LumenActions.java`, ‏Java רגיל שנבדק עם `javac`.

### ‏iOS ‏(Xcode)

הקבצים נמצאים במאגר. הצעדים האלה מוסיפים אותם לפרויקט Xcode, פעם אחת:

1. `npm run build && npx cap sync ios`, ואז פותחים את
   `ios/App/App.xcworkspace` (או `App.xcodeproj` עם Swift Package Manager).
2. **קבצים חדשים ליעד App:** ‏File ← Add Files to "App"… ובוחרים:
   - את `App/LumenNative.swift` ואת `App/LumenIntents.swift`, כשהתיבה
     *Target: App* מסומנת;
   - את `App/en.lproj` ואת `App/he.lproj` ‏(`Localizable.strings`,
     ‏`AppShortcuts.strings`).
3. **שפות:** ‏Project ← Info ← Localizations, ומוסיפים **Hebrew**.
4. **הרחבת הווידג'ט:**
   - ‏File ← New ← Target ← **Widget Extension**. קוראים לה
     `LumenWidgets`, מבטלים את *Include Configuration App Intent* ואת
     *Include Live Activity*, ובוחרים *Activate* כשנשאלים.
   - מוחקים את קובץ ה-Swift ש-Xcode יצר. מוסיפים את
     `LumenWidgets/LumenWidgets.swift` ואת `LumenWidgets/en.lproj` /
     `he.lproj` ליעד **LumenWidgets**.
   - קובעים את גרסת היעד ל-iOS 16 ומעלה, ואת מזהה החבילה
     ל-`com.lumen.editor.LumenWidgets`.
5. **חתימה:** אותו צוות ליעד App וליעד LumenWidgets (החשבונות בתוכנית
   15.7). לא צריך App Group או יכולת חדשה: הווידג'ט רק פותח קישורים,
   ו*הוספה לתיבה* של Siri רצה בתהליך של האפליקציה עצמה.
6. ‏`Main.storyboard` כבר משתמש ב-`MainViewController`, שרושם את התוסף של
   האפליקציה. בודקים שהמחלקה שלו מציגה *Module: App*.
7. בונים ומריצים על מכשיר. לחיצה ארוכה על מסך הבית ← **+** ← **Lumen**
   מוסיפה את הווידג'ט.

### ‏Android ‏(Android Studio)

הכול כבר בפרויקט: הווידג'ט (`LumenWidgetProvider`,
‏`res/layout/widget_lumen.xml`, ‏`res/xml/widget_lumen_info.xml`), קיצורי
האפליקציה (`res/xml/shortcuts.xml`), מסנן ה-intent של `lumen://`, והתוסף,
ש-`MainActivity` רושם.

1. `npm run build && npx cap sync android`, ואז פותחים את `android/`
   ב-Android Studio.
2. ‏Build ← Make Project, ומריצים על מכשיר או אמולטור (API 26 ומעלה).
3. לחיצה ארוכה על מסך הבית ← **Widgets** ← **Lumen** מוסיפה את הווידג'ט.
   לחיצה ארוכה על סמל האפליקציה מציגה את הקיצורים.

### בדיקות ידניות במכשירים אמיתיים

התוכנית מבקשת לבצע את הבדיקות האלה ולתעד אותן, באייפון ובטלפון אנדרואיד,
כשהטלפון בעברית ואז באנגלית:

1. **מהקשה עד הקלדה בפחות משנייה:** מקליטים את המסך ב-60 פריימים לשנייה,
   מקישים *פתק מהיר* בווידג'ט, וסופרים פריימים מההקשה עד שהסמן מהבהב.
   האפליקציה גם רושמת ביומן `widget tap → typing` מהרגע שבו היא מקבלת את
   הקישור, כך שזמן ההפעלה של המערכת לא נכלל בו.
2. **‏Siri:** אומרים „הוסף לתיבת הלכידה של Lumen” ואז משפט, כש-Lumen
   סגור. פותחים את Lumen: המשפט נמצא בסוף `inbox.md`, עם השעה שבה אמרתם
   אותו.
3. **אפליקציית הקיצורים:** יוצרים קיצור עם *הוספה לתיבת הלכידה של Lumen*
   ומריצים אותו. התוצאה זהה.
4. **‏RTL:** כשהטלפון בעברית, כפתורי הווידג'ט מסודרים מימין לשמאל
   והתוויות בעברית. אותו הדבר בקיצורי האפליקציה.
5. **כל קישור:** ‏`lumen://search?q=test` מהדפדפן פותח חיפוש עם „test”.
