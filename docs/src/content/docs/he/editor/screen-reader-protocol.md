בדיקות אוטומטיות כמו axe מוצאות רק חלק ממה שחוסם משתמשי קוראי מסך. את
המסע הזה מריץ אדם, **בלי להסתכל על המסך**, עם כל קורא מסך, **בעברית**
(ממשק עברי, קול עברי). צעד עובר כשמצליחים לבצע אותו עם קורא המסך בלבד.
**חסם** הוא צעד שאי אפשר לבצע בכלל. היעד לגרסה: **0 חסמים** בכל קורא מסך.

## הגדרות

| קורא מסך | מערכת | דפדפן | קול |
|---|---|---|---|
| NVDA 2025.x | Windows 11 | Firefox ו-Chrome | ‏eSpeak NG או Microsoft Asaf (עברית) |
| VoiceOver | macOS 15+ | Safari | כרמית (עברית) |
| VoiceOver | iOS 18+ | Safari | כרמית (עברית) |
| TalkBack | Android 14+ | Chrome | ‏Google TTS, עברית |

לפני שמתחילים: ב-Lumen בוחרים בשפה עברית (הגדרות ← שפה, או בהגדרה
הראשונית), ומנקים את נתוני האתר כדי שההפעלה הראשונה תתחיל מאפס.

## המסע

1. **פתיחה.** פותחים את האפליקציה. כותרת הדף ושם העורך מוקראים.
2. **קישור דילוג.** Tab אחד: מוקרא "דילוג לעורך"; Enter מעביר את המיקוד לעורך.
3. **כתיבה.** מקלידים `# תוכנית`, ‏Enter, ואז שורת טקסט בעברית. הטקסט מוקרא תוך כדי הקלדה, בעברית.
4. **מבנה.** חץ למעלה לשורה הראשונה: מוקרא "כותרת 1: תוכנית".
5. **משימה.** מוסיפים `- [ ] לקנות חלב`, זזים ממנה וחוזרים: מוקרא "משימה, לא בוצעה".
6. **איפה אני.** פותחים את לוח הפקודות (Ctrl+K / ⌘K), מקלידים `מיקום`, ‏Enter: מוקראות השורה, העמודה והכותרת.
7. **לוח הפקודות.** בלוח הפקודות עוברים בתוצאות בחצים: שם כל פקודה מוקרא, ומספר התוצאות מוקרא כשהוא משתנה.
8. **חלון דו-שיח.** פותחים את קיצורי המקלדת (Ctrl+/ / ⌘/). שם החלון מוקרא, Tab נשאר בתוכו, Escape סוגר אותו, והמיקוד חוזר לעורך.
9. **חיפוש.** פותחים חיפוש, מקלידים מילה מהפתק ופותחים את התוצאה: הפתק נפתח והמיקוד בעורך.
10. **סרגל צד.** פותחים את סרגל סביבת העבודה מלוח הפקודות, עוברים בין הקבצים ופותחים אחד.
11. **תצוגה מקדימה.** עוברים לתצוגה מקדימה (מלוח הפקודות). אפשר לפתוח את רשימת הכותרות של קורא המסך, והכותרות בה בסדר הנכון.
12. **AI.** אם AI מוגדר: מריצים פקודת כתיבה. מוקרא "ה-AI עובד…" ואחר כך "ה-AI סיים.", ואפשר להגיע לתוצאה.
13. **כיוון מעורב.** שורה עם עברית ומילה באנגלית מוקראת בסדר הנכון.
14. **הגדרות.** פותחים את הגדרות ערכת הנושא, עוברים למצב כהה ובחזרה במקלדת. המצב של כל פקד מוקרא.
