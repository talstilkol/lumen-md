Lumen לא הופך פתק שלם לימין-לשמאל או לשמאל-לימין. כל בלוק נקרא בכיוון של
הטקסט **שלו**, כך שפסקה בעברית יושבת מימין והפסקה האנגלית שאחריה משמאל,
באותו פתק.

| בלוק | כיוון |
| --- | --- |
| פסקה, כותרת | האות החזקה הראשונה שלו (עברית ← מימין לשמאל) |
| רשימה, פריט, ציטוט | הטקסט שלו: לרשימה בעברית הסימנים וההזחה מימין, ולציטוט הפס מימין |
| טבלה (תצוגה, ייצוא) | הטבלה משמאל לימין; **כל תא** לפי הטקסט שלו |
| טבלה (WYSIWYG) | הפסקה שבכל תא לפי הטקסט שלה |
| קוד, נוסחאות | תמיד משמאל לימין, גם עם הערה בעברית |

אותם כללים חלים בעורך המקור (שורה אחרי שורה), בתצוגה, ב-WYSIWYG ובייצוא
ל-HTML — פתק בעברית שיוצא נפתח כ-`<html lang="he" dir="rtl">` עם אותו
`dir` על כל בלוק.

כשהממשק בעברית, האפליקציה עצמה מתהפכת: סרגל הכלים, החלוניות והתפריטים
מתחילים מימין.

## בדיקות

`e2e/rtl-matrix.spec.ts` בודק טבלאות, רשימות (תבליטים, ממוספרות, מקוננות,
משימות), ציטוטים וקוד בתצוגה, ב-WYSIWYG ובייצוא, כשהממשק בעברית ובאנגלית,
ב-Chromium, ‏Firefox ו-WebKit, ועל iPhone 14 ו-Pixel 7. `visual/rtl.visual.ts`
שומר תמונות בסיס של אותו פתק (ראו [רגרסיה חזותית](/he/contributing/visual-regression/)).
