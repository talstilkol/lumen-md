Lumen תומכת בכניסה יחידה ב-SAML וב-OIDC דרך [WorkOS](https://workos.com).
מנהל הארגון מחבר את ספק הזהויות פעם אחת; אחר כך החברים מתחברים עם דומיין
הדוא״ל של העבודה.

## התחברות

1. פותחים **Sign in** בסרגל הכלים.
2. מקלידים את דומיין הדוא״ל של הארגון (למשל `acme.com`).
3. משלימים את ההתחברות אצל ספק הזהויות. חוזרים ל-Lumen ומחוברים.

## סיבות לשגיאה

כש-SSO נכשל, Lumen חוזרת עם `?sso=error&reason=…`:

| סיבה | תיקון |
|---|---|
| `no_sso_connection` | אין ארגון מוגדר לדומיין הזה. בקשו מהמנהל להוסיף את הדומיין ב-WorkOS. |
| `state_mismatch` | ההתחברות התחילה בדפדפן אחר או נמשכה יותר מ-10 דקות. התחילו מחדש. |
| `access_denied` | ספק הזהויות סירב להתחברות — בקשו ממנהל ה-IT לשייך אתכם לאפליקציית Lumen. |
| `code_exchange_failed` | ה-worker של SSO לא הצליח לאמת את ההתחברות. בדרך כלל `WORKOS_API_KEY` / `WORKOS_CLIENT_ID` שגויים. |

## אירוח עצמי

מתקינים את `edge-workers/auth/` (ראו `DEPLOY.md` §5b) ומגדירים את
`VITE_WORKOS_ENDPOINT` לכתובת ה-worker.
