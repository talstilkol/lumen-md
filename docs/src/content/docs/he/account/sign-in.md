ההתחברות אופציונלית — Lumen עובדת במלואה בלי רשת ובלי חשבון. חשבון פותח
חדרי שיתוף מתמשכים, סנכרון בענן וחיפוש חכם.

## הודעות מצב

| מצב | משמעות | מה לעשות |
|---|---|---|
| **Signed in** | יש סשן פעיל. | כלום. |
| **Signed out** | התחברות לענן זמינה אבל אתם לא מחוברים. | פותחים **Sign in** בסרגל הכלים. |
| **Sign-in not configured** | בבנייה הזו אין ספק אימות (מצב מקומי בלבד). | מארחים עצמאיים: ראו [הפעלת חשבונות](#הפעלת-חשבונות). כל השאר: ממשיכים לעבוד מקומית. |
| **Sign-in error** | אי אפשר היה להגיע לספק, או שהוא דחה את הבקשה. | ראו [פתרון בעיות](#פתרון-בעיות). |

## הפעלת חשבונות

מגדירים את אלה ב-`.env.local` ובונים מחדש:

- **דוא״ל / OAuth ‏(Supabase)** — `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY`,
  ואז `npm install @supabase/supabase-js`.
- **SSO ארגוני (WorkOS)** — `VITE_WORKOS_ENDPOINT`; ראו
  [כניסה יחידה](/he/account/sso/).

## פתרון בעיות

- **שגיאת רשת / הספק לא זמין** — בדקו את החיבור, ה-VPN או ה-proxy הארגוני,
  ונסו שוב. בינתיים Lumen ממשיכה לעבוד מקומית.
- **דוא״ל או סיסמה שגויים** — אפסו את הסיסמה מהדוא״ל של הספק, או השתמשו
  בכפתורי ה-OAuth.
- **הסשן פג** — התחברו שוב; המסמכים המקומיים שלכם לא נפגעים.
