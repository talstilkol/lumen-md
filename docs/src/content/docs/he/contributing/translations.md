הממשק של Lumen קיים בשמונה שפות. **אנגלית** היא שפת המקור, ו**עברית** נכתבת בידי דוברי
שפת אם. שש האחרות תורגמו במכונה (תוכנית 9.1), ואף דובר/ת שפת אם עוד לא בדקו אותן, ולכן
Lumen מסמן אותן **בטא**:

| שפה | מצב |
|---|---|
| English (אנגלית) | מקור |
| עברית | שפת אם |
| العربية (ערבית) | בטא |
| Русский (רוסית) | בטא |
| Français (צרפתית) | בטא |
| Deutsch (גרמנית) | בטא |
| 日本語 (יפנית) | בטא |
| 简体中文 (סינית מפושטת) | בטא |

ב**הגדרות ← כללי ← שפה** ובלוח הפקודות, שפה בבטא מופיעה כ-"Русский (בטא)", "Français
(בטא)" וכן הלאה, בשפת הממשק שלכם. כשהממשק בשפה שבבטא, ההגדרות מציינות שהתרגום מחכה לבדיקה
של דובר/ת שפת אם, עם קישור לטופס ההצעה.

## הצעת תרגום טוב יותר

לוח הפקודות ← **הציעו תרגום טוב יותר** (יש קישור גם מתחת להגדרת השפה).

1. הקלידו את המילים שראיתם על המסך. Lumen מוצא את המחרוזות שמכילות אותן, בשפה שלכם או
   באנגלית.
2. בחרו את המחרוזת וכתבו אותה כמו שדובר/ת שפת אם היו כותבים. השאירו כל `{placeholder}` כמו
   שהוא.
3. **פתיחה ב-GitHub** פותחת את טופס ה-issue של הפרויקט בכרטיסייה חדשה, עם הכותרת
   (`[i18n:ru] toolbar.save`), התוויות `i18n` ו-`locale:ru`, המקור באנגלית, התרגום הנוכחי
   והתרגום שלכם. אתם מפרסמים אותו מחשבון GitHub שלכם. **העתקת הטקסט** נותנת את אותו טקסט
   לשליחה בכל דרך אחרת.

שום דבר לא נשלח מ-Lumen עצמו: אין שרת ואין חשבון באפליקציה. ה-issue קיים רק אחרי שאתם
מפרסמים אותו.

## בדיקה של שפה שלמה

אם אתם דוברי שפת אם ורוצים לבדוק שפה שלמה, המחרוזות נמצאות ב-`src/i18n/locales/<lang>/*.json`,
קובץ לכל תחום. פתחו pull request עם התיקונים. מחרוזות חדשות שמודל ניסח רשומות
ב-`i18n/needs-review/` עד שאדם מאשר אותן ([טיוטות תרגום](/he/contributing/translation-drafts/)).
כששפה נבדקה, המצב שלה ב-`src/i18n/review.ts` משתנה מ-`beta` ל-`reviewed`, וסימון הבטא נעלם.

ערבית היא השפה השנייה בישראל שנכתבת מימין לשמאל, ולכן הבדיקה שלה כוללת גם את בדיקות ה-RTL
(מטריצת ה-RTL, תוכנית 9.5, רצה גם בערבית).
