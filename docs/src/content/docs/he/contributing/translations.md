Lumen יוצא עם שתי שפות **מלאות**: **אנגלית**, שפת המקור, ו**עברית**, שנכתבת בידי דוברי
שפת אם. הממשק זמין גם בשש שפות נוספות, אבל הן תורגמו במכונה (תוכנית 9.1), ואף דובר/ת שפת
אם עוד לא בדקו אותן. Lumen מסמן כל אחת מהן **בטא (תרגום מכונה, ממתין לבדיקת דובר/ת שפת
אם)**, וצפויים בהן ניסוחים שגויים או מסורבלים:

גם מחרוזת עברית חדשה יכולה להתחיל כטיוטת מכונה. עד שדובר/ת שפת אם מאשרים אותה
(`npm run i18n:draft -- --approve=he`), היא רשומה תחת `he` ב-`i18n/needs-review/`. כרגע אלה
7 מחרוזות, כולן מחלון הייצוא האקדמי: `academic.chosen`, ‏`academic.chosenUnverified`,
‏`academic.exported`, ‏`academic.noChoice`, ‏`academic.none`, ‏`academic.pick` ו-`academic.unverified`.

| שפה | מצב |
|---|---|
| English (אנגלית) | מלאה (מקור) |
| עברית | מלאה (שפת אם) |
| العربية (ערבית) | בטא |
| Русский (רוסית) | בטא |
| Français (צרפתית) | בטא |
| Deutsch (גרמנית) | בטא |
| 日本語 (יפנית) | בטא |
| 简体中文 (סינית מפושטת) | בטא |

בכל מקום שבו בוחרים שפה, שפה בבטא אומרת זאת, בשפת הממשק שלכם:

- **לוח הפקודות** (שפה: …) ו**הגדרות ← כללי ← שפה**: "Русский — בטא (תרגום מכונה, ממתין
  לבדיקת דובר/ת שפת אם)".
- **ההגדרה הראשונית**: כל שפה בבטא נושאת את אותו סימון מתחת לשמה.

מתחת להגדרת השפה ובשלב השפה של ההגדרה הראשונית יש קישור שפותח את הדף הזה
ב[דיווח על בעיה בתרגום](#report-a-translation-issue). כשהממשק בשפה שבבטא, ההגדרות גם
מציינות שהתרגום מחכה לבדיקה של דובר/ת שפת אם, עם קישור לטופס ההצעה.

הרשימה של אילו שפות מלאות ואילו בבטא נמצאת במקום אחד, `src/i18n/review.ts`; בוחר השפה,
ההגדרה הראשונית, ההגדרות והטבלה הזו כולם הולכים לפיה (בדיקה משווה את הטבלה הזו אליה).

## דיווח על בעיה בתרגום

<a id="report-a-translation-issue"></a>

מצאתם מחרוזת שנקראת לא נכון, נחתכת, או עדיין באנגלית? השתמשו ב**הציעו תרגום טוב יותר**
שלמטה; זו הדרך המהירה ביותר, וצריך רק חשבון GitHub. אם אתם מעדיפים לא להשתמש ב-GitHub,
לחצו על **העתקת הטקסט** באותו טופס ושלחו אותו לפרויקט בכל דרך אחרת. כתבו באיזו שפה,
מה ראיתם, ואם אפשר, מה צריך להיות כתוב.

## הצעת תרגום טוב יותר

לוח הפקודות ← **הציעו תרגום טוב יותר** (יש קישור גם מתחת להגדרת השפה).

1. הקלידו את המילים שראיתם על המסך. Lumen מוצא את המחרוזות שמכילות אותן, בשפה שלכם או
   באנגלית.
2. בחרו את המחרוזת וכתבו אותה כמו שדובר/ת שפת אם היו כותבים. השאירו כל `{placeholder}` כמו
   שהוא.
3. **פתיחה ב-GitHub** פותחת את טופס ה-issue של הפרויקט בכרטיסייה חדשה, עם הכותרת
   (`[i18n:ru] toolbar.save`), התוויות `i18n` ו-`locale:ru`, המקור באנגלית, התרגום הנוכחי
   והתרגום שלכם. אתם מפרסמים אותו מחשבון GitHub שלכם. **העתקת הטקסט** נותנת את אותו טקסט
   לשליחה בכל דרך אחרת.

שום דבר לא נשלח מ-Lumen עצמו: אין שרת ואין חשבון באפליקציה. ה-issue קיים רק אחרי שאתם
מפרסמים אותו.

## בדיקה של שפה שלמה

הדרך הקלה ביותר היא בדפדפן, ב-[Weblate](/he/contributing/weblate/): כל תיקון חוזר כבקשת משיכה.

אם אתם דוברי שפת אם ורוצים לבדוק שפה שלמה, המחרוזות נמצאות ב-`src/i18n/locales/<lang>/*.json`,
קובץ לכל תחום. פתחו pull request עם התיקונים. מחרוזות חדשות שמודל ניסח רשומות
ב-`i18n/needs-review/` עד שאדם מאשר אותן ([טיוטות תרגום](/he/contributing/translation-drafts/)).
כששפה נבדקה, המצב שלה ב-`src/i18n/review.ts` משתנה מ-`beta` ל-`reviewed`, וסימון הבטא נעלם.

ערבית היא השפה השנייה בישראל שנכתבת מימין לשמאל, ולכן הבדיקה שלה כוללת גם את בדיקות ה-RTL
(מטריצת ה-RTL, תוכנית 9.5, רצה גם בערבית).

בודקים שקובצי השפות מסודרים כפי שהכלים מצפים (הדוגמה הזאת רצה בבדיקת התיעוד):

```sh run
node scripts/i18n-split.mjs --check   # expect: i18n layout is current
```
