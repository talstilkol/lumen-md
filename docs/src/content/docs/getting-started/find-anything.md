---
title: "Tutorial: find anything"
description: Find a command, a setting, a link and a heading — typing without niqqud, without accents, even in the wrong keyboard layout.
type: tutorial
---

Lumen has many commands and settings. In this tutorial you find them by
typing, the way you would find a file on your computer. Every box you meet
here ignores niqqud, accents, capitals and geresh: `שלום` finds `שָׁלוֹם`,
`cafe` finds `café`, `צהל` finds `צה״ל`.

1. **Open the command palette.** Press `⌘K`. Type `outline` — or `תוכן`
   in Hebrew. The matching commands are listed, best first. Press `Esc`.
2. **Type in the wrong layout.** Press `⌘K` again and type `jhpuai` with the
   English layout on: those are the keys of `חיפוש`. Lumen finds the search
   command and says it also read your keys as Hebrew. Press `Esc`.
3. **Open the settings by keyboard.** Press `⌘,`. The search box already has
   the focus.
4. **Search for what you want, not for its name.** Type `מצב כהה` (or `dark
   mode`). The theme setting comes first, though its name is "Theme". Press
   `Enter`: its control has the focus; choose a theme with the arrow keys.
5. **Go back to the search.** Press `⌘F`. Type `vim`, then `↓` and `Enter` to
   reach the Vim switch. Press `Esc` twice to close the settings.
6. **Filter a note's backlinks.** Open a note that other notes link to and
   open the backlinks panel (`⌘K` → *Backlinks*). Type a word in its search
   box: only the links whose note name or sentence has it stay.
7. **Link to a note with an accented name.** In the editor type `[[` and then
   `lodz`: a note called `Łódź` is offered. Press `Enter` to insert the link.

You can now find any command, setting, heading or note by what it is called
or what it does. See [Settings](/editor/settings/) for all the settings keys.
