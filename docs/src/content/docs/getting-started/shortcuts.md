title: Keyboard shortcuts
description: Every shortcut Lumen binds, where it works, and how to find the rest in the command palette.
---

On Windows and Linux, `⌘` is **Ctrl**, `⌥` is **Alt** and `⇧` is
**Shift**; the app shows the right keys for your system.
`⌘/` opens this list inside the app.

Everything Lumen can do is a command in the **command palette** (`⌘K`),
which shows each command's shortcut when it has one.

## Anywhere in the app

| Keys | Action |
|---|---|
| `⌘K` | Command palette |
| `⌘/` | Keyboard shortcuts |
| `⌘N` | New document |
| `⌘O` | Open file |
| `⌘S` | Save |
| `⇧⌘S` | Save as |
| `⌘1` / `⌘2` / `⌘3` / `⌘4` | Source / Split / Preview / WYSIWYG |
| `⌘H` | Find and replace |
| `⇧⌘V` | Smart Insert (paste anything, detected and wrapped) |
| `⇧⌘F` | Focus mode (press again to leave) |
| `Esc` | Close the open dialog |

Workspace search has no global key of its own today: open it with
`⌘K → Search workspace…`. Printing is `⌘K → Print / Save as PDF…`; `⌘P`
opens the browser's own print dialog.

## In the editor

| Keys | Action |
|---|---|
| `⌘Z` / `⇧⌘Z` | Undo / redo |
| `⌘F` | Find in this note (source editor) |
| `⇧⌥F` | Format the document |
| `Ctrl+Space` | Ask the AI for a continuation (ghost text) |

## In the tab strip and the rich editor

| Keys | Where | Action |
|---|---|---|
| `⌘W` | a focused tab | Close it |
| `↑` / `↓` | a focused block handle | Move the block up / down |
| `Enter` / `Space` | a focused block handle | Put the cursor at the block's start |
