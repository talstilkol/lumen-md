Lumen is built in the open, in Hebrew and English.

## The beta

- **Joining:** open a discussion in the **Beta** category of the project's
  GitHub Discussions. It's a short form, and you need a GitHub account.
  The beta page (`/beta.html`) explains it all and sends nothing by itself.
- **What you get:** new features before everyone else. They ship behind
  feature flags in beta builds first.
- **What we ask:** use Lumen for real writing a few times a week, and tell
  us what got in the way, in **Beta feedback**.
- **The weekly survey:** a short, voluntary poll, *how many days this week
  did you open Lumen?* It is the only way we count testers. Lumen has no
  analytics and doesn't count you.
- **Keep a backup:** *Export the whole vault* now and then. It's a beta.

## Where to talk

| For | Where |
|---|---|
| Beta feedback: bugs, ideas, Hebrew and RTL problems | Discussions → *Beta feedback* |
| A confirmed bug or a concrete feature | GitHub Issues |
| Questions, show and tell | Discussions → *Q&A*, *Show and tell* |
| Security problems | privately, as in `SECURITY.md` |

Hebrew or English, whichever you prefer.

## The code of conduct

The project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
The repository has it in English (`CODE_OF_CONDUCT.md`) and in Hebrew
(`CODE_OF_CONDUCT.he.md`). In short:

- assume good intent;
- criticise the work, not the person;
- no harassment, no personal attacks, no sharing others' private
  information.

Reports go privately to the maintainers, as described in `COMMUNITY.md`,
and are kept confidential.
