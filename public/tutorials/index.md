# Lumen Video Tutorial Series

## Quick Start (3 min)

Cover the absolute basics: creating a new note, typing markdown, switching between Source / Split / Preview mode, and saving to disk.

**Script outline:**
1. Open lumen.md in browser (0:00)
2. Click "New Document" (0:10)
3. Type `# Hello World` — see live preview (0:30)
4. Press ⌘E to toggle Split mode (0:45)
5. Drag-drop an image into the editor (1:00)
6. Press ⌘S to save as `.md` file (1:15)
7. Open the file from Finder → back in Lumen (1:30)
8. Command Palette (⌘K) for power users (1:50)

## Advanced Markdown (8 min)

Tables, code blocks with syntax highlighting, math (KaTeX), mermaid diagrams, callouts, and frontmatter.

## Collaboration (5 min)

Starting a collab room, sharing the URL, watching live cursors, resolving conflicts, and using inline comments.

## AI Copilot Deep Dive (6 min)

Configuring local LLM (WebGPU), inline ghost-text suggestions, generating outlines from unstructured notes, voice dictation, and semantic search.

## Sync & Backup (4 min)

Connecting Dropbox / Google Drive, setting up real-time auto-backup, iCloud on iOS, and restoring from version history.

## Customizing with Plugins (7 min)

Installing community plugins, building a hello-world plugin with `create-lumen-plugin`, and submitting to the contest.

## Mobile & iOS (4 min)

Installing from TestFlight, Share Extension (share any web page into Lumen), offline editing, and iCloud sync.
