## Goal

Measure the free-fall acceleration $g$ from the time $t$ it takes a ball to
drop a height $h$.

## Theory

$$
h=\frac{1}{2}gt^2 \quad\Rightarrow\quad g=\frac{2h}{t^2}
$$

## Measurements

| $h$ (m) | $t$ (s) | $g=2h/t^2$ (m/s²) |
| --- | --- | --- |
| 1.00 |  |  |
| 1.50 |  |  |
| 2.00 |  |  |

## Error analysis

$\frac{\Delta g}{g}=\frac{\Delta h}{h}+2\frac{\Delta t}{t}$, with $\Delta t=$ s.

## Conclusion

The measured value $g=$ m/s² differs from $9.81$ m/s² by %.
