Everything you need to write

From quick notes to encrypted research vaults — Lumen handles it all in your browser.

✍️

4 Writing Modes

Source, Split, Preview, and WYSIWYG. Switch instantly with ⌘1-4. Each mode is optimized for different workflows.

🧠

AI-Powered Writing

18 prompt templates in Hebrew, Arabic, Russian & English. Summarize, improve, translate, and code review — all from ⌘K.

🔒

Vault Encryption

AES-256-GCM encryption with PBKDF2 key derivation. Your documents stay private, even from us.

📊

Data → Tables

Import CSV, TSV, JSON, XML and see them instantly rendered as beautiful, interactive tables. Also supports RTF, DOC, DOCX.

🔌

Plugin System

Extend Lumen with custom plugins. Full API for commands, lifecycle hooks, and content manipulation.

🎙️

Voice to Markdown

Dictate in any language using the Web Speech API. Your words are transcribed directly into markdown.

🌐

Real-time Collaboration

P2P editing over WebRTC. No server needed. Share a link and co-edit with anyone in real time.

🗺️

Knowledge Graph

Visualize connections between documents with an interactive force-directed graph. See your knowledge structure emerge.

📄

Page View

A4 paginated preview with page numbers and smooth navigation. Your documents look exactly like they'll print.
