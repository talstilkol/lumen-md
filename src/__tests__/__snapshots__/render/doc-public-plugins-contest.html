📋 Rules

  1. Create a Lumen plugin using our Plugin SDK
  2. Open source — MIT license required
  3. Original work — no forks of existing plugins without significant improvement
  4. Submit by November 30, 2024 23:59 UTC
  5. Judging criteria:
    • Innovation (30%) — does it solve a real problem in a novel way?
    • Polish (25%) — UI/UX quality, error handling, documentation
    • Performance (20%) — doesn't slow down the editor
    • Community (15%) — stars, issues, discussion engagement
    • Code quality (10%) — tests, TypeScript, clean architecture

🚀 How to Enter

  1. Build your plugin: npx create-lumen-plugin my-plugin
  2. Publish to GitHub with #lumen-plugin-contest topic
  3. Open a discussion in GitHub Discussions
  4. Include: demo video (max 2 min), README with screenshots, install instructions

📦 Popular Ideas (not required)

  • AI summarizer — auto-generate TL;DR for long docs
  • Zettelkasten linker — bidirectional note links with graph view
  • Calendar/timeline view — render dates as Gantt or calendar
  • Mermaid live editor — inline diagram editing
  • Spaced repetition — flashcards from headings
  • Citation manager — BibTeX / Zotero integration
  • Word count goals — NaNoWriMo-style daily targets
  • Folding regions — custom fold markers beyond headings

⚖️ Judging

Panel: Lumen core team (3) + community maintainers (2)

Scoring rubric published in JUDGING_RUBRIC.md
