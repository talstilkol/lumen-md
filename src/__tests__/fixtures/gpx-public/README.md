# Public GPX files (plan W12.F7)

GPX files copied unchanged from the test files of
[gpxpy](https://github.com/tkrajina/gpxpy) (`test_files/`, commit
056cdfc34677f85b0185abffb855d2de01520da7), Apache-2.0 (`LICENSE-gpxpy`):
`korita-zbevnica.gpx`, `cerknicko-jezero.gpx`, `Mojstrovka.gpx` (tracks),
`route.gpx` (a route), `gpx1.1_with_all_fields.gpx` (waypoints, routes and
tracks with every GPX 1.1 field) and `unicode_with_bom.gpx` (a byte-order
mark and non-ASCII names).
