# Mac pack, lane L3 (wave g6)

What the Mac runs for the 41 Mac tasks of lane L3, and how each result is checked by a machine.
The pack is [`L3.json`](L3.json): 49 entries `{id, cmd, expect, needs, minutes}`, 1381 minutes of machine time declared (most of it unattended: the e2e run, models day, mutation, fuzz).

## How to run it

```sh
node scripts/mac-pack/L3/run.mjs --check        # the pack is well formed and every script/spec it names exists
node scripts/mac-pack/L3/run.mjs --list         # entries, needs, minutes
node scripts/mac-pack/L3/run.mjs                # everything, in order
node scripts/mac-pack/L3/run.mjs --only L3-setup,L3-e2e-run,L3-W4.2   # a part
node scripts/mac-pack/L3/run.mjs --verify-only  # re-check every JSON expect without running again
```

Results go to `reports/mac-pack/L3.json` (`schema: lumen.mac-pack/1`: commit, dirty flag, machine, and per entry `id, ok, exit, minutes, detail`). The run exits 0 only when every entry that ran is ok. An entry whose prerequisite failed still runs: its own expect decides.

**One e2e run, many checks.** `L3-e2e-run` runs the nightly full plan once (build with `VITE_E2E=1`, all vitest, every spec on chromium, firefox and webkit in 4 shards, the `@nightly` perf project). Every e2e entry after it only reads those shard files with `scripts/mac-pack/L3/e2e-summary.mjs --specs …` and writes `reports/mac-pack/L3-e2e-<label>.json` with `ok`. A spec counts as green in a project when it has at least one passed test and no failed or flaky ones.

**Expect.** `exit` is the command's exit code; `json` checks a field of a file the command wrote (`*` picks the newest match; an object in the path picks an array element, e.g. `{"id": "asr-web"}`). The aggregator can evaluate the same objects with `scripts/mac-pack/L3/lib.mjs` (`checkExpect`).

**Environment variables** a few entries need: `LUMEN_OBSIDIAN_VAULT` (a vault with real `.base` files), `LUMEN_NEMO_TEST` and `LUMEN_NEMO_SHA256` (a local NEMO test file, never committed), `LUMEN_FLORES_DIR` (a local FLORES-200 copy, gated).

**What the owner still does by hand:** keys for `L3-W4.5`, `L3-11.5` and `L3-W4.22-ios`; the Obsidian step between `L3-W4.30-prepare` and `L3-W4.30-diff`; looking at the visual baselines (W12.M3) before `npm run visual:approve`; committing the files the runs write (`scripts/mutation/receipt.json`, `models/registry.json`, `src/ai/defaults.ts`, `eval/failures.md`).
