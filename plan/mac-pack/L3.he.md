# חבילת Mac, מסלול L3 (גל g6)

מה ה-Mac מריץ עבור 41 משימות ה-Mac של מסלול L3, ואיך מכונה בודקת כל תוצאה.
החבילה היא [`L3.json`](L3.json): ‏48 רשומות `{id, cmd, expect, needs, minutes}`, ‏1311 דקות מכונה מוצהרות (רובן בלי השגחה: ריצת ה-e2e, יום המודלים, mutation ו-fuzz).

## איך מריצים

```sh
node scripts/mac-pack/L3/run.mjs --check        # החבילה תקינה וכל סקריפט ו-spec שהיא מזכירה קיים
node scripts/mac-pack/L3/run.mjs --list         # הרשומות, מה כל אחת צריכה וכמה דקות
node scripts/mac-pack/L3/run.mjs                # הכול, לפי הסדר
node scripts/mac-pack/L3/run.mjs --only L3-setup,L3-e2e-run,L3-W4.2   # חלק
node scripts/mac-pack/L3/run.mjs --verify-only  # בדיקה חוזרת של כל ציפיות ה-JSON בלי להריץ שוב
```

התוצאות נכתבות ל-`reports/mac-pack/L3.json` (‏`schema: lumen.mac-pack/1`: הקומיט, האם העץ נקי, המכונה, ולכל רשומה `id, ok, exit, minutes, detail`). הריצה יוצאת 0 רק כשכל רשומה שרצה ok. רשומה שהתנאי שלה נכשל רצה בכל זאת: הציפייה שלה מחליטה.

**ריצת e2e אחת, הרבה בדיקות.** `L3-e2e-run` מריץ פעם אחת את תוכנית הלילה המלאה (בנייה עם `VITE_E2E=1`, כל vitest, כל spec ב-chromium, ‏firefox ו-webkit ב-4 shards, ופרויקט ה-perf). כל רשומת e2e אחריה רק קוראת את קובצי ה-shards עם `scripts/mac-pack/L3/e2e-summary.mjs --specs …` וכותבת `reports/mac-pack/L3-e2e-<label>.json` עם `ok`. ‏spec נחשב ירוק בפרויקט כשיש בו לפחות בדיקה אחת שעברה ואין בו כשל או flaky.

**ציפיות.** `exit` הוא קוד היציאה של הפקודה; `json` בודק שדה בקובץ שהפקודה כתבה (`*` בוחר את הקובץ החדש ביותר; אובייקט בנתיב בוחר איבר במערך, למשל `{"id": "asr-web"}`). המאגד יכול להעריך את אותם אובייקטים עם `scripts/mac-pack/L3/lib.mjs` ‏(`checkExpect`).

**משתני סביבה** שכמה רשומות צריכות: `LUMEN_OBSIDIAN_VAULT` (כספת עם קובצי `.base` אמיתיים), `LUMEN_NEMO_TEST` ו-`LUMEN_NEMO_SHA256` (קובץ test מקומי של NEMO, לא נכנס למאגר), `LUMEN_FLORES_DIR` (עותק מקומי של FLORES-200, מוגבל).

**מה הבעלים עדיין עושה ביד:** המפתחות של `L3-W4.5`, ‏`L3-11.5` ו-`L3-W4.22-ios`; השלב ב-Obsidian בין `L3-W4.30-prepare` ל-`L3-W4.30-diff`; מבט על ה-baselines הוויזואליים (W12.M3) לפני `npm run visual:approve`; ‏commit לקבצים שהריצות כותבות (`scripts/mutation/receipt.json`, ‏`models/registry.json`, ‏`src/ai/defaults.ts`, ‏`eval/failures.md`).

## מה נבדק בענן (g6 L3)

- `run.mjs --check`: ‏48 רשומות, כל סקריפט npm, סקריפט ו-spec שמוזכרים קיימים (גם מקרה ב-vitest).
- `src/__tests__/macPackL3.test.ts` ‏13/0 (shim): בודק הציפיות, בחירת הקובץ החדש ביותר, סיכום ה-e2e על דוח JSON אמיתי של Playwright 1.56, כלל הריצה המלאה (shard חסר, shard מעל 40 דקות, כשל), והכרעת Argon2.
- `run.mjs --only L3-0.5,L3-W4.10,L3-W4.6` כאן: הפקודות רצו ונכשלו בגלל הסביבה (אין דוחות לילה, אין ריצת e2e, אין יום מודלים), כל אחת עם הסיבה ב-`detail`.
- `argon2-bench.mjs --runs 1` כאן: ה-Argon2id שלנו עובר RFC 9106 ולוקח 8.6 שניות ב-m=64 MiB ‏t=3 במכונה (העמוסה) הזאת; hash-wasm לא מותקן, ולכן ההכרעה ✗ כמו שצריך.
- `playwright test --list e2e/bases-kanban.spec.ts` מונה את ה-spec החדש בשלושת פרויקטי הדפדפנים; הוא לא רץ (אין Vite כאן).
