**How to read `expect`.** `exit` is the command's exit code. Each item of `json` is one check on a JSON file the command wrote: `path` is a dot path into the file, compared with `op` against `value`. Vitest files come from `--reporter=json --outputFile` (`numFailedTests`, `numPassedTests`); Playwright files from `PLAYWRIGHT_JSON_OUTPUT_NAME` with `--reporter=json` (`stats.expected`, `stats.unexpected`). Every result file goes under `.mac-pack/L2/`. A `>=` minimum is the number of tests that exist today, so a missing test is red, not a pass.

**One e2e run.** `L2-e2e-batch` runs every spec below at once, on three engines, with one dev server. The per-task entries reuse the same specs, so the aggregator can read either.

Run from the repo root after `npm ci`. "Cloud" says what was checked here and how. "Owed" is what only the Mac or the owner can do.
