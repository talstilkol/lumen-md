The first public beta of Lumen: a local-first Markdown editor that is Hebrew-first. Your notes stay files on your own device; AI runs locally unless you choose otherwise.

This beta is for people who want to try Lumen early and tell us what breaks. It is the first release since 0.1.0, so it carries everything built since then: the full list is under "All changes" below.

- **Desktop updates.** The desktop app now updates itself. A beta build follows the beta channel and gets every later beta; stable builds never get a beta. Each update is checked against the release's signing key before it installs, and a file with one changed byte is refused.
- **Signed downloads.** Every file of the release is listed in SHA256SUMS, which is signed with minisign, and the software bill of materials (sbom.cdx.json, CycloneDX) is signed the same way.
- **Before you start.** Back up your notes folder. This is a beta: report problems at https://github.com/talstilkol/lumen-md/issues. Unless the macOS build is notarized and the Windows installer signed (see the asset list), macOS asks you to confirm the first launch (right-click → Open) and Windows SmartScreen shows a warning.
